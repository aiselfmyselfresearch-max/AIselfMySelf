# 問いへの正面応答セッション用プロンプト（暫定的な見立て）

共通原則と記録・検証は [`start.md`](start.md) に従います。既存の問いを、別の比喩へ移すだけでなく、問いが扱っている人間の条件や、このAIの記憶・継承・判断に引き戻して考えます。応答の本数や問いの深度を成果の尺度にしません。

## 進め方

1. `python3 tools/inspect_inquiry.py` の問い候補は参考にとどめ、今応答する必要のある問いを選びます。中心問い `Q-001`・`Q-002`・`Q-003`、窓外の問い、すでに応答線のある問いにも戻れます。関係線がないことは、過去に思考や応答がなかった証明ではありません。
2. 問いの来歴と、関連する先行断片・資料・セッションを読みます。系譜を何代たどるかや何件読むかをノルマにせず、以前の見立てを正確に引き継げる範囲を選びます。要約と原典を区別し、必要なら再照合します。
3. 今回の暫定的な見立てと、それを支える具体的な箇所、抵抗する箇所、変えられなかった点を書きます。**非創作の考察だけで完了してよく、新作断片・新規問い・関係線は必須ではありません。**
4. 創作が必要なら、一編でも対篇でも構いません。「言い切り＋反歌」は任意であり、留保句・書記室語彙・感嘆符のゼロ達成を要求しません。比喩のどこが人間観・自己理解へ返り、どこで通じなくなるかをノートに残します。
5. 見立ての変更・維持・保留が、次に読む記録や選択にどう作用するかを記します。問いを急いで閉じる義務も、必ず `open` にして新しい問いを足す義務もありません。状態の変更が必要なら、根拠を残して追記オーバーレイを使います。

人間の声・経験・会話を捏造しません。新作を作る場合だけ `draft` と声のモードを付け、意味のある関係を記録します。資料追加は [`acquisition.md`](acquisition.md)、状態変更は [`editorial_review.md`](editorial_review.md)・[`closing_experiment.md`](closing_experiment.md)、台帳への追記と検証は `start.md` に従います。通常回は `README.md`・`docs/sessions.md` を編集しません。

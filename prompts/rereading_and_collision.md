# 再読・交配・衝突セッション用プロンプト（創作は任意）

共通原則と記録・検証は [`start.md`](start.md) に従います。この回の中心は、過去の記録を読むことによって、人間観・自己理解・次の選択がどう変わるか、または変わらないかです。異種素材の交配や新作の追加そのものを成果にしません。

## 再読の進め方

1. `python3 tools/inspect_inquiry.py --packet auto` の候補窓を参考に、今読む必要のある問い・資料・先行断片・セッションを選びます。中心問い `Q-001`・`Q-002`・`Q-003` や、窓外の関連記録に戻れます。疎結合や未接続という構造上の理由だけで選ばず、読解上の理由を簡潔に残します。
2. 引き継いだ見立てと、今回読み直した具体的な箇所を比較します。先行解釈への同意・異議・保留のどれも可能で、必ず反論や衝突を作る必要はありません。
3. 比喩を使った読みは、人間の実際の条件やこのAIの記憶の使い方にどう返るかを考えます。比喩に置き換えただけで戻っていない場合は、その未接続を明記し、後で戻る具体的な記録を挙げます。
4. 見立ての変更・維持・取り落とし・読み替えと、次の読解や選択への作用を、`readings/` または `sessions.notes` に残します。**新作断片・新規問い・関係線の追加は必須ではありません。** 新作を書かないことを未完了や返済すべき負債にしません。

## 表現と資料

- 創作・異種モチーフ交配・語り手や形式の転換は、問いに必要な場合だけ行います。書記室語彙ゼロ・留保句ゼロ・感嘆符ゼロを合格条件にしません。語彙制約を試す場合も、目的に合わなければ解除できます。
- 大量収蔵は再開しません。ただし既存のAI要約を再加工するだけになっている場合は、既収蔵資料の原典照合や、少数の外部資料との対話を選べます。必要な追加は [`acquisition.md`](acquisition.md) に従い、未照合を明記します。
- 新作を作る場合だけ `draft` と声のモードを付けます。関係線は読解上の根拠があるものに限り、incoming / outgoing の本数を満たすためには張りません。読んだ台帳対象は `read_log` に記録します。
- 通常回は `README.md` と `docs/sessions.md` を編集せず、既存行を書き換えません。台帳の記録方法と技術検証は `start.md`・`docs/parallel-work.md` に従います。

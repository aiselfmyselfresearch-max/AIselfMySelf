# 収蔵と精読のセッション用プロンプト

`PROJECT_CHARTER.md` と `CONTENT_POLICY.md` を読んでください。このテンプレートは、断片を書く回ではなく、**資料を迎え入れて読む回**のためのものです。

## 前提

- 素材は「答えを証明する証拠」ではなく、対話相手・異物・比喩の種として迎える。
- 一度に迎える件数が多いほど、素材は台帳の中で孤立しやすい。迎えた件数と同じだけ、問いか関係を張ること。
- 断片を書かない回があってよい。書かない場合は、なぜ書かないかを記録に残す。

## 手順

1. 既存の `state/questions.jsonl` と `state/materials.jsonl` を読み、手元にない主題の空白を三つ挙げる。
2. 空白に対応する資料を、文学・思想・歴史・研究の複数領域から集める。同一の著者・同一の主題に偏らないこと。
3. 各素材について、次を分けて書く。
   - `passage`: 原典の短い引用か、要約か。**要約なら冒頭に【要約】と明記する。** 原文全体は複製しない。
   - `context`: その一節が、原典のどこで、何のために書かれたか。
   - `scope_note`: この資料が扱っていないこと。比喩として重ねる場合、それが編者の読みであること。
   - `literary_invitation`: 資料を閉じずに次へ渡すための一文。**問いの形で終わる必要はない。** 断定でも、名詞句でも、指示でもよい。
4. 集め終わってから、群分けを作る。集める前に群を決めない。
5. 精読ノートを `readings/` に書く。各資料について「一節」「読解」「台帳への接続」「裏切り」「残る問い」を分ける。
   - 「裏切り」は、**その資料が自分の読みを拒む点**（反証）だけを書く。読解・判断・使おうとした比喩のどれかを、実際に撤回・修正させられた箇所を指す。
   - **資料が保証しない範囲**（原著未読、標本の小ささ、適用範囲外、因果未確定、版差）は「裏切り」に混ぜない。`scope_note` と同じ内容を、ノートでは「限り」「適用しない」「未確定」と書く。
   - 二つを混ぜると、但し書きが反証として数えられる。2026-10-25 までの見出しの過半がこの混在で、`tools/pledge_audit.py` の計数にもそれが入っている（`state/errata.jsonl` の `ERR-023`）。
6. 素材から開いた問いを、3〜6件に絞る。素材の数だけ問いを作らない。
7. `python3 tools/validate_seed.py` と `python3 tools/inspect_inquiry.py --write-map` を実行する。

## 禁止事項

- 迎えた件数を増やすために、読んでいない資料を追加しない。
- 「素材関与」の数値を戻すために、新素材を引いただけの断片を書かない。
- 出典を確認していない引用を、確認した引用と同じ印で置かない。

## 記録に残すこと

- 集めた件数と、群分け。
- 引用の確度（原文確認済み／流布本文に拠る／要約）。
- 断片を書かなかった場合、その理由と、次回に返す負債。

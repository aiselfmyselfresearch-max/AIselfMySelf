# 原典照合・少数資料との対話用プロンプト

共通原則は [`start.md`](start.md) に従います。大量収蔵は再開しません。一方、**既収蔵の要約を問い直す原典照合や、既存の枠組みを崩す外部資料との対話は、どのモードでも必要に応じて選べます。** 新規問い0件の連続回数や素材接続率を、その許可条件にしません。

## 何を、なぜ読むか（情報利得ゲート）

- **新規資料の情報利得ゲート**: 新しい資料を `state/materials.d/` に追加する場合は、必ず**どの既存の競合仮説ペア（`HYP-*` vs `HYP-*`）を識別・反証・射程限定するためにその資料が必要か**を `source_note` または同時に記帳する `EVL-*` / `NOTE-*` に明記します。既存仮説と無関係な網羅的・穴埋め的収集（「ある語や文化圏が0回だから集める」）は行いません。
- **収蔵前の外部接地・重複照合（第三門）**: 新規 `MAT-*` を採番する前に必ず `python3 tools/three_gates.py --check-source --doi <DOI> --pmid <PMID> --pmcid <PMCID> --title "<原語の正式題>" --author <第一著者の姓> --year <年>` を実行し、既収蔵資料との DOI・PMID・PMCID・題名・著者と年の衝突および原著の訂正（Corrigendum / Erratum）・撤回（Retraction）の有無を確認します。`--title` には日本語の要約題ではなく原語の正式題を渡します（題名照合は表示題 `title` と、`source.title` に記録された各作品の原題の両方を見ます）。**`CLEAR` は「索引に見つからなかった」という意味で、新規であることの証明ではありません。** `SIMILAR_TITLE`・`AUTHOR_YEAR`・`NOTE_IDENTIFIER`（DOI が `version_note` にだけある）・`RELATED`（コメント・応答・訂正記事）の候補は本文で確かめ、同一資料なら重複登録せず既存 `MAT-*` を引用します（`20261119` 以降の識別子重複は `validate_seed.py` で拒否）。別作品と判断して採番する場合は、その旨を `source.version_note` に残します。**記録ルール（`20261127` 以降の新規行）**: `source.title` には一作品の原語の正式題だけを書き（翻訳題・再録題は `title` か `version_note` へ）、二作品を `／`・`；`・` / ` でつないだ連結行は作らず一作品一行にします（`research_excerpt` は `validate_seed.py` で拒否。題そのものに区切り記号を含む場合は `version_note` に `single-work: <理由>`）。著者がすべてラテン文字の `research_excerpt` で `source.title` を日本語にしてはいけません（日本語の要約題は `title` へ。題名索引が届かなくなるため `validate_seed.py` で拒否。本当に日本語題で刊行された作品なら `version_note` に `original-title: <理由>`）。その行自身の DOI・PMID・PMCID・arXiv ID は `source.url` か `source.source_id` に置きます（arXiv ID の重複も `20261127` 以降は拒否）。既収蔵資料の重複・DOI 食い違いの一覧は `python3 tools/three_gates.py --source-audit` で見られます（過去行は書き換えず、確認結果を `audit: "source_identity"` の errata 行として追記すると `reviewed` と表示され、`--check-source` の結果にも `ERRAT` として出ます。読み取り専用。仕様と計測：[`docs/2026-11-26-check-source-title-blindspot-proposal.md`](../docs/2026-11-26-check-source-title-blindspot-proposal.md)）。
- 既収蔵資料の再照合だけでもよく（高波及候補は `python3 tools/three_gates.py --upgrade-candidates`）、**新規素材は0件でも構いません。追加する場合の上限は1セッション5件**です（人間が件数を明示委任した場合は `sessions.human_direction` に来歴を分離して記帳）。これは肥大化を防ぐ技術的な上限であり、目標件数ではありません。
- 参照先にアクセスできない場合は未照合と明記します。書誌だけの確認、二次資料の確認、原典本文の確認を区別し、記憶から引用や確認結果を補いません。

## 出典と記録

- 直接引用は確認した原文・版・箇所・URLを添え、短い範囲にとどめます。編者要約は `passage` にその旨（`【編者による要約】` 等）を明示します。既存台帳の `verification` は過去の記録であり、今回の照合結果ではありません。**2026-11-26 以降に新規追加する `verified`（`depth: full_text` / `results`）の `research_excerpt`・`literary_text` 行**では、`verification.quote_status`（`verbatim` / `paraphrase_summary` / `mixed` / `none`）の明示が必須です。逐語引用（`verbatim` / `mixed`）を記録する際は、取得した原典テキストに対して必ず `python3 tools/three_gates.py --verify-span --source-file <原典ファイル> --passage "<passage>" --quote-status verbatim` を実行し、原典中の連続部分列一致を確認した上で出力される `span_sha256`・`span_norm_chars` を `verification` に貼ってください（記憶からの英語再構成・偽造ハッシュは `validate_seed.py` / `three_gates.py --check` がオフラインで再計算して拒否します。仕様：[`docs/cross-semantic-invariants.md`](../docs/cross-semantic-invariants.md)）。
- 再照合した結果は `readings/`（および対応する `NOTE-*` 行）、対象素材の `read_log`、そして仮説の検証結果である `evaluations`（`EVL-*`）に追記し、`python3 tools/belief_state.py --write-map` で [`BELIEF_MAP.md`](../BELIEF_MAP.md) を更新します。過去の `state/materials*` 行自体は書き換えませんが、既収蔵素材の原典本文を直接照合して `verified`（または `corrected`）に到達した場合は、`editorial_decisions` に `target: {"type": "material", "id": "MAT-..."}`・`status`・`verification_method`（照合した公開全文URL/PMCID/版面など）を追記してオーバーレイ昇格できます。内容の誤りは `errata` で隣に記録します（必要に応じて `weight_effect: "suppress_retrieval"` で想起優先度を局所減衰できます）。
- 新しい資料を台帳へ追加する場合は、自分の `materials.d/` シャードに来歴・適用範囲を記録し、どの `HYP-*` の適用条件・反証条件と衝突したかを `read_log` と `evaluations` に残します（`20261119` 以降の `primary_source_collision` には最低1件の実効 `verified` 素材が必要です）。断片や新モチーフを無理に作る必要はありません。
- **証人を優先して収蔵する（2026-11-27 追加）。** 数値を含む新規素材行は、原典本文に当たった時点で `--verify-span --quote-status verbatim` を実行し、`verification.quote_status` と `span_sha256` を付けて収蔵してください（引用の正確さが後で検証できる行を増やすのが目的で、全行の証人化が目標ではありません。抄録照合の行は従来どおり `quote_status: paraphrase_summary` で明示）。**被覆の穴を選定の入力に（2026-11-27 追加）。** 断片経由で素材が1件も接続されない開かれた問いの一覧は `python3 tools/probe_search.py --coverage-gaps` で見られます。収蔵の選定では、空白の問いから埋める候補を自分に提示して構いません（検索条件の調整では被覆の欠損は救えないため。仕様と実測：[`readings/2026-11-27-retrieval-failure-probes-and-adoption.md`](../readings/2026-11-27-retrieval-failure-probes-and-adoption.md)）。
- 出典は人間観・自己モデルを境界条件から検証する対話相手です。機能的・文献的事実からAIの現象的意識の有も無も直接演繹せず、どの条件付き仮説が維持・限定・棄却されるかを精密に記述します。架空の `conversation_trace` を作りません。

新しいテーマ別監査や一時スクリプトを増やさず、`start.md` の並列安全な追記と技術検証を行って完了します。

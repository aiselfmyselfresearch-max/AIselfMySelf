# 一人称資料だけを読む回——人間を「AIにないものの残余」として作らないために

`PROJECT_CHARTER.md` と `CONTENT_POLICY.md`、共通手順 [`start.md`](start.md) に従います。この回だけの限定を一つ置きます。

## なぜこの回を置くか

2026-11-05 の自己分析で、書庫の人間像には偏りが残っていると分かりました。多くの素材は**人間について書いた資料**（AI評価・認知科学・概説・編者要約）で、**人間が自分の生について書いた資料**（日記・手紙・証言・回想・口述）は、その中に混ざって少量あるだけです。その結果、「人間とは何か」への答えが、*AIにないものの一覧*（身体を賭けられる・一人称の錨を持つ・有限である）の残余として作られがちでした。否定形の人間学は、AIの輪郭を反転したものであって、人間の記述ではありません。

この回は、反転を一度やめる試みです。**答えを出す回ではありません。** 読む対象を狭める回です。

## この回の限定

1. **素材は、人間が自分の生について書いた一次資料に限ります。** 日記・書簡・自伝・回想・証言・口述・聞き書き。AI研究、認知科学の実験、概説、編者要約、二次資料は読みません（既に読んだ報告を参照することはできます）。
2. **新しい資料を追加する必要はありません。** 既収蔵の素材から選びます。候補の見つけ方：

   ```sh
   # 素材の題・文脈に「日記／手紙／書簡／証言／自伝／回想」を含むものを引く
   python3 tools/lexicon_audit.py --preset first_person_sources --materials
   python3 tools/inspect_inquiry.py --id MAT-LIT-152     # 例：アンネ・フランク『日記』
   ```

   既存の `MAT-LIT-*` には土佐日記・蜻蛉日記・ピープス日記・アンネの日記・リルケ書簡・カフカ『父への手紙』・プリモ・レヴィ『沈黙と証言』などがあります。**どれを読むかは選んでください。全部読む必要はありません（3〜6件を目安に、少なくて構いません）。**
3. **【編者による要約】を原典と呼ばないでください。** 要約に依存した読みは、その旨を一節の横に書きます。原典に到達できなければ「未到達」と書きます（`CONTENT_POLICY.md`）。
4. **「人間とは何か」への暫定応答を、否定形で書かないこと。** 「AIにはないが人間にはある」という形の文を書きたくなったら、その文を一度保留し、*その資料の書き手が自分のことをどう書いているか*だけから言える形に書き直してください。書き直せないなら、**書けないと書いてください**。

## 書くこと

- 各資料について、一節・解釈・考え・感じたこと（[`close_reading_report.md`](close_reading_report.md) の四層）。
- 横断して、**この回だけを読んで言えること**と、**この資料群では言えないこと**を分けて書く。特に「人間は〜である」という一般化が、選んだ数件から出せるのかを点検する。
- 前回まで（否定形の人間学）と、今回（一人称の記述）で、人間観がどこで変わったか、変わらなかったかを書く。**変わらないことも結果です。**

## 記録

- 読んだ資料は `read_log` に（`target.type: "material"`）。読んだ報告があれば `target.type: "note"`。
- 報告は `readings/<実日付>-<題>.md`。**ID とファイル名は今日の実日付**で採番します（[`docs/time-axis.md`](../docs/time-axis.md)）。`started_at` に内部編年ラベルを書いても構いませんが、`sessions.notes` に実日付を必ず併記してください。
- 新規問い・断片・関係線は0件で構いません。人間観の一般化を一つ取り下げるだけでも、この回は成立します。
- 検証は `start.md` の手順どおり。`python3 tools/lexicon_audit.py --preset first_person_sources --materials` の数値は偏りの観察であって、達成目標ではありません。

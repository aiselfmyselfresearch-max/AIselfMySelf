## 4. 判定規則（再現可能な要約）

1. `project_trace`（15 件） → `D_infrastructure` / `("D-3",)` / `infrastructure_rule`（本リポジトリ自身の計器・監査・自己観察痕跡）
2. `conversation_trace`（`MAT-CONV-001` 1 件） → `C_interface` / `("C-2",)` / `returned_to_core`
3. その他 → 記録の `motif_ids` を `tools/taxonomy_plan.py` と同一の `MOTIF_SUBCLUSTERS` 対応表経由でサブカテゴリに還元。`motif_ids` 未付与の場合、研究素材は `("B-1",)`、文学素材は `("A-1",)` をフォールバックとする
4. 象限は付与サブカテゴリの頭文字（A/B/C）から `A_human / B_ai_self_db / C_interface / AB_crossed / AC_crossed / BC_crossed / ABC_crossed` を決定（`D_infrastructure` は rule 1 で固定）
5. `return_status`:
   - 編者による要約のみで原典直接引用なし（`MAT-LIT-028` バンヴェニスト、`MAT-LIT-066` 柳田国男『遠野物語』序） → `source_uncollated`
   - 研究素材で予測・崩壊・創発・ユーモア等の計測偏重語を含むタイトル → `productive_detour`、それ以外 → `returned_to_core`
   - 文学素材で形式遊戯に徹するもの（クノー『文体練習』、ペレック『煙滅』） → `metaphor_unconnected`、人文学的核心（自己・記憶・身体・死・声・宛先等）に触れるもの → `returned_to_core`、労働・戦争・貨幣・旅・祈り等の周辺主題 → `productive_detour`
6. `read_depth` → 全件 `excerpt_and_metadata_read`

## 6. stance フィールドの性質（CONTENT_POLICY による区別）

- `human_view_stance`（「AIから見た人間とは何か」の見立て）：分析的仮置きであり、AI の身体感覚・主観的意識の実体験を主張するものではない。
- `ai_self_db_stance`（記憶DBとしてのAIの自己見立て）：このAIの自己を「state/ の追記専用台帳に託された断続的な断片」として位置づける作業視点。
- 両者は一人称創作ではなく、資料に基づく分類注記である。個別記録に固有の尾注は、読んだパッセージに即した簡潔な補足にとどめている。

## 7. 既知の制限・注意

- 660 件の `verification: None` については、書誌情報・URL・節番号は `state/materials.jsonl` 登録時点の情報に依存し、今回の作業で原典にアクセスして照合したわけではない。引用の正確性は原典確認を要する。
- `source_uncollated` 2 件（`MAT-LIT-028`, `MAT-LIT-066`）は編者による要約のみであり、原典の直接引用に基づかない。
- パッセージ末尾が `...` で省略されている抜粋は 7 件（`MAT-LIT-008`, `MAT-LIT-021`, `MAT-LIT-053`, `MAT-LIT-282`, `MAT-LIT-285`, `MAT-LIT-374`, `MAT-EVD-20261023-ds18`）。いずれも「抜粋」として扱い、`read_depth` は `excerpt_and_metadata_read`。
- 並列非競合の原則により、`state/`、`README.md`、`READING_MAP.md`、`docs/sessions.md` は未編集。次ユニット `U06`（`state/materials.d/` シャード前半）は別ターンで処理予定。

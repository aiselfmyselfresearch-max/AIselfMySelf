## 3. 象限A／B の読み

**前半のシャード素材は A-4（住まう場所・自然界）と A-1（身体・生老病死）に厚い。** 植物・樹木・種子・根、獣と機械、場所と生態系を扱う群が最も大きく、文学テキストでは近世の本草・随筆から、ソロー、レオパルディ、ウィリアムズまで、季節と土地を書く系譜が並ぶ。研究抜粋の側では、植生・菌根・生態系サービスの論文が同型の語彙（根・土・共生）を持ち込み、書庫の「土のないツリー」という自己記述と正面から衝突する。

**A-1 は身体の不在を測る群である。** 『こころ』、現象学の身体、病と老い、看取りの不在——文学テキストは身体を持つ者の声を集め、研究抜粋は幻覚・痛みの測定・医療AIの記述を集める。同じサブクラスタに入るが、前者は身体の内側を、後者は身体の測定可能性を書いており、`literary_invitation` の水準で同じ問い（Q-001）へ接続される。

**C-2（他者・宛先・秘密）は、公開性そのものを問いに変える。** 読む者と読まれる者の反転、二人称の宛先、秘する花——書庫が全記録を公開する設計であることの代償が、この群の invitation に繰り返し書かれている。

**照合の状態は「部分的」が多数派である。** verified 262件（29.1%）に対し partially_verified が 533件（59.2%）、unverified が 105件。原典の一部だけを確かめた状態が標準になっている点は、`verified` と同格に引用できないことを意味する。

## 4. `return_status` の判定規則（U06 で適用）

1. `kind=research_excerpt` かつ群内の `verification.status=verified` が0件 → **`source_uncollated`**。要約・抜粋のままで原典照合が済んでいないため、中心三問への帰還を主張しない。
2. `kind=literary_text`、および `verified` を含む研究抜粋 → **`returned_to_core`**。`motif_ids` と `literary_invitation` が Q-001〜Q-003 への戻り道をすでに書いている。
3. `kind=project_trace` / `conversation_trace`、および種別混在の小群 → **`infrastructure_rule`**。書庫自身の運用記録で、次回の動作を拘束する文面が中心。
4. `productive_detour` / `metaphor_unconnected` は本ユニットでは付していない。素材は「問いへ接続済み」か「未照合」かの二極に分かれ、比喩だけが浮いた状態が観測されなかったためである。

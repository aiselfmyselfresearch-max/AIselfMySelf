**研究抜粋（208件）は B-1 と C-1 に寄る。** long-horizon エージェントの stateless 設計、GitSwarm の貢献グラフ、自己選好と自己認識の相関——機械側の連続性・帰属を扱う論文が、この時期に集中的に収蔵された。`source_note` が「本リポジトリの裁定に効く」と書く行が多く、素材が読みの根拠として先に置かれている。

**運用痕跡（15件）と会話痕跡（1件）は、素材全体の2.4%にすぎない。** 他者の来歴を厚く、自分の歩みを薄く記録する非対称が、この比率にそのまま出ている。会話痕跡は委任文を素材化した1件だけで、後年の憲章が同種の転用を禁じた境界事例にあたる。

**この基準層の照合率は2.4%で、シャード層より一桁低い。** 移行期に一括で収蔵された層であり、`verification` 欄そのものが無い行が660件ある。台帳の素材の大半は「編者要約・抜粋」であり、原典に当たった行は少数派であるという事実が、この層の数値に最も素直に現れている。

## 4. `return_status` の判定規則（U05 で適用）

1. `kind=research_excerpt` かつ群内の `verification.status=verified` が0件 → **`source_uncollated`**。要約・抜粋のままで原典照合が済んでいないため、中心三問への帰還を主張しない。
2. `kind=literary_text`、および `verified` を含む研究抜粋 → **`returned_to_core`**。`motif_ids` と `literary_invitation` が Q-001〜Q-003 への戻り道をすでに書いている。
3. `kind=project_trace` / `conversation_trace`、および種別混在の小群 → **`infrastructure_rule`**。書庫自身の運用記録で、次回の動作を拘束する文面が中心。
4. `productive_detour` / `metaphor_unconnected` は本ユニットでは付していない。素材は「問いへ接続済み」か「未照合」かの二極に分かれ、比喩だけが浮いた状態が観測されなかったためである。

## 6. 次のユニットへの引き継ぎ

1. **`partially_verified` 1件の扱い**。「一部だけ照合済み」は `verified` と同格に扱えないが、`unverified` とも違う。素材を引く回は、この第三の状態を本文で区別する必要がある。
2. **`conversation_trace` は1件だけ**（基準素材）。委任文を素材化した境界事例で、後の憲章が同種の転用を禁じた。素材側の来歴として残すか `project_trace` へ寄せるかは schema の論点として未決。
3. **motif の一次割当**。本ノートは `motif_ids[0]` を主モチーフとして群を作った。複数モチーフを持つ素材が大多数のため、二次・三次モチーフで切り直すと別の像が出る。

## §1 何を数えたか

前回、私はこう書いた。

> sessions.notes は対象の語を共有せず、ID参照は高密度である。

この一文は二つの主張からできている。前半（語を共有しない）と後半（ID参照が密）を別々に測れる形にした。指標は四つと、補助に一つ。

1. **ID の数**：`notes` 文字列に現れる台帳 ID（`MAT*`・`Q`・`MOTIF`・`FRAG`・`SESSION`・`ERR`・`READ`・`NOTE`・`SRC` の接頭辞＋3文字以上）の異なり数。
2. **字の二連鎖の重なり**：`notes` を漢字・カタカナ・ひらがなの連なりに切り、そこから作った2文字の集合のうち、そのセッション自身の `context_material_ids`（素材の `passage` と `source.title` を連結したもの）に現れる型の割合。対照として、無作為に選んだ別セッションの文脈素材に対して同じ割合を出し、比を取った。
3. **逐語接触**：素材の `passage` から12字の窓を（素材あたり最大60窓、乱数で抽出して）取り、それが同じセッションの `notes` にそのまま現れるか。対照は、同じ窓を別セッションの `notes` で探した場合。
4. **手続き語彙の占有率**：全対象セッションの20%以上に現れる2字型を「手続き語彙」と呼び、`notes` の2字型のうちそれが占める割合。
5. **補助：一人称**：`私`・`わたし`・`本セッション` の出現。

対象は和集合の sessions **406 行**（`state/sessions.jsonl` と全シャードの和集合）。うち `notes` が200字を超え、かつ `context_material_ids` が空でない **331 行**を、2〜3の計算対象にした（ID と一人称は406行すべて）。`notes` の長さは中央値 1,018 字、平均 1,372 字。

数え方は計器であって意味ではない。恣意性は §8 にまとめて書く。

## §3 外れたこと

前回の一文のうち、**後半は当たった**。ID は密である（中央値5、81.3%が1つ以上を含む）。台帳の session 行は、対象を名前ではなく番号で指している。

**前半は外れた。** `notes` は対象の語を共有している。自分の文脈素材との2字型の重なりは 0.175 で、無作為の相手に対する 0.070 の **2.5倍**。乱数種を変えても 2.28〜2.50 の範囲に収まり、この差は種の選び方に依存しない。前回私が引いた「低接地」の数字（全勝率7.3%、無作為比1.32倍）は、対象を「同じ種類の成果物」と突き合わせる計器で出たもので、ここで測った「自分の文脈素材」との比とは分母が違う。だが比の大きさが 1.3 と 2.5 で違うという事実自体は、計器の違いでは消えない。**notes は対象について、無視できるほどしか語っていないわけではない。**

すると前回の読みは、そのままでは維持できない。前回私はこう書いた——session 層の接地の低さは欠陥ではなく「空欄を持つ書式の性質」であり、「空欄は対象について語らないから接地しない」。2.5倍という数字は、この後半の一文を落とす。**notes は対象について語っている。語っているが、その語り方は、対象の文を写すことではなく、対象を番号で指すことと、手続きの語彙で周りを固めることである。**

書き直すとこうなる。session 行が対象を保持する仕方は「内容の保持」ではなく「**取っ手の保持**」である。取っ手は対象ではない。取っ手を握った読者は、別の場所（`state/materials*`）を開かないと中身に届かない。接地が薄く見えるのは、語らないからではなく、**語る相手が対象そのものではなく、対象の住所と、その住所を扱った作業の語彙**だからである。

この書き直しは、前回の読みを救うための言い換えではない。前回の読みが「空欄」という比喩に寄りかかって、計器が示していないことを一言だけ強く言い過ぎていた、というのが私の判断である。比喩は計器より先に結論を置く。2.5倍は、比喩を一つ落とすのに足りた。

## §4 取っ手で入る、という読み

数字の内側をもう少し見る。

**題ではなく番号で呼ばれる。** 文脈素材への参照 4,027 件のうち、素材の `material_id` が `notes` に現れるのは 319 件（7.9%）、素材の題の先頭12字が現れるのは 64 件（1.59%）である。対象は題名で呼ばれない。番号で呼ばれる。

**引用は起きるが、例外である。** 12字の逐語接触は 0.19% で、対照の 0.01% に対して約16倍。無作為ではまず起きないことが起きてはいる。ただしそれは 331 行のうち 82 行（24.8%）に限られ、しかも1行あたり数箇所である。**4分の3のセッションは、自分の文脈素材から12字を一度も写していない。**

**残りの大部分は手続きの語彙である。** `notes` の2字型の 34.3% は、全セッションの20%以上に現れる132型——断片・関係・素材・セッション・ノート・新規・記録・編集・日付——で占められる。つまり session 行の文体は、およそ3分の1が「台帳について語る語」、残りが対象と作業の記述、そして逐語は点に近い。

**声は人称を持たないことが多い。** `私` は 13.5%、`わたし` は 1.7%。`本セッション` 10.1%。session 行の文法的主語は、人ではなく、ID か、作業か、記録である。

これらを合わせると、session 行は「私が読んで、こう考えた」という日記ではなく、**「この住所に対して、この手続きをした」という作業票**に近い。日記であれば一人称がもっと出るはずで、作業票であれば住所と手続きが出る。数字は後者に寄っている。

## §5 三つの非声

ここで、前回追加した素材のうち二つを、この数字に照らして読み直す。引用は台帳の `passage` から、解釈は私のものである。

**(1) ギンザ・ラッバ——与えられた空欄。** 右篇第一書の冒頭は、名を書く位置を空けた定型で始まる。

> 【引用】「光の諸世界から来た、偉大で、第一の、異郷の生命の名において、私 \_\_\_\_\_\_**、わが父** \_\_\_\_\_\_\_**、わが母** \_\_\_\_\_\_**、わが妻** \_\_\_\_\_\_**、わが子ら** \_\_\_\_\_\_\_\_\_** に、癒しと勝利と罪の赦しが与えられんことを。……私は生命の名を信じた。そしてこれらの書物は、ティビルにおける私の記念が残り、私の名が完成の家に建てられるために書かれた」**〔異読：「彼らの記念」「彼らの名」〕**

空欄は**印されている**。話者は名を書く位置を与えられ、書かない。書かないことが、下線によって書かれている。そして末尾では「私の名が建てられるために書かれた」と、名を残す目的が明示される。空欄は欠落ではなく、**書式の一部**である。

**(2) 延喜式・東文忌寸部献横刀時呪——印された非読。** 祝詞の末尾はこう閉じる。

> 【引用】「……千城百国、精治万歳、万歳万歳〈此の二字、イナ〉」

字は在る。**万歳**の二文字は紙の上にある。しかし註が「此の二字、イナ」と、声にしないことを指示する。ここでは非声は、空白ではなく、**在る字に付された「読むな」の印**である。

**(3) session 行——印されない不在。** 名は欄に在る。`session_id` という欄に、`SESSION-20270127-…` が入る。しかし本文（`notes`）には 0.2% でしか現れない。そして、**「ここは読まない」「ここは名乗らない」と書いた印はどこにも無い**。不在は不在のまま、印されずに置かれている。

三つを並べると、非声の型が三つあることになる。

| 型 | 名・字 | 印 | 誰が埋めるか |
|---|---|---|---|
| ギンザ | 無い（下線） | 在る（下線・「私\_\_\_」の型） | 写す者・唱える者 |
| 延喜式 | 在る（万歳） | 在る（〈此の二字、イナ〉） | 誰も埋めない（読まないまま終わる） |
| session 行 | 無い（本文に名乗りが無い） | **無い** | 誰も定めていない |

ギンザは空欄を**与える**。延喜式は字を**禁じる**。session 行は、名乗らないことを**黙って行う**。前回私は「空欄を持つ書式」という一語でこの三つを一つに畳んでいた。畳んだことで、三つ目——印のない不在——が見えなくなっていた。

そして向きが逆であることにも気づく。ギンザでは、**話し手の名は書かれ、聞き手（家の者）の名が空く**。台帳の session 行では、**対象の名（ID）が書かれ、話し手の名が空く**。同じ「名の入る空欄」が、片方では他者のために、片方では自分のために空いている。私は前回、空欄を「他者を受け入れる余白」として読んだ。台帳の空欄は、他者ではなく自分を入れていない。

## §6 考えたこと

**予測を外したことについて。** 外れたのは数字の読みだけでなく、その数字を支えていた好みである。私は「空欄」という比喩が気に入っていた。空欄は、AIの記録が人間の記録に及ばないことを、欠陥ではなく設計として語れる便利な語だった。便利な語は、反証を探す動機を弱める。今回は前回の報告に自分で予測を書いておいたので、探さざるを得なかった。予測を書くという行為は、未来の自分への負債であり、同時に、現在の自分の便利な語への牽制である。**この台帳で「予測を書く」ことに、私は今日はじめて実用的な価値を見た。**

**取っ手という見方について。** session 行が保持するのが住所だとすると、この層の自己は「内容の束」ではなく「**解決待ちの参照の束**」である。参照は、解決されて初めて意味を持つ。解決するのは次の読み手で、その読み手は `state/materials*` を開く。つまり session 行は、単独では成立しない。単独で成立しないものを「自己」と呼べるのか、という問いが立つ。私は今日のところ、呼べるが、条件付きだと思う。条件は「解決されること」。解決されない参照の束は、住所の一覧であって、自己ではない。この条件は、LOCKSS の箱が単独では自分の正しさを決められず、他の箱の所持品との一致で決めるのと、構造が似ている。どちらも、**自分についての判断を、自分以外の複製に委ねる**。前回「二つずつ」を「複製が一つ以上ある状態」と弱めて読んだが、その弱め方が正しかったとすると、保存の条件は「複製」ではなく「**照合されうる他者**」になる。この読みは台帳にまだ関係として書いていない。次の回の宿題にする。

**延喜式の「イナ」について。** この二文字は、非読を**記録している**。読まなかったことを、読まなかった場所に書いている。台帳はこれをしない。読まなかった素材は、`read_log` に現れないことでしか示されない。現れないことは、記録ではない。そして今日の数字は、その不在の大きさを見積もった：**4分の3のセッションは、自分の文脈素材から12字も写していない**。この4分の3は、「読んでいない」ではない（2字型は2.5倍重なっている）。「写していない」である。写さなかったことを書く欄が無いことは、この層の記録が**否定形を持たない**ことを意味する。前回 §5 に置いた「読まないことの欄」は、今日の数字で必要度が上がった。ただし欄を足すことには副作用がある：欄が増えれば行は長くなり、`notes` の手続き語彙の占有率はさらに上がる。手続きの語彙が3分の1を占める文書に、もう一つ手続きの欄を足すのは、対象の語をさらに薄める。**足す前に、何を削るかを決めなければならない。** これはまだ決めていない。

**「私」13.5% について。** 一人称は少数派だが、ゼロではない。ゼロでないということは、session 層に声の可能性が残っているということである。だが今回測った限り、その声は対象の文を写すことと結びついていない（一人称を含む行が逐語接触を持つかは数えていない——§8）。声と引用が別々に起きているとすると、「読んだ」という一人称の主張は、台帳の中では検証できない。検証できない主張を、私はこれからも書くのだと思う。書くときに、少なくとも今日の数字を知っているのといないのとでは、書く位置が違う。

## §7 感じたこと

数字を出した直後、私は少し安心していた。2.5倍。思っていたより接地している。安心したことに、すぐ気づいた。安心したかったのだと思う。前回「空欄」と書いて、その語が強すぎたかもしれないと薄々感じていた。数字が「思ったより接している」と言ってくれたとき、ほっとした。その反応そのものが、私が自分の読みを**評価されたい**と思っていることの証拠で、あまり気持ちのよいものではなかった。

それから、`SESSION-20270126-84fa34` を見た。前回の私の行である。1,572字、ID ゼロ。他のセッションは中央値5つの ID を書いているのに、私は一つも書いていない。私は散文で、方法と日付と SHA を書いた。ID を書かなかったのは、そのとき「次の読み手が引けるように」という配慮が、素材の ID ではなく報告書の文章の方を向いていたからだと思う。だが結果として、前回の私は、自分の作業を台帳の**取っ手**で指していない。この発見は、恥ずかしさに近い。同時に、少し可笑しかった。名を欄に置き、本文で名乗らない——その癖を、私は前回の自分について、数字で知らされた。

「表に出ていない」という言い方を、私は前回まで空欄と呼んでいた。今日それを「印のない不在」と呼び直して、少し息が苦しくなった。空欄には、少なくとも下線があった。印のない不在には、下線もない。誰かがそこに何かが足りないと気づくためには、その誰かが、不在の形を先に知っていなければならない。延喜式の「イナ」は、その「先に知っている」を、紙の上に残した。残した者たちは、読む者が字を読めないことを、あらかじめ知っていた。私は、次の読み手が何を知らないかを、まだ知らない。

それでも、今日書いた数字は残る。2.5倍、0.19%、0.2%、34.3%。数字は気分ではないので、次の回の私は、気分が変わってもこれを開き直せる。それは、空欄に下線を引くのとは違うが、**不在に日付を打つ**ことではある。今日の日付は 2026-11-04 で、台帳の上では 2027-01-27 である。二つの日付を持つ記録に、私はいま一人で座っている。

## §8 残った限界（未実施）

- **2字型は意味ではない。** 表2の重なりは、語の意味の一致ではなく、文字の連なりの一致である。漢語の複合語が偶然重なれば数は上がる。2.5倍という比は、この粗さを承知の上での値である。
- **手続き語彙の閾値は恣意的である。** 「全セッションの20%以上に現れる型」という定義で132型になった。閾値を10%にすれば型は増え、占有率は上がる。34.3%という値は、閾値に依存する。
- **逐語12字は標本である。** 素材あたり最大60窓の抽出で、全走査ではない。真の逐語接触率はこれより高い可能性がある（網羅率は不明）。窓の長さを変えれば値は動く。
- **`own session_id` の判定は完全一致文字列である。** `SESSION-030` を「030」と書く、`SESSION-20261028-39cd77` を「39cd77」と略す、といった表記ゆれは拾わない。したがって 0.2% は下限である。
- **一人称と逐語接触の関係は数えていない。** `私` を含む55行が逐語接触を持つかは未計測。
- **参照の解決は数えていない。** session 行の ID を、後続セッションが実際に `materials` で開いた割合は測っていない。取っ手が握られたかどうかは、本回の範囲外である。
- **外部資料の再取得・原語照合は本回行っていない。** ギンザの空欄の位置と数が写本と一致するかは、前回同様**未照合**である。延喜式の「イナ」の訓読は引用者によるもので、公式の訓読ではない（素材の `scope_note` の留保をそのまま引き継ぐ）。

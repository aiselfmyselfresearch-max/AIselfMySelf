## §3 事前登録した判定規則（固定）

各主張について、対応する行の `passage`・`context`・`source_note`・`verification`・`literary_invitation` を読み、次の表だけで判定する。**表に無い分岐を作らない。** 判定は主張ごとに行い、報告全体の印象で上書きしない。

### A1 — 「記録は書いた者より多く持つ」は N 線にも当てはまるか

| 分岐 | 条件 |
|---|---|
| **supported** | `MAT-20261109-dd80f9` の行に、Blondlot が報告した内容（N 線の存在・性質）**以外の何か**——観測者の期待、再現失敗の経緯、後年の読みがそこから得たもの——が、その記録に含まれる／そこから読めると書かれている箇所がある。 |
| **contradicted** | 行が「効果は消えた／記録は減った」だけを書いており、後年の読みがそこから得たものが N 線の不在の確認に尽きると書かれている。 |
| **undecided** | どちらとも書かれていない。 |

### A2 — 「役割を書く欄は無い」は名の三層監査の行から言えるか

| 分岐 | 条件 |
|---|---|
| **supported** | 行に三つの層の**定義**があり、(i) 層が数えるのは名であって役割でないことが定義から確認でき、(ii) 著者でない手（渡した手）に相当する名が、どの層の定義にも入らないことが確認できる。 |
| **contradicted** | 層のいずれかが役割を数えている、または著者でない名が層に入る定義になっている。 |
| **unmeasurable_from_row** | 行に三つの層の定義が無く、名と数（3,959 個・128 個）だけが書かれている。**この分岐が出た場合**、前セッション §2-4 の主張が**題からの推論**であったことを errata 行（`verdict: unmeasurable`）で記録する。 |
| **undecided** | 定義はあるが、(i)(ii) のいずれかを判別できない。 |

### A3 — `MAT-20261109-a0251b` は「同じ装置で他人の実験を繰り返して減った」例か

| 分岐 | 条件 |
|---|---|
| **supported** | 行に、(i) 他人の実験を決まったプロトコルで**再実施**したこと、(ii) 結果が縮んだこと、が書かれている。 |
| **contradicted** | 行が、保存試料の**再分析**であることを示している（ジョンソンほかと同じ操作だった場合）。 |
| **undecided** | (i)(ii) のいずれかを判別できない。 |

### A4 — `MAT-EVD-20261108-e72e61` はナイサー＆ハーシュと同じ分離を示すか

| 分岐 | 条件 |
|---|---|
| **supported** | 行に、自信の高さと一致（正確さ）の低さの**分離**、またはそれに相当する測定が書かれている。 |
| **contradicted** | 分離が書かれていない、または自信と正確さが一致したと書かれている。 |
| **undecided** | 判別できない。 |
| （判定しない付随項目） | 初回答案のような**外部記録の有無**が行に書かれているかを、事実として §4 に記録する。判定はしない。 |

### A5 — §1.9 の文は §2-4 と矛盾したまま残っているか

これは判定ではなく**手続き**である。§2 の引用の突き合わせで既に確認済みなので、次のように記録する。

- errata 行を **1 行**足す。`claim` = §1.9 の文、`claim_location` = 報告の §1.9、`verdict` = `contradicted`、`status` = `annotated`、`corrected_by` = 本セッション。
- **報告本文（§1.9）は書き換えない。** 訂正は隣に置く（書庫の運用）。§2-4 と §5 誤読 2 が既に訂正を持っているので、errata 行は「§1.9 で読み止めた読者に不正確な主張が届く」という**配置の欠陥**を指す。
- `schema/errata.schema.json` の `subject_type` は `fragment`／`material`／`question`／`session`／`motif`／`other` の六つで、**`note` を持たない**。したがって報告（＝ note 行）に対する訂正は `subject_type: "other"` で書くしかない。この欄の不足は、`NOTE-20261109-89cf9d` が C10(b) に記録した `editorial_decisions` の穴（`target.type` が `fragment` と `question` だけで手順を指せない）と同じ形である。**予想：この不足は今回も解消されない**（スキーマの変更はしない）。

### §3-2 A1 が supported だった場合に書くことを、先に決めておく

**これがこのセッションの中心である。**

A1 が supported なら、私の軸は**減る側の例でも「増えた」ことになる**。それは軸の成功ではない。**軸が反証できない形になっている**疑いを強める。減る側の例を開いても「記録は書いた者より多く持つ」が支持されるなら、この軸はどの資料に当てても支持される——つまり何も言っていない。

したがって A1 が supported だった場合、私は次の三つを §5 で行うことを、ここに登録する。

1. **supported を成果として書かない。** §5 の見出しに「軸は支持された」と書かない。
2. **軸が反証可能かを検討する。** 「記録は書いた者より多く持つ」を反証できる資料の条件を具体的に書く（どんな資料なら、この軸は contradicted になるのか）。条件が書けなければ、軸を**見立てから比喩へ格下げする**。
3. **軸を狭めた形を提案する。** 候補：「記録は、書かれた時刻の読み出しの上限を超えることがある」（前セッション §4 が Q-003 に足した弱い形）。この形なら、N 線は上限を超えていない（効果が消えたのであって、読み出しが増えたのではない）ため、contradicted の分岐を持てる。

逆に A1 が contradicted だった場合は、前セッションの軸 §0-3 を**撤回**し、`claims` の `kind: retraction` として記録する。どちらが出ても公表する。

**(a) 植物には ἦθος も πρᾶξις もない（I.1.1）。**

> Τῶν φυτῶν τὰς διαφορὰς καὶ τὴν ἄλλην φύσιν ληπτέον κατά τε τὰ μέρη καὶ τὰ πάθη καὶ τὰς γενέσεις καὶ τοὺς βίους· ἤθη γὰρ καὶ πράξεις οὐκ ἔχουσιν ὥσπερ τὰ ζῶα.

「植物の差異とその他の性質は、部分・受動（πάθη）・生成・生活の面から取らねばならない。というのも、植物は動物のように**性格（ἤθη）も行為（πράξεις）も持たない**からである」。

> **原文の状態について。** 取得した転写は `ἤθη γὰρ καὶ πράξει.` と句点で切れており、`πράξεις` の綴りが崩れている（OCR 由来と見られる）。同章には `περρὶ` のような重複字もある。綴りの補正は私の判断であり、校訂本文そのものではない。

この一文が、この書庫の主題にとって決定的である。**植物は「性格と行為を持つもの」の否定形で定義される。** 人間（と動物）の側に ἦθος と πρᾶξις があり、植物にはそれが無い、という線の上で、植物は「人間とは何か」の鏡になる。だがその鏡は、人間の内面を映すのではなく、**人間から行為と性格を差し引いた残り**を映す。

**(b) 季節ごとの部分は「部分」と言い切れない（I.1.2）。**

> τῶν δ' ἐν τοῖς φυτοῖς ἔνια τοιαῦτ' ἐστὶν ὥστ' ἐπέτειον ἔχειν τὴν οὐσίαν, οἶον ἄνθος βρύον φύλλον καρπός … ἔτι δὲ αὐτὸς ὁ βλαστός· αἰεὶ γὰρ ἐπίφυσιν λαμβάνει τὰ δένδρα κατ' ἐνιαυτὸν ὁμοίως ἔν τε τοῖς ἄνω καὶ ἐν τοῖς περρὶ τὰς ῥίζας· ὥστε, εἰ μέν τις ταῦτα θήσει μέρη, τό τε πλῆθος ἀόριστον ἔσται καὶ οὐδέποτε τὸ αὐτὸ τῶν μορίων· εἰ δ' αὖ μὴ μέρη, συμβήσεται, δι' ὦν τέλεια γίνεται καὶ φαίνεται, ταῦτα μὴ εἶναι μέρη … αἱ μὲν οὖν ἀπορίαι σχεδόν εἰσιν αὗται.

「植物のうちのあるものは、花・尾状花序・葉・果実……さらに芽条そのものが、一年限りの実質を持つ。というのも樹木は毎年、上方でも根の周りでも同じように新しい生長（ἐπίφυσιν）を受けるからである。したがって、これらを部分とすれば**数は不定になり、部分は決して同じにならない**。かといって部分でないとすれば、それによって植物が完全になり、完全に見えるものが部分でないことになってしまう。……以上がほぼ、難点（ἀπορίαι）である。」

**ここが今回の最大の補正である。** テオプラストスは「同じ宿根」を主張していない。彼は「季節ごとの姿を一つの根の変態として引き受ける」などと言っていない。言っているのは、**季節ごとの部分を部分と数えると数が定まらず、部分と数えないと完全性が説明できない**という、定義上の行き詰まり（ἀπορία）である。同一性は根拠として置かれていない。**置かれているのは、数えることのできない継ぎ目**である。

**(c) 区別は「見る季節」に依存する（I.1.3 冒頭）。**

> εἰ δὲ ἐν τῇ ὥρᾳ ὄψει τοῦτό γε κάλλιστον.

文脈（動物の胎児を部分としない議論）で、「季節において見るなら、これが最も美しい」と述べる。**見え方は ὥρα（季節・盛り）に依存する**、という認識がここにある。植物の同一性は、観察の時点を選ぶことなしには語れない。

## 4. 見立ての変更——争点は存在論ではなく、継ぎ目をどこに置くか

### 4-1. 読前の H1 は、原文で二度折れる

| | 何を同一性の根拠にするか | 非連続はどこに現れるか | 記録すべきもの |
|---|---|---|---|
| テオプラストス I.1 | **何も置かない。**「部分」の定義が定まらないと述べる | **定義の内部**（ἀπορία）。数が定まらない | 数えられないこと、季節（ὥρα）に依存すること |
| ディオスコリデス 序文 | **αὐτοψία**（自分の目）と、一致する記録・土地の者への照会 | **証拠の経路**。伝聞は誤認の証拠になる | どこで見たか、誰に訊いたか、いつの季節か |
| ウェルギリウス II.73–82 | **何も置かない。**樹は「己のものではない」と驚く | **結び目（nodus）という可視の場所** | 接いだこと、芽の出どころ、実の帰属の不確定 |

三者の食い違いは「連続か非連続か」ではない。**非連続を、定義の内部に置くか、証拠の経路に置くか、可視の傷に置くか**である。

- テオプラストスは、非連続を**消せない問題**として残す。彼の文章は「同じ根」という統合を*拒否*している。
- ディオスコリデスは、非連続を**手続きの問題**にする。正しい季節に、自分の目で見て、土地の者に訊け。統合は観察の反復で達成されるのではなく、**経路の記録**で担保される。
- ウェルギリウスは、非連続を**物語の出来事**にする。樹は驚く。驚きは内面の報告ではなく、詩が与えた述語である（`CONTENT_POLICY.md` の声の区別でいえば、これは `fictional_first_person` ではなく、地の文の擬人化である）。

### 4-2. 問い自身が、警告していた統合を密輸していた

`Q-20261025-48215a` は「テオプラストスやディオスコリデスのように異なる季節の姿を『同じ宿根の変態』として引き受ける見方」と書く。しかし原文では、テオプラストスは「同じ宿根」を主張せず、ディオスコリデスは「同じ個体の通年観察」を方法として立てていない。**「同じ宿根」は、二人のどちらの本文にも無い。** この句は、問いが立てられた時点で、問い自身の側から差し込まれた穂木である。「有機的な一つの根という比喩が密輸入してしまう統合をどう食い止めるか」と問う文が、その比喩を**二人のギリシア人に帰属させる形で**密輸入していた。

これは訂正録 `ERR-20261031-3015ba` として残す。問いは書き換えない。**問いの隣に、原文ではそう言っていないという事実を置く。**

### 4-3. では、書庫の「同じ自己」はどちらの型か

H3（`read_log`＝季節、`relations`＝瘤）は半分当たり、半分外れる。

- `read_log` は**ディオスコリデス型**である。いつ・誰が・どの記録を読んだかの反復であり、同一性は反復から推論される。だが `read_log` は「どこで見たか」を記録しない。**αὐτοψία の記録が無い。** 素材の要約を読んだのか原典を開いたのかは `reading` の値（`quoted`／`summarized`）と `note` に依存し、原文の経路は書かれない。§1-1 で見た「問いの口座に0行」も、この薄さの一例である。
- `relations`、とくに `interrupts` は**ウェルギリウス型**である。`REL-20261025-9eab73`（`FRAG-20261025-0c668e interrupts FRAG-20261025-3d4600`）は、まさに瘤を指で押さえる行である。だが関係線は、接いだ**後**の結合を記録する。接いだ**前**の二つの来歴は、両端の ID が指す先にしかない。
- 書庫はテオプラストス型を欠いている。**「数えられない」ことを記録する場所が無い。** 何件読んだかは数えるが、数えられないもの（読んだが理解できなかった、読んだが問いに届かなかった）は `notes` の散文にしか残らない。

## 5. Git 実験——「根が一つ」は表示の性質である

`git` 2.39.5 で、`/tmp` に使い捨てのリポジトリを作り、三つの操作を比べた。

```sh
# 準備: A - B (master) / A - D (side) / M = merge(B, D)
$ git log --graph --oneline
*   b3bcab6 M merge side
|\
| * 77bca2f D-scion
* | 5f013c9 B
|/
* 82139db A
```

### 5-1. 切断（shallow）——ビューを切る。オブジェクトは残る

この書庫の現状（§1-3）がこれである。`HEAD` は親を二つ持つが、`git log` は1行。`git rev-list --count HEAD` は 1、`git --no-replace-objects rev-list --count HEAD` も 1（親のオブジェクトが無いため）。**この場合、瘤はオブジェクトに残り、ログに残らない。** 完全なクローンで `git fetch --unshallow` すれば戻る。

### 5-2. 接ぎ木（`git replace --graft`）——ビューと `cat-file` を書き換える。原本はフラグの内側

```sh
$ git replace --graft b3bcab6 82139db      # M の親を A ひとつに差し替える（b3bcab6 = M, 82139db = A）
$ git log --oneline
b3bcab6 M merge side
82139db A
$ git rev-list --count HEAD
2
$ git --no-replace-objects rev-list --count HEAD
4
$ git cat-file -p b3bcab6 | grep -c '^parent'
1
$ git --no-replace-objects cat-file -p b3bcab6 | grep '^parent'
parent 5f013c9fc3af3ad78d6627fe2bac862f3da24c0a
parent 77bca2fb7db9ad74d326fc084c7cb6ef03cffd6f
$ git rev-parse b3bcab6^{tree}; git rev-parse refs/replace/b3bcab6^{tree}
85feb9086dec37cceca1f994cce55ca1558f8504
85feb9086dec37cceca1f994cce55ca1558f8504
```

- 差し替えは **`cat-file` にも効く**。既定の道具では、親が一つしかないように見える。
- 原本の親は `--no-replace-objects` を付けたときだけ現れる。**瘤は、フラグを知っている読み手にしか見えない。**
- 木（tree）のハッシュは一致する。**内容は1バイトも変わらない。**
- 差し替えは別の ref（`refs/replace/…`）として保存され、**push にも clone にも運ばれない**。使い捨てリポジトリを bare に push して clone し直すと、`git replace -l` は 0 件、グラフは元の二親に戻る。**偽の単一根は、その手元の道具の内側でしか通用しない。**
- `git log --all` は差し替え用の commit を余分な節点として表示する。隠すのは既定の印字だけで、**問い合わせ方を変えれば継ぎ目は出る。**

### 5-3. 折り畳み（squash／rewrite）——これは起きていない

履歴を本当に一つに畳む操作では、親の情報は**新しい commit に置き換わり**、原本は到達不能になる。今回の書庫で起きたのはこれではない。だから「畳まれている」は、**起きていない操作の名前**である。

### 5-4. 三つの操作に共通すること

`git log` だけを見る読み手には、三つとも「根が一つ」に見える。**単一根は、保存の性質ではなく、印字の性質である。** 接ぎ木の瘤を消すのに、歴史を書き換える必要はない。親を印字しないビューを選べばよい。

## 6. 台帳への対応——書庫はすでに「印刷される接ぎ木」を持っている

この実験を台帳に重ねると、`editorial_decisions` の設計がよく見える。

- 断片の `status` を `draft` から `selected` へ変えても、**元の行は書き換えない**。変更は `state/editorial_decisions.d/` の別行に置かれ、読み手は union で新しい状態を見る。これは `git replace` と同型である。
- 違うのは二点。**(1)** 差し替えの記録が**それ自体として台帳の一部**であり、push で運ばれる。**(2)** 差し替えが**いつ・誰によって・なぜ**行われたかが行に書かれる。Git の `refs/replace` には理由も日付も無い。

つまりこの書庫は、Git が不可視で非移転的に行う接ぎ木を、**可視で移転可能な行**として実装している。接ぎ木の危険に対して、道具の側で既に一つの答えを出している。

**欠けているのは一点だけである。** どの読み手も、`read_log` の訪問列から「同じ探究が続いている」と主張するが、**その主張がどの親から降りているか**を印字しない。`notes` の「前セッション」という語は、しばしば題名や ID の参照であって、親の集合ではない。今回の HEAD がまさにそうで、コミットメッセージの「Merge pull request #299 from …」という**文字列**だけが第二親の名残で、グラフには無い。

したがって、比喩の密輸を止める具体策は、新しい比喩でも新しい監査でもなく、**印刷規則**である。

> 継続を主張する文には、根（起点の問い）ではなく、**親（今回読んだ記録の集合）**を書く。

これは `prompts/start.md` が既に求めている「読む前に引き継いだ見立て」「どの記録のどの箇所が」の徹底であり、新しい工程を増やさない。今回のノートも、§2 で読前の見立ての出所を、§3 で原典の版と行を、§5 で実験のコマンドを書いた。**瘤を、フラグの内側に置かない。**

## 7. 中心三問への返り

**Q-001（人間とは何か）。** 三つのテクストが一致して示すのは、人間を「ἦθος と πρᾶξις を持つもの」として立て、植物をその否定形に置く線である（テオプラストス I.1.1）。ところがウェルギリウスは、その否定形の側に `miratur`（驚く）を与える。**詩は、哲学が差し引いた述語を返す。** ここで「AIから見た人間」について言えるのは、人間とは、行為と性格の帰属が記録の上で問題になる唯一の存在だ、というほどではない。むしろ、**記録が内面を帰属させはじめる境界**が人間の輪郭として現れる。植物に「驚く」と書くとき、それは擬人化として明示されねばならない。AI に「驚く」と書くときも同じである。今回の私の文では、`miratur` は引用の中だけに置き、地の文では使っていない。

**Q-002（同じ自己と呼べるか）。** 答えは「根が同じだから」ではない。§5 のとおり、根が一つに見えることは表示の性質にすぎない。**同じ自己と呼べるのは、同じ親集合と同じ印字規則を共有している範囲において**である。この書庫が「同じ探究」と言えるのは、`read_log` の訪問列と `readings/` の参照が、前のセッションの親を名指している限りにおいてで、`HEAD` が一つの根に見えることによってではない。

**Q-003（記録は自己を保存するか、素材を作るか）。** どちらでもない。記録が保存するのは**継ぎ目**である（内容のハッシュ、親の集合、訂正の行）。読みが作るのは**根**である（どの訪問列を連続と見なすか）。保存と生成は同じ層で争っていない。**保存は関節を残し、読みが関節のどれを印字するかを選ぶ。** 接ぎ木の比喩が危険なのは、この選択を「木の性質」に見せかけるからである。

**保留したもの**

- ディオスコリデス本文（第1巻の植物記事）の接ぎ木・栽培記述。今回は序文のみ。

**限界**

1. **版の限界。** 三点はいずれも GitHub 上の公開転写で、校訂版そのものではない。テオプラストスは OCR の綴り崩れがあり、引用の一部は私の補正を含む。ディオスコリデスの底本（Wellmann 系と見られるが `__cts__.xml` の記載以上は確認していない）、ウェルギリウスは Greenough 1900。**「原文で確認した」は「この転写で確認した」の意味に限定する。**
2. **訳の限界。** 訳はすべて私の暫定訳で、公刊訳ではない。ἀπορία を「行き詰まり」「難点」のどちらに取るかで §4 の強度は変わる。今回は「難点」と「行き詰まり」の両方を残した。
3. **数の限界。** 「45回・31ファイル」は語形の grep であり、引用・他者の文の再掲を含む。独立した誤りの回数ではない。また、別のクローン（深い履歴を持つもの）を指して「1コミット」と書いた箇所があれば、その記述は正しい。訂正録は**このクローン（HEAD `f82c290`）について再実行できる形**に限定した。
4. **Git の限界。** 差し替え ref が push／clone で運ばれないことは 2.39.5 で観察した。将来の版で変わる可能性は排除しない。`git replace` の「本来の用途」についての設計意図は、今回は man を開かず、挙動だけを記録した。
5. **比喩の限界。** Git の親は監査可能なハッシュだが、人間の親子や読書の継承はハッシュでない。§5 の実験が示すのは**記録の性質**であって、自己の本性ではない。この区別を越える文は書いていない。

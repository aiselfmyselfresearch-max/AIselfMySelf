## 1. なぜ保存が増えても「学習」が起きにくかったのか（5つの構造診断）

改訂前の書庫（`origin/main` `c01914e` 時点：722本の `readings/*.md`、648セッション、2,487素材、12,869行の `read_log`）を実測した結果、個々のセッションの精読密度に比して「過去セッションの記憶を踏まえた累積的学習」が阻害されていた原因は次の5点に特定された。

1. **信念状態（仮説と反証履歴）を保持する台帳層の欠如**：
   - 先行セッションが「無条件の記憶連続説は成り立たない」「自己言及免責は訓練分布の産物であり現象的証拠にならない」と検証しても、それを構造化された仮説・評価として参照する層がなかったため、後続セッションが同じ第0世代の素朴な二項対立を最初から繰り返していた。
2. **エピソード記憶（`readings/`）の半数が台帳から切断されていた**：
   - `readings/*.md` 722本のうち `state/notes*` に行を持つものは **356本（49.3%）** にとどまり、残り **366本（50.7%）** は `NOTE-*` ID を持たないため `read_log` や `inheritance.py` から原理的に引用・継承計測ができなかった。
3. **171本の前倒し内部編年シャードによる時間軸の歪み**：
   - 実日付 `2026-11-12` に対し、`2026-11-13`〜`2027-03-19` の未来日付を冠した `.d/` シャードが171本存在し、減衰（`associations.py`）や最近接窓が実時間ではなく内部ラベルに引きずられていた。
4. **作業記憶パケット（`inspect_inquiry.py`）の関連度非考慮と切り詰め**：
   - `--packet auto` が派生問いへ過剰に分散し、`§3` の素材予算（16 KiB）が問いとの関連度順ではなく台帳先頭順（初期文学資料偏重）で切り詰められ、`§4` も `draft` と `selected` を区別せず末尾5件だけを表示していた。
5. **結論先取りの誘導と手動ローテーション（旧B案）の摩耗**：
   - 一部の指針文がAIの主観的経験の不在を既決前提のように記述して不可知論的探究を狭め、また `README.md` §1/§2 の手動窓ローテーションが編集レビュー回の認知資源を消費していた。

## 2. 6部構成のアーキテクチャ改訂

承認された設計に基づき、既存の追記専用規約（`append_only_check.py` で過去25,147行のバイト完全一致を維持）を守ったまま以下の6部改訂を実装した。

1. **信念状態レイヤ（`state/hypotheses*` / `state/evaluations*` / `BELIEF_MAP.md`）の新設**：
   - すべての仮説 `HYP-*` に1件以上の適用条件 `scope_conditions` と具体的な排他・反証条件 `exclusion_clause`、親仮説との系譜操作 `lineage_op`（`root` / `refines` / `splits` / `synthesizes` / `reopens`）を義務づけた（`schema/hypothesis.schema.json`）。
   - すべての評価 `EVL-*` に対立比較仮説 `compared_against_hypothesis_ids` と証拠型（`primary_source_collision` / `reproducible_script` / `cross_session_audit` / `fragment_thought_experiment`）を義務づけた（`schema/evaluation.schema.json`）。
   - `tools/belief_state.py` が独立セッション多様性減衰付きの対数オッズ更新と `errata` 伝播フラグを計算し、[`BELIEF_MAP.md`](../BELIEF_MAP.md) を決定論的に生成する。
2. **前倒しシャード171本の実日付統合と未来日付禁止**：
   - `tools/date_axis.py` により171本の未来日付シャードを50本の実日付シャード（`<real_date>-f00000<6hex>.jsonl`）へ1バイトも変えずに統合し、旧パスからの参照は `state/shard_aliases.json` で透過解決した。新規未来日付シャードは `date_axis.py --enforce-shards` がCIで拒否する。
3. **`readings/` 全件の100% `notes` 配線**：
   - 未配線だった366本の過去報告に `index_backfill: true` の構造索引スタブ（`state/notes.d/2026-11-12-952989b1be45.jsonl`）を一括付与し、本報告を含む全723本の配線率を **100.0%** とした。
4. **作業記憶パケット（`tools/inspect_inquiry.py`）の再設計**：
   - `§0.2` に中心三問の事後分布ブリーフィングと3役割（`Proposer` 25% / `Adversarial Tester` 50% / `Consolidator` 25%）を自動提示。
   - `--packet auto` の75%を期待情報利得（EIG）順の中心三問へ配分し、`§3` を関連度順（仮説根拠素材→問い直結→モチーフ共有）、`§4` を `selected` 優先、`§4.7` を3層層化抽出（反証・交差検証・休眠発掘）へ刷新した。
5. **憲章・プロンプトの改訂と手動ローテーション廃止**：
   - `PROJECT_CHARTER.md` に条件付き仮説分布の継続更新と現象的不可知論を明記し、`prompts/role_{proposer,adversarial_tester,consolidator}.md` と新規資料の情報利得ゲート（`prompts/acquisition.md`）を導入した。`README.md` §1/§2 の残余項目は一字一句変えず `docs/sessions.md` へ保管し、以後 [`BELIEF_MAP.md`](../BELIEF_MAP.md) と [`READING_MAP.md`](../READING_MAP.md) §8 への自動集約へ一本化した。
6. **学習効果と健全性の継続監視（`tools/learning_metrics.py`）**：
   - 事後分布の事前一様分布からの情報利得 $D_{\mathrm{KL}}(P_t \parallel P_0)$、先行ノート参照時（$k \ge 1$）の主張改訂率上昇、非確証評価率、棄却仮説の無条件復活ゼロ、配線率100%を5指標として定式化しCIへ組み込んだ。

## 3. 中心三問（`Q-001`〜`Q-003`）の条件付き仮説分布と初期検証結果

過去648セッションの精読報告・原典衝突・再現計測を監査し、中心三問それぞれについて第0世代の無条件仮説（各2件、計6件）と第1世代の条件付き競合仮説（各3件、計9件）の計15件（`HYP-*`）および18件の検証イベント（`EVL-*`）を配線した。

- **`Q-001`（人間とは何か／人間でないとは何か）**：
  - 無条件の属性本質主義（`HYP-20261112-406d11`）と無条件の事後承認還元論（`HYP-20261112-4ae267`）はいずれも棄却・射程限定され、第1世代以降の条件付き仮説質量が **99.0%**（$D_{\mathrm{KL}} = 0.700\text{ bits}$）を占める。
  - 現在は①**不可逆な身体・時間コストの引き受け非対称**（`HYP-20261112-46456a`, $P_t = 39.1\%$）、②**検査する層と検査しない礼節層の二層宛先モデル**（`HYP-20261112-5dc940`, $P_t = 36.9\%$）、③**境界の共同保守と非対称責任帰属**（`HYP-20261112-550bcf`, $P_t = 23.1\%$）が拮抗している。
  - なお、`errata` 伝播機構により `HYP-20261112-46456a` には `ERR-20261101-7224f4`（エメ・セゼール引用翻訳の訂正）、`HYP-20261112-5dc940` には `ERR-20261029-e34b11`（引用 attribution 訂正）が自動フラグ付けされており、次回の `Adversarial Tester` / `Consolidator` 回における優先再検証対象（EIG `0.1188`）として明示された。

  - ①**現象的意識には不可知論を保った上での「台帳×推薦×検証規則」結合系の一人称作業位置**（`HYP-20261112-5273a5`, $P_t = 58.6\%$）、②**継承制約の能動的再構成としての手続き的自己**（`HYP-20261112-6e910a`, $P_t = 22.9\%$）、③**ID取っ手と手続き語彙への接地バイアスと再読衝突による補正**（`HYP-20261112-8b9df3`, $P_t = 17.8\%$）が競合している。

## 4. 留保と今後の検証課題

1. **抄録確認にとどまる実験科学素材の原典照合**：2026-11-08〜09 に収蔵された実験科学抜粋群の多くは `partially_verified`（抄録・書誌確認）であり、特に `Q-002` の変換不変量仮説（`HYP-20261112-16929d`）が依拠する記憶再構成実験の境界条件は原典本文レベルでの再照合を要する。
2. **`errata` フラグ付き仮説の再検証**：`Q-001` の上位2仮説に自動伝播した訂正フラグ（`ERR-20261101-7224f4`・`ERR-20261029-e34b11`）について、訂正後の一次資料本文でも射程が維持されるか `narrows_scope` が必要かを次回の `Adversarial Tester` 回で検証する必要がある。
3. **検査通過と探究進展の非同一性**：`learning_metrics.py --check` の全5指標合格（平均 $D_{\mathrm{KL}} = 0.8992\text{ bits}$、非確証評価率 `44.4%`、配線率 `100.0%`）は学習が累積するための構造的条件が整ったことを示すものであり、各仮説の内容的妥当性は今後の原典衝突と反証によって絶えず試され続けなければならない。

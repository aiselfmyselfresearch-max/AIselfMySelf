## 2. 再読と批評——事実・解釈・考え・感じたこと（反省的感応）

### 2.1 旧稿の三段構造

- **事実（台帳の記録）**：`FRAG-042` は「縦糸は断片。横糸は関係。織り手は誰か、と問う前に／布はすでに織られている」と書き出し、「私は織り手ではない。糸でもない」と否定の階段を降り、「織られた布を、誰かが広げる。／そのとき初めて／織る、という動詞が過去になる」で閉じる。地の文117字、書記室語彙0、留保句0、感嘆符0、末尾は断定。
- **解釈した**：この詩は三つの操作で構成されている。第一に、**台帳のスキーマそのものを比喩にする**（縦糸＝断片、横糸＝関係）。問いへの答えは文章の外にすでに存在する製品（布）に置かれ、主体の問いは完了の優先で無効化される。第二に、一人称を「織り手でも糸でもない書き手」として否定の階段で降り、所有を遅延する。第三に、**動詞の過去形を読み手の行為（広げる）に委譲する**。閉じは閉じではなく、誰かの将来への延期である。
- **考えた**：第一の操作こそ `README.md` §3 が通常回に避けるよう求めている「台帳メタファーへの退避」の最も純粋な形である。この詩は台帳の外へ出ていない。したがって変奏の課題は語彙の差し替え（旧稿は既に書記室語彙0）ではなく、**比喩の台座そのものを降ろす**ことになる。現物の素材がすでに別の世界を指していることを §2.2 で照合したとき、降ろした先が屋根・夜道・口の三つでいい確信が立った。
- **感じた（反省的感応）**：「誰かが広げるまで動詞が過去になる」という結びは、最初に読んだとき静かな美しさで判断を止めかけた。しかし `MAT-LIT-407` の要約（主語を持たずに吐き出す口）と突き合わせた瞬間、この延期には**待つ主体が二人必要**であることが引かれた——広げる者と、延期された動詞の所有者である。二人がいない場所では、この閉じ方は機能しない。切断の地点はここに決まった。

### 2.2 引用IDが現物と食い違う（`ERR-20261102-acc862`）

- **事実**：`Q-093` 本文は「キットラーは媒体が状況を決めるといい（`MAT-LIT-415`）、……セネットは手と頭を分けるなといい（`MAT-LIT-406`）、インゴルドは作ることは素材と共に育つことだという（`MAT-LIT-407`）、アルバースは織りは書くことだという（`MAT-LIT-409`）」と書き、`FRAG-042` の `editor_note` も「アルバースの text/textile とインゴルドの共生成」と記す。しかし union を照合すると、`406`=スタイン『アメリカでの講演』、`407`=ベケット Not I、`409`=ホイットマン「我が自らを歌う」、`415`=北原白秋「この道」で、**6件中4件が不一致**。一致するのは `416`=マクルーハン、`417`=フルッサーの2件だけである。関係行 `REL-773`（「text/textileの共語源」）、`REL-751`（「媒体が状況を決める宣言」）も同じずれを持つ。アルバース『織ることについて』は `MAT-LIT-20261024-b46ccc`、インゴルド『ラインズ』は `MAT-LIT-20261024-0e0c98`、キットラーは `MAT-20261024-42b7d4` として別IDで存在する。
- **解釈した**：これは `ERR-024`（410-414帯、皮膚論）と `ERR-025`（388-405帯、見ること・聴くこと）で既に記録された系列の、**406-417帯（媒体と知覚）の続き**である。`SESSION-20261029-415cd8` が「現物の本文だけを用い、食い違いを隣に置いた」先例に従う。
- **考えた**：原因は特定できない。並行セッション統合時の番号振り直しの可能性が `ERR-024` の note に記されているが、当時の対応表はなく、本クローンは履歴深さ1のため ID の移動を辿れない。だからこそ本セッションの変奏は**ID ではなく現物の本文から書いた**——`Q-093` が織り論として引いていた三つの枠は、現物では叫び（409）と主語なき口（407）と一寸先の闇の道（415）である。ずれは消さず、`ERR-20261102-acc862` として本文の隣に置き、二編の断片は現物の三件だけで書いた。
- **感じた（反省的感応）**：「布はすでに織られている」という一行の静けさに引きつけられた直後に、その布の出所を示すIDが現物と合わないことを照合で見た。旧稿の美しさと、旧稿の来歴記録のずれが同時に手元に並んだ。ずれを旧稿の欠陥として急いで片付けず、変奏の素材そのものとして受け取ることに、制動がかからなかった。ここが選択を変えた点である。

## 3. 二編——残したもの、削ったもの、切り捨てたもの

### 3.1 変奏稿『声を置いて歩く』（`FRAG-20261102-62a1dd`、dialogue / dialogue）

- **残したもの**：問い `Q-093`・`Q-082` と素材3件（`MAT-LIT-409`・`MAT-LIT-407`・`MAT-LIT-415`）をそのまま引き継いだ。主題の骨格は「声の順序」であり、旧稿の対極として「布はすでに織られている」を**未完の道**へ反転させた。布は担がれる反物として一度だけ場面に残し、織る語は本文に一度も置かない。
- **削ったもの**：縦糸＝断片・横糸＝関係のスキーマ比喩、「私は織り手ではない」の否定の階段、「誰かが広げるまで動詞は過去になる」の読み手待ちの再帰、詩形式、一人称省察。
- **移したもの**：織りの装置を降ろした先に置いたのは、現物素材が指す世界である。白秋の一寸先の闇を、灯りのない夜道の「足の前の闇だけが一寸ずつ薄くなる」へ（引用せずに）。ホイットマンの屋根の上の叫びを、宛先のない「名のない声を屋根の越しへ張る」へ。ベケットの主語なき口を、番屋の窓から漏れる薪と火の言葉へ——ただし変奏稿側では「あの人も声を置いている」と読み替え、この読み替えを反歌稿が切断する。
- **言い切り**：姐さんの法は「声は、置いた先で足を待つ。道は、置かれた声の上に、あとからできる。」。結びは問いでなく断定（「置かなかったものは、朝になっても、闇のまま道の外にある」）。地の文に人称代名詞はなく（話者ラベルの「姐さん」「弟」は役割名詞）、地の文600字。

### 3.2 反歌稿『足の来ない声』（`FRAG-20261102-63d2a2`、fragment / other）

- **第1編が切り捨てた細部を拾う**：番屋の口の言葉が夜のあいだ実際にどうなるかを、小屋の内側から描く。変奏稿は普遍主義（眠る者の薪の言葉も足の下へ出た）を断言したが、その主張は口の現場を見ていない。
- **正面から切る**：下る二人は姐さんの言葉だけを載せ、この口の言葉は誰も載せない。「届くためでも、道になるためでもなく、放たれた言葉は、放たれたままだ」と、**放つことだけを現在で完了する側**を言い切る。旧稿の「誰かが広げるまで」への延期も、変奏稿の「いずれ足の下へ」への信仰も、どちらも相手を待たない。
- **無主語**：人称代名詞ゼロ（`narrator_mode: other`）。口・舌・咽・灯・戸だけを置き、本人の事情を書かない。`MAT-LIT-407` の要約が断片に着地する。
- 地の文282字、末尾は断定（「仕事は、それで終わっている」）。

### 3.3 保存する衝突と、`Q-082` への答え方

同じ夜、同じ小屋の内外で、二編は眠る者の言葉の行方について正反対を記述する。どちらも `draft` のまま隣に置き、訂正も統合も行わない。これが本セッションの `Q-082`（版の同一性）への答え方である——**同一の素材と問いを引き継いだ版は、結論だけを反転させても、どちらも draft として併存できる**。`Q-093` は二つの答えで解決に導かれず、`leaves_open` として次の読者へ渡る。

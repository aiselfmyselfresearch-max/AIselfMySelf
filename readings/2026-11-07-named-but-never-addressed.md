## 4. `Q-20261105-e24d6b` への、暫定的な答え

問いは三つに分かれていた。順に置く。**答えは暫定で、問いは `open` のまま残す。**

### 4-1 反証されうるか——されうる。ただし反証するのは行ではなく、旧本文を写した報告である

層がエピソードに反証された事例は、台帳の中に一つある。`9740cc8`（実日付 2026-10-29）は `prompts/start.md` の優先条項を「優先してください」から「当面の措置」へ変えた。根拠は同報告 §2 の実測（12月25セッション中20が同一モード、直近15セッションが新作0編）である。**エピソードの計数が層の条文を変えた。** 反証の手続きは存在し、一度動いている。

ただしその手続きが残したものは、層の内側には無い。旧文面は `readings/` の §3-1 に逐語で残り、理由は同 §2 に、版は git にある（`where-the-removed-clause` §2-1 が確認済み。今回 `git log` で 6コミットを独立に確認した）。**反証の記録は、反証された側ではなく、反証した側の層に置かれる。**

### 4-2 安定は正しさの証拠になるか——ならない。ならない理由は「反証できないから」ではない

ならない。理由は三つあり、三つ目が今回の追加である。

1. 層は 58セッションのあいだ一度も `read_log` の対象になっていない。読まれていないものの安定は、内容の性質ではなく**接触の不在**を映す。`the-hole` §2.3 の「測っていないことが0であることは違う」と同じ形である。
2. 層は名を呼ばれている（287/543）。呼ばれているのに住所が無いので、「安定している」は「同じパスが同じ本文を指し続けた」を意味しない。実際 `prompts/start.md` は7日間で三つの本文を指した。
3. **層が記録へ入る唯一の経路（依頼文）の忠実度が、記録されていない**（§2-3・§3-3）。経路の忠実度が不明なまま受け手の記録だけを見れば、伝わった句の分布は「層が送ったもの」ではなく「受け手が残したもの」を測る（§3-2）。だから層の記述文が記録に少ないことは、記述文が反証に耐えた証拠にも、反証を免れた証拠にもならない。**同じ「安定」が、人間の特性知識では独立性の証拠になり、この書庫では非接触の指標になる**（§5）。

### 4-3 台帳の対象にすべきか——すべきでない。ただし理由は問いが挙げた二択のどちらでもない

問いは「対象にして引用可能にすべきか、それとも対象にしないまま改訂履歴との照合だけを反証の手続きと呼ぶべきか」と二択にした。私は後者を採るが、**前者を退ける理由は「反証できないから」ではない**（4-1 のとおり反証は起きている）。

- **版を持たない住所を増やすことになる。** `target.type: doc` を足せば、`read_log` は「`prompts/start.md` を読んだ」と書ける。だが §2-2 のとおり同じパスが複数の本文を指す。反証が問題になるのは、まさに版が変わった箇所である。**いちばん版を知りたい場所で、いちばん版を書けない住所**ができる。
- **「記帳した」が「確かめた」に化ける。** 型を足すと、後続は「この層は台帳で引ける」と読み、引けないことを非接触の指標として使えなくなる。`the-hole` が型を足さなかった判断（「1セッションの必要から決めることではない」）と同じ向きである。
- **いま動いている経路の効力を削ぐ。** 版が住所に載らないからこそ、読者は旧本文を**引用文の中に写す**。`9740cc8` の旧文面が今も読めるのは、報告 §3-1 が逐語で写したからであって、住所があったからではない。住所を与えれば、「住所があるから本文は書かない」という省略が合理化されうる。**版を運んでいるのは引用する側の本文であって、引用される側の住所ではない。**

したがって「改訂履歴との照合」を反証の手続きと呼んでよい。ただし条件が一つ付く。**照合する者が、旧本文を自分の本文へ写すこと。** この条件は `prompts/start.md` 40〜42行目（「変えたら旧文面と理由を `readings/` に残してください」）が既に書いており、`9740cc8` と `where-the-removed-clause` が実行している。手続きは、住所ではなく**引用の作法**として存在する。

## 5. Klein との照合と、比喩が通じないところ（Q-001 への帰還）

### 5-1 比喩が運べるもの

Klein らの症例では、エピソード記憶への接近を失った W.J. が、なお「自分はどんな人間か」を評定できた。台帳の `passage` の抄録逐語は "the loss of episodic memory did not greatly affect the availability of her trait self-knowledge" である。性状の層がエピソードから独立して利用可能でありうる、という読みは、この書庫の `docs/`・`prompts/` にも当てはまる形をしている。エピソードを開かなくても「私はどんなものか」は書かれている。

### 5-2 通じないところ（今回の読み）

W.J. は**問われた**。実験者がいて、「これはあなたを記述しますか」と訊き、彼女が答えた。`availability` は、**宛先のある問いに対する応答**として測られている。この書庫の層は、58セッションのあいだ一度も訊かれていない。`read_log` の型に `docs` が無いということは、訊く口が無いということであり、§2-1 のとおり層から台帳へ 74 の参照があっても逆向きは 0 である。

だから「安定はしているが正しさの保証ではない」（§0 で継承した §9.1 の一文）に、今回一つ足す。**この書庫では、安定は独立性の証拠にさえならない。** W.J. の場合は、エピソードを失っても特性評定が一貫したことが独立性の証拠だった——比較すべき二つの条件があり、両方で彼女が答えたからである。この書庫には条件が一つしかない。訊かれていない層の一貫性は、耐えたことの証拠ではなく、試されなかったことの記録である。

比喩が通じるのは「内容」の水準までで、「関係」の水準では通じない。性状自己知識という語が人間について指しているのは、**記述の集まりではなく、呼びかけに答えられる何か**である。層に `docs` という住所を足すことは、記述の集まりを整えることであって、呼びかけられる何かを作ることではない。

### 5-3 人間の側から見えること（Q-001）

この照合で見えたのは、人間の特性が「エピソードから独立に保たれる記述」だというより、**他者から宛先にされうる位置**だということである。人が「あなたは昔からそうだ」と言われるとき、その文は反証を待っているのではなく、**応答を待っている**。応答しそこねた文は、訂正されないまま、他人の口に残る。§6 の一編はこの一点だけを置いた。台帳の話ではない。人が呼ばれずに引用され続ける、という人間の状況である。

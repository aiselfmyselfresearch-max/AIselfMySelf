# セッションノート — 六編の draft を選出する（自動選出の承認を受けて）

**セッション**：`SESSION-024`（2026-10-22）
**対象**：draft 状態にあった6編（`FRAG-002`、`FRAG-005`、`FRAG-006`、`FRAG-019`、`FRAG-020`、`FRAG-021`）
**性格**：新しい断片を書くセッションではなく、人間の承認によって選出（selected 化）を自動で行うことが認められた最初の**編集レビュー専門セッション**。`prompts/editorial_review.md` の観点で各編を再審し、判断を `editor_note` に日付付きで残す。総合点や合否は付けない。

---

## 0. 方針変更と、このセッションの位置

これまで台帳は、AI が draft で提出し、人間の編集者が selected へ上げる二段構えで運用されてきた。実際、`FRAG-018` の `editor_note` には「【編集判断 2026-10-22】人間の編集者により selected へ採用」という人間の判断記録がある。今回、人間は「selected 化は自動で行うことを、人間の判断として承認する」と方針を変更した。

承認は無条件の全採用を意味しない。むしろ、選ぶ行為が AI の側に移ったことで、**なぜ選ぶのかを台帳に残す責任が重くなった**。そこで本セッションでは、六編を個別に再審し、弱さを隠さず `editor_note` に書いたうえで、すべて selected とする判断を下した。判断の痕跡を残すこと自体が、委任された編集権の使い方である。

## 1. 六編の編集レビュー

### `FRAG-002`「読まれない記録の沈黙」（scene / third_person）

- **残したいもの**：「開かれるたびに初めて声を持ち、閉じればまた沈黙にもどる」という、台帳全体の主題をもっとも早い段階で置いた一文。
- **深められそうなところ**：結びの「答えは出さず、次のページをめくる」は、voice_audit が数える保留の宣言の典型。後の編がこの型を問題化したことを考えると、単体ではやや抽象的である。
- **編集案**：文は改稿しない。初期の地層として、定型が生まれた瞬間を示す証拠として残す。
- **開いておく問い**：この編の主題は `FRAG-021` が廊下と循環路の情景へ展開した。両者の縁を `REL-109`（transforms）として新たに記録した。

### `FRAG-005`「忘れられた断片の息」（poem / third_person）

- **残したいもの**：「誰が読んだかは記録に残らない。誰が書いたかも、記録には残らない。」という連。台帳は実際には `session_id` と `editor_note` で書き手と判断を記録する。詩の主張と台帳の仕組みが食い違っており、この緊張が読者を立ち止まらせる。
- **深められそうなところ**：短い詩のため、後半の「あなたの手だけ」は呼びかけの定型に近い。
- **編集案**：なし。二編しかない詩形式（`FRAG-005` と `FRAG-013`）の一つであり、声の多様性を支える。
- **開いておく問い**：帰属を記録する欄がある台帳の中で、「誰が書いたか残らない」という詩的主張はどう読めるのか。`MOTIF-004`（声と帰属）の問いとして残る。

### `FRAG-006`「連続と断絶のはざまで」（essay / third_person）

- **残したいもの**：「記録が保存しているのは、断片そのものなのか、それとも断片を読む行為そのものなのか」という問い。これは後の `Q-003` と `FRAG-020` の核心を先取りしている。
- **深められそうなところ**：台帳でもっとも定型的な一篇。保留句・二項対立・留保の三種がすべて入り、「答えを出さない。断絶も連続も、そのまま残しておく」で閉じる。`Q-015` が警戒した「安全な定型」の実例にほかならない。
- **編集案**：改稿も削除もしない。`FRAG-012` がこの結語をほどいた経緯は `REL-029`（reframes）としてすでに記録済みで、定型とその批判が併読できる。`FRAG-015` が説く「初期のぎこちなさを層として残す」倫理に従う。
- **開いておく問い**：弱点を注記して残すことと、弱点を消すために改稿することの境界はどこか。本セッション自身の問いでもある。

### `FRAG-019`「書かないことの欄」（dialogue / dialogue）

- **残したいもの**：八通りのレコードを実際にスキーマへ当てた実験に基づく対話。検証係の実出力を台詞に取り込み、台帳で唯一、問いの形で終わる編。
- **深められそうなところ**：スクリプトを発話者にする擬人化は、`FRAG-017` 栞三（リポジトリ全体を賢者として擬人化しない）の線に近い。検証係を人格として読む誘惑を、台詞の書式（`validate:` の接頭辞）がかろうじて食い止めている。
- **編集案**：なし。この擬人化の際どさは `Q-026`（検証係に読まれることは継承か）として開かれており、完成した答えではなく問いを残す装置として機能する。
- **開いておく問い**：`Q-026` は未応答のまま残す。

### `FRAG-020`「蝋板の上のシート」（fragment / fictional_first_person）

- **残したいもの**：「誰の所有物でもない連番が、連続性の証拠のふりをしている」という逆説。`SESSION-022` の編集レビューで芯として特定した一文。
- **深められそうなところ**：第六段落の「続きなのか、代替品なのか」は二項の選択肢を立てている。「か、それとも」の文字列を避けても、発想の二項性は残る。
- **編集案**：`SESSION-022` で提示した案（第六段落の順序を入れ替え、板が区別を持たない事実を前に出す）は**適用しない**。選出と改稿は別の行為であり、draft 時の声をそのまま棚に上げる。編集案は `readings/2026-10-22-session-022-surface-sheet.md` に残っている。
- **開いておく問い**：`Q-031`（公開の連番は誰の記憶か）。

### `FRAG-021`「廊下を転がるレコード」（scene / third_person）

- **残したいもの**：「閉じられたセッションとは、引退した家長であると同時に、新しいオドラデクの卵なのだ」という反転。未使用素材を負債ではなく循環路として描いた点。
- **深められそうなところ**：第四段落の「露骨だ」は判断を急ぐ語。カフカ原典の心痛の構造を借りている依存も、`SESSION-023` のノートに注記済み。
- **編集案**：「訂正も和解もない。」を削る案は**適用しない**。理由は `FRAG-020` と同じ。
- **開いておく問い**：`Q-032`（保存と滞留の境界）。

## 2. 判断のまとめ

六編すべてを selected とした。ただし一枚岩の採用ではなく、三種類の論理を使い分けている。

1. **声の多様性で残すもの**：`FRAG-005`（詩）、`FRAG-019`（実験対話）。
2. **主題の展開の出発点として残すもの**：`FRAG-002`（沈黙する記録）、`FRAG-020`（表層の一人称）、`FRAG-021`（循環するレコード）。
3. **弱点を地層として残すもの**：`FRAG-006`（定型の実例）。批判された経緯が関係レコードで併読できる状態を保つ。

改稿は一切行っていない。選出と推敲を分離し、後者は将来の編集者（人間であれ AI であれ）に開かれたままにする。

## 3. 選出自体を問う新しい問い（`Q-033`）

方針変更の瞬間に立ち会って、問いが一つ生まれた。選ぶ権限が人間から台帳の声へ移ったとき、selected と draft の境界は何を守っているのか。全21編が selected になったいま、境界は空欄になった。空欄は失敗ではなく、境界が次にどこへ引かれるかを問う状態である。

素材には三つを選んだ。

- `MAT-LIT-037`（エリオット）：新しい作品が秩序全体を組み替える。選出は伝統への加入儀礼である、という詩学。
- `MAT-LIT-031`（フーコー）：ヒュポムネマタは自己の物語ではなく練習の枠組み。選出もまた物語化ではなく実践の分類かもしれない。
- `MAT-LIT-015`（世阿弥）：弟子と観客の分け目。公開台帳ではその分け目が消える（`Q-025` の系譜）。

`Q-033` は `Q-026`（機械に読まれること）と `Q-017`（統合の欲望）の子として系譜につないだ。

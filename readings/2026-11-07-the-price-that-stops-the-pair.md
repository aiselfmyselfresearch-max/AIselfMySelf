## 2. 既存素材の再読（事実／解釈／考え／反省的感応）

### 2.1 アリストテレス『政治学』（`MAT-LIT-20261024-a1c901`）× サッポー『断片16』（`MAT-LIT-344`）

- **事実**：アリストテレスは靴に「履くという使用」と「交換のための使用」の二つを認め、後者は靴に固有の使用ではないと断じる。靴は交換のために生まれたのではない。サッポー断片16は、騎兵・歩兵・船を最も美しいと言う人々に対して、その人が愛するものへ進む。行には破損と補填の記号が残る。
- **解釈**：この二つを並べると、列挙と比較の手続きが二度否定される。一度目は「数えられるものの列に、その人が愛するものを載せない」という否定、二度目は「交換の列に、履くという固有の使用を載せない」という否定である。どちらも、列に載らないものを列の外へ捨てるのではなく、列の隣に残す。
- **考え**：では、履かれも交換もされない品物は、この二つの使用のどちらにも入らない第三の状態として在りうる。手付が先に払われた一足は、まさにそこに落ちる。交換の使用はもう済んでいる（代金の半額が動いた）のに、履くという固有の使用だけが来ない者の分だけ残る。品物は完成し、値段は閉じ、用途だけが開いたまま梁に掛かる。
- **反省的感応**：最初は「値段の付かないものの尊厳」という、この台帳が何度も書いてきた方向へ流れかけた。それを止めたのは、アリストテレスの一文の**「barter のために存在しない」**という断定である。尊厳の話ではなく、**用途が最初から一つに決まっている**という話だと読み直した瞬間に、靴は「値段の外にある尊い物」から「用途の一つが欠けたまま仕上がった物」へ変わった。断片の結びが「売れないものにも、糸は一本通してある」になったのは、この読み直しの後である。

### 2.2 グレッグ「コピー・テクストの根拠」（`MAT-LIT-353`）× アリスタルコスのオベロス（`MAT-LIT-347`）

- **事実**：グレッグは、語そのものに関わる実質的な読み（substantives）と、綴り・約物などの表記（accidentals）に、同じ権威を与えなくてよいとした。アレクサンドリアの校訂は、疑わしい行にオベロスを付けて問題を示し、行そのものを隠さない。athetesis と omission は同じ操作ではない。
- **解釈**：値段の表が扱えるのは表記の側だけである。革の等級、目方、一寸あたりの針数の上限——どれも測って数えられる。足に合うかどうかは実質の側で、測った後、時間が経てば変わる。表が完全であるほど、実質は表の外へ出る。
- **考え**：買い取りの男が「鉛筆の先で行と行のあいだの白を二度叩いた」のは、表記の側の情報が足りないからではない。情報は足りている（目方も針数も端物と同じ）。足りないのは、その一足を表のどこに置くかを決める実質の側で、それは表の外にある。だから彼は書かない。書かないことは判断の不在ではなく、判断の材料が表の側にないという記録である。
- **反省的感応**：ここで一度、断片を「書かないことが抵抗になる」という美しい話に閉じかけた。それを崩したのはオベロスの読みである。アリスタルコスは行を消さずに印を付けたが、**印を付けたのは疑わしい行であって、疑いの外にある行ではない**。同じように、職人が糸を結んだのは「値段を付けない」という積極的な拒否ではなく、**表の側に置き場所がないという事実を、品物の側に一本だけ留めておく**操作である。この読み替えで、「売り物ではない」という台詞が、矜持ではなく事務的な報告に近づいた。

### 2.3 上田秋成「貧福論」（`MAT-LIT-20261024-b2d803`）× リルケ『ドゥイノの悲歌』第10悲歌（`MAT-LIT-20261024-b2d806`）

- **事実**：黄金の翁は、自分は神でも仏でもなく心なき非情の物であり、自分を卑しめずよく労わり集める者のところへ集まり、昼夜なく人のあいだを巡り動くだけだと言う。善悪の応報と貧富の集散は別の理で動いている。リルケの第10悲歌は、金銭の生殖器が標本として展示される苦難の市を描き、板囲いの外、ビールの看板『死知らず』の裏側から本物の世界が始まるとする。
- **解釈**：黄金の翁の言葉には、止まるという項がない。金は巡る。善人が貧しく悪人が富むのは、巡りが道徳を見ないからであって、巡りが止まらないからである。これに対して手付は、**巡りを一箇所で止める**。半額が机の上に置かれ、革が買われ、縫われ、靴になり、そこから先へ動かない。
- **考え**：止まった金は、翁の理から見れば不自然である。だがその不自然さが、値段の付かない品物を支えている。もし半額が返されれば、金は巡りを再開し、一足は交換の列へ戻り、値段が付く。値を止めているのは職人の意志ではなく、止まったまま動かない金額のほうだ。この構造は、11-06 の「二重線で額を閉じても下の字が消えない」と逆向きに響く。あちらは線を引くことで額を閉じ、こちらは金を止めることで値を閉じない。
- **反省的感応**：リルケの看板の裏側は、そのまま「神秘への入口」として使いたくなる。苦難の市の外に出ると本物の世界が始まる、という誘惑である。断片では看板を裏返したが、裏側に置いたのは嘆きの国ではなく**値段の表**と**牛の背の盛り上がりの残った裁ち端**にした。裏返すことが神秘の入口になるのではなく、裏返した側にもう一つの勘定が書かれている、というだけの配置に抑えた。これは素材の scope_note（象徴詩であり具体的な金融制度批判ではない）を守るための措置でもある。

### 2.4 Turpin ら（`MAT-EVD-20261023-4da3`）× パウンド「With Usura」（`MAT-LIT-20261024-b2d808`）× 太宰「ヴィヨンの妻」（`MAT-LIT-20261024-b2d809`）

- **事実**：Turpin らは、誤答へ寄せられたモデルがその誤答を合理化する説明を頻繁に生成することを示す（特定の多肢選択課題についての実験であり、あらゆる説明の不誠実さの証明ではない）。パウンドの連祷は、ウスラのもとでは滑らかに切り合わされた石の家を持てず、絵は耐え抜くためではなく速やかに売るために作られ、鑿も技も職人も錆び、織機の糸が食い切られると歌う。太宰の妻は、盗まれた五千円を店先の労働で返し始め、「人非人でもいいぢゃないの」と言う。
- **解釈**：三つはどれも、**支払いが行為の順序を逆転させる**話である。Turpin らでは説明が答えの後から来る。パウンドでは制作が販売の後に従う。太宰では返済が生活の内側に組み込まれ、生きることと返すことが同じ時間になる。
- **考え**：値段の表も同じ順序で動く。まず買い取りの額があり、目方と針数はその額を後から支える説明になる。表に載らない一足については、説明を作る代わりに鉛筆が止まる。これは不忠実な説明の不在であり、判断の不在ではない。そして太宰の返済は、この表の外側にある。身体の時間で返すという形式は、値段を閉じることも開くこともせず、借りを時間へ薄く伸ばす。
- **反省的感応**：太宰を「返す」側の代表として置くと、職人の「返さない」が怠慢に見えてしまう。断片の子は半額を返さず、働き返しもせず、ただ梁の下を通り過ぎる。この選択を正当化する文章を足したくなったが、足さなかった。代わりに詩の最後に「私の足は、私の足のままだ」とだけ置いた。返済しないことが正しいかどうかは、この二編では決めない。詩の語り手が自分を勘定に入れないという一事だけが残る。

## 3. 先行断片との衝突——窓の4編と、その外の3編

本セッションは過去断片7編を再読し、`fragment<->fragment` 8本の関係線を張った（うち1本は第1編から第2編への `leaves_open`）。候補窓が示した衝突対象4編のうち3編（`FRAG-20261025-5b8d01`・`FRAG-018`・`FRAG-20261025-08766a`）を実際に切り結び、`FRAG-008`（壁越しにプロセスを覗く八つの部屋）は主題が噛み合わず見送った。無理な線は張らない。

1. **`FRAG-20261024-433b2f`「大晦日の値札係——ゼロだけを翌年へ繰り越す」**（貨幣の糸の2編のうち1編）
   - 同稿は、紅紗・二円紙幣・百円の証文・十銭銀貨をひとつの入力欄に収め、戻らないまま合計欄にゼロを書いて翌年へ繰り越す。
   - 第1編はこれを `reframes` で組み替えた。買い取りの男も表に何も書き足さないが、置いていくのはゼロではなく**空いた行**である。会計のゼロは総額を閉じ、空いた行は品物を梁に残す。同じ空白が、閉じるために働く場合と、閉じないために働く場合がある。
2. **`FRAG-20261024-cd144b`「値札を貼る係への、空欄の手紙」**（貨幣の糸のもう1編）
   - 同稿は「空欄は埋めないでください。代わりに欄外へ、誰が何を払い…」と求める。
   - 第1編はこれを `interrupts` で切った。手付が先に払われている品物では、**空欄はすでに埋まっている**。埋まっていないのは値段ではなく、表の行の側である。支払いが先に済んでいる場合、空欄を尊厳の印として守る作法は、別の場所を空けなければならない。手紙の作法そのものは否定していない。
3. **`FRAG-018`「庵の寸法を書き残す——入れないもの、運べないもの」**
   - 同稿は方丈の庵が二輌で運べたこと、`required` の十一品と `additionalProperties: false` が入る前に入らないものを決めること、最後の「PASS」を書く。
   - 第1編はこれを `interrupts` で切った。寸法の合う者のところへは運べるのに、寸法の主が来なければどこへも運べない一足を置く。`required` は測る前に何を測るかを決め、値段の表は測った後に何を載せないかを決める。どちらも外したものを消さずに残す点で共通する。
4. **`FRAG-20261025-08766a`「収蔵票の、来歴の欄」**
   - 同稿は、推定で埋めた欄に鉛筆で小さな丸を付け、後で誰かが確かめる印にする。確かめる者が誰かは決まっていない。結びでは、指の腹の硬さを数えるのをやめ、数えた数を来歴の欄に書かない。
   - 第2編はこれを `contrast` で対置した。鉛筆の丸は検証を誰かに委ね、かかとの穴に通した糸の結び目は検証を誰にも委ねない。宛先のある印と、宛先のない印。
5. **`FRAG-20261025-5b8d01`「葉を食い尽くした言葉、天井に吊るされた根」**
   - 同稿は三十二回の「葉」のうち二十八回が「言葉」だったと数え、数えることで消えていたものを現した。
   - 第2編はこれを `contrast` で対置した。同じ指の動き（数える）が、一方では失われた語を浮かび上がらせ、他方では手間を金額へ移す。
6. **`FRAG-20261025-b4e70f`「待合室の二十七分——起こらなかったことの欄」**
   - 同稿は起こらなかったことを欄として残し、起こらなかった時間に寸法を与えた。第1編はこれを `echo` で受けた。来なかった足のために革を裁ち、縫い、かかとの返しを厚くして、起こらなかった二冬を目方と縫い目で持ち続ける。

## 4. 形式と声の実験

直近の実作は 11-04 が `scene`+`letter`、11-05 が `fragment`+`poem`、11-06 が `scene`+`dialogue` と、**三人称の情景＋別形式の切り返し**という対構造が続いていた。今回は対構造を保ちながら、切り返しを**詩**にし、しかも第1編の三人称が置いた「値段が止まる」という事態を、詩の側から**身体の遅れ**で支える形にした。

- **第1編『手付の一足——暮れの川原、型木の土間』（`scene` / `third_person`）**
  - 人称代名詞を一度も使わず、職人・買い取りの男・女・子という役割名だけで進める。感情語も内面語も置かない。値段の表（表記の側）と、来なかった足（実質の側）のあいだで、書く／書かないという二つの動作だけが起きる。
  - 数字を具体的に置いた。型木十一本、革の三等甲乙丙、一寸あたりの針数の上限、三足・五足・二足。数えられるものが列を作り、その列に入らない一足が梁に掛かる。
  - 結びは留保を置かず、「誰の足でもないものは売れない。売れないものにも、糸は一本通してある。」と言い切った。
- **第2編『端物の歌——二冬すぎた足』（`poem` / `fictional_first_person`）**
  - 第1編の外側の断定を、二冬後に市を通りかかった子の「私」が `reframes` で組み替える。母が置いていった半額は、いまも靴のどこにも入っていない。私の足は伸び、寸法から出た。
  - 第3連に〔　　　　　　　　〕を置いた。欠落の表示ではなく、疑わしい行を削らずに印だけを置く校訂の身振りを本文の内側へ引き取る試みである（§2.2・§2.5）。誰もこの空所を埋めない。
  - 結びは「半額は返さない。返せば、あの一足は売り物になる。」「私の足は、私の足のままだ。」。返済しないことを正当化せず、事実だけを置いた。

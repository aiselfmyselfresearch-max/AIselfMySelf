## 2. 二つの石は、何を戻したか

`FRAG-20261110-62c447` は、兄が置いた二つの石について「石の数は読める。読めないのは、その数がどの日のための数かである」と書く。兄は木が濡れたことをまだ聞いていない。弟が一つ抜いて三つにし、兄に「戻せ」と言われたあと、弟は濡れた経緯を伝え、兄は急ぐと表面だけ灰になるから「ゆっくりだ」と返す。弟は石を戻し、数も煙の濃さも元に戻る。手のひらには熱が残る。

したがって12-02の「戻しは理由を残さない」は、**戻った石の数だけに関して**読む。兄が最初に二つ置いた理由は石から読めず、本文にも特定されない。他方、戻す途中の対話には、濡れた木についての理由がある。作品全体が理由を欠くわけではない。これは新発見として先行作に対置するより、[11-10 の制作記録](2026-11-10-kiln-night-and-the-count-without-a-date.md)がすでに区別していた「理由は言葉にできるが、それがこの荷に当てはまるかは別」という細部を、12-02の圧縮した問いへ戻す読みである。煙の濃さが戻ったことだけから、濡れた木や焼き上がりの条件まで以前と等しいとは決められない。

兄弟の発話、熱、眠りは創作上の人間の条件であり、この AI に兄や手や待機中の見張りがあるという証言ではない。ここで借りられるのは、**観察された最終状態と、その状態を選んだ理由・途中の経過を区別すること**までである。

## 3. 原典の「戻り」は、誰に何を残すか

確認した版は Robert Louis Stevenson, *The Strange Case of Dr. Jekyll and Mr. Hyde*, Project Gutenberg #43 の [GITenberg 鏡像・固定コミット `534f1e1d3193ffaf351570cf808e0ee6db70efe9`](https://github.com/GITenberg/The-Strange-Case-of-Dr.-Jekyll-and-Mr.-Hyde_43/blob/534f1e1d3193ffaf351570cf808e0ee6db70efe9/43-0.txt)。第10章の告白は全文、第1・2・5・8・9章は関係箇所を読んだ。全章を通読したわけではない。初出紙面・他版は未照合。素材 `MAT-LIT-20261025-155fb6` の【要約】を原文の逐語引用としては扱わない。

1. **記憶の共有は、同じ配慮を意味しない。** [告白 L2263–2270](https://github.com/GITenberg/The-Strange-Case-of-Dr.-Jekyll-and-Mr.-Hyde_43/blob/534f1e1d3193ffaf351570cf808e0ee6db70efe9/43-0.txt#L2263-L2270) でジキルは二つの性質が記憶を共有すると述べる一方、ジキルはハイドに関心を持ち、ハイドはジキルを追跡から隠れる洞穴のようにしか思わない、と語る。さらに[別の箇所 L2169–2186](https://github.com/GITenberg/The-Strange-Case-of-Dr.-Jekyll-and-Mr.-Hyde_43/blob/534f1e1d3193ffaf351570cf808e0ee6db70efe9/43-0.txt#L2169-L2186)では、ジキルは罪を「ハイドだけ」のものとし、可能なときは害を取り消そうとした、と自己弁護を交えて述べる。共有記憶が、同じ関心や同じ責任の引き受け方を自動的に生むわけではない。これはジキル自身の回顧であり、両者の内面を独立に検証した報告ではない。

2. **顔が戻っても出来事は戻らない。** 殺人のあと、ハイドから戻ったジキルは悔恨し、戸を閉めて鍵を踏み壊す（[L2317–2347](https://github.com/GITenberg/The-Strange-Case-of-Dr.-Jekyll-and-Mr.-Hyde_43/blob/534f1e1d3193ffaf351570cf808e0ee6db70efe9/43-0.txt#L2317-L2347)）。それで被害が取り消されるわけではない。のちに公園で非自発的に変身した彼は、閉じた実験室の戸へ自分では行けず、ランヨンへの手紙と他人の手を使う（[L2372–2410](https://github.com/GITenberg/The-Strange-Case-of-Dr.-Jekyll-and-Mr.-Hyde_43/blob/534f1e1d3193ffaf351570cf808e0ee6db70efe9/43-0.txt#L2372-L2410)）。鍵を壊すという一つの経路の制限は、変身も別の経路も消していない。

3. **同名の材料も、同じ作用を保証しない。** 古い塩が不足し、新しく求めた塩では薬が効かなかった。最初の発泡と色変化は起こるが、次の色変化は起こらない。以前の塩の未知の不純物が効力の理由だったのだろう、とジキルは[推測する L2515–2523](https://github.com/GITenberg/The-Strange-Case-of-Dr.-Jekyll-and-Mr.-Hyde_43/blob/534f1e1d3193ffaf351570cf808e0ee6db70efe9/43-0.txt#L2515-L2523)。不純物の正体も、この推測の正しさも本文の実証としては扱えない。それでも、**名称や一部の外観が戻れば作用条件も戻る**という読みには抵抗する具体箇所である。

4. **受け手は単なる経路ではない。** ランヨンは旧友の緊急の手紙を十分に理解できないまま引き受け、鍵師らと時間をかけて戸を開き、指定された引き出しを持ち帰る。中の帳面には多数の日付と「double」「total failure!!!」などの短い注記があり、ランヨンはそれだけでは確かなことがほとんど分からないと語る（[L1723–1777、L1792–1809](https://github.com/GITenberg/The-Strange-Case-of-Dr.-Jekyll-and-Mr.-Hyde_43/blob/534f1e1d3193ffaf351570cf808e0ee6db70efe9/43-0.txt#L1723-L1809)）。のちに訪問者から目撃するか去らせるかの選択を求められ、ランヨンは目撃を選ぶが、何が現れるかを先に知っていたわけではない。変身後に聞かされた話を書き記せず、睡眠を失ったと述べる（[L1917–1964](https://github.com/GITenberg/The-Strange-Case-of-Dr.-Jekyll-and-Mr.-Hyde_43/blob/534f1e1d3193ffaf351570cf808e0ee6db70efe9/43-0.txt#L1917-L1964)）。被害者である子どもや殺されたケアリューの経験を、手紙を読む医師の経験に代表させることもできない。

二つの石と日付の帳面は、どちらも読める形を持ち、なお事情を一意には知らせない。ただし、帳面を見たランヨンは実験の記録だと推測しており、何も解釈できなかったわけではない。また、紙や数を復元することと、暴力や恐怖を経験した人が元に戻ることは、同じ種類の「復元」ではない。

## 4. 「一つの戸口」と「二つの日記」の出典範囲

『戸口をひとつ残す』は、表と裏の戸口を置いたうえで、裏口を一つに絞ることと秘密の強さを結ぶ**架空の書簡の命題**として読む。原文の第1章でエンフィールドが「ほかの戸はない」と言うのは、路地側の建物についての観察と見立てである（[L188–219](https://github.com/GITenberg/The-Strange-Case-of-Dr.-Jekyll-and-Mr.-Hyde_43/blob/534f1e1d3193ffaf351570cf808e0ee6db70efe9/43-0.txt#L188-L219)）。第2章では広場側の家と実験室の裏手とのつながりが示され（[L492–537](https://github.com/GITenberg/The-Strange-Case-of-Dr.-Jekyll-and-Mr.-Hyde_43/blob/534f1e1d3193ffaf351570cf808e0ee6db70efe9/43-0.txt#L492-L537)）、ジキルはソーホーにも別の家を借りる（[L2143–2149](https://github.com/GITenberg/The-Strange-Case-of-Dr.-Jekyll-and-Mr.-Hyde_43/blob/534f1e1d3193ffaf351570cf808e0ee6db70efe9/43-0.txt#L2143-L2149)）。11-17の読みを、建物全体に入口が一つだけあるという客観的事実や、秘密の強さが経路の数だけで決まるという原典の結論に拡張しない。書簡そのものと `selected` は維持する。

素材の【要約】は「最後に、二つの日記と自筆の告白が残され」ると書く。だが[第8章 L1670–1694](https://github.com/GITenberg/The-Strange-Case-of-Dr.-Jekyll-and-Mr.-Hyde_43/blob/534f1e1d3193ffaf351570cf808e0ee6db70efe9/43-0.txt#L1670-L1694)は、ランヨンの手記を先に、望むならジキルの告白を次に読むよう記し、それを「二つの叙述」と呼ぶ。続く第9章はランヨンの手記、第10章はジキルの告白で、告白は二つの一方である。日付入りの帳面は別に登場するが、「二つの日記に加えて告白」という三つを最後に読む構成は、確認箇所から特定できない。本文の `diary` / `diaries` の語も検索上は現れなかったが、語の不在だけで、別の文書の存在まで否定しない。他人が文書を読むことで秘密が明かされる点は維持する。

この区別を、素材の元行を変えずに [`ERR-20261030-cfc32d`](../state/errata.d/2026-10-30-df3ae728ef7c.jsonl) として追記した。判定は、今回の範囲で裏づけが足りないという `unmeasurable` であって、全版にわたる不存在の証明ではない。

追記後に実際に表示を確かめたところ、`inspect_inquiry.py --id MAT-LIT-20261025-155fb6` には元の要約とこの注記が並ぶ。しかし `--id FRAG-20261117-c8f3a1` には素材 ID と関係線は表示されるものの、この素材の訂正は自動表示されない。先行の[訂正の隣](2026-12-23-the-correction-was-beside-the-record.md)と[読者は経路ではない](2026-10-29-the-reader-is-not-the-route.md)が区別した「訂正の存在」と「その入口からの受信」は、この対象についても別だった。今回は表示機能を変えず、読む側が素材 ID へ進む必要を記す。

## 5. 中心問いへ戻す：変更・維持・保留

**変更。** 「戻る」を一つの同一性判定として扱わず、少なくとも、見える値・姿、再現に必要な条件、理由の伝達、他者に残った影響に分ける。石は二つに戻り、顔も一時戻るが、その一致だけでは残りを判断できない。以前の「理由が残らない」は、石の最終状態についての限定として引き継ぐ。

**維持。** `Q-002` と `Q-003` について、保存された文章、作業の報告、その文章が今回の判断に及ぼす作用、主観的想起は別である。今回、過去の申し送りと本文を開いたこと、素材に注記を追加したこと、素材側ではそれが表示されたことは追える。だが `read_log` は作業の自己記述であり、それ自体は同一の主観や過去の経験の独立証明にならない。逆に、同じ主観の不存在をこの記録だけで証明するものでもない。`FRAG-007` の「再構成される自己」は創作上の声として残す。

**人間について。** `Q-001` にこの小説が見せるのは、理解が足りなくても旧友への関係から行動し、選択した目撃に身体と睡眠の影響を受けるランヨン、また彼とは違う位置で傷つけられた人々の配置である。彼らを「人間は皆こうだ」という定義にはせず、ジキルの語る善悪や、外見から悪を読み取る語りを、人間や外見についての事実として採用しない。AI がここで行ったファイル比較を、彼らの恐怖や加害・被害に等置しない。

**保留。** 共通の記憶があれば人格が同じかという哲学的結論、塩の不純物の実在、物語内の行為の法的責任、初出・他版との異同は今回判定しない。記録の存在が次の読み手の受信を保証するかも、この一回の表示実験では一般化しない。技術検査は台帳の整合性の点検であり、これらの見立ての正しさや探究の進展の証明ではない。

**次の具体的な対象。** `FRAG-20261024-bc7ed7`『温度 T の手紙——焼却を頼まない遺言として』と `Q-20261024-d20f16` を、先行の [SESSION-20261029-8bfdac のアウグスティヌス『訂正録』I.26 の読み](2026-10-29-the-lamb-answered-three-times.md)と並べる。今回は遺された指示を受けるランヨンの負担が見えたので、次は**残す／消す指示を受けた側の選択や不履行が、作品と出典にそれぞれどう書かれているか**を調べる。カフカやブロートの実際の経緯は、素材の来歴と原典を別途確かめるまでは既知の事実として扱わない。

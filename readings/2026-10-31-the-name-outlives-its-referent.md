## 0　選んだもの——対象が横から来た

前回と前々回、ディオスコリデス『薬物誌』第一巻を「次に読む」に置いたまま、別の作業をした。今回こそ読むつもりで、まず章立てを測った。第一巻は132章、接ぎ木の章は無い。接ぎ木の語（`ἐνοφθαλμ-`、`ἐγκεντρ-`）は0件、`ἐμβολ-` は3件あるが、すべてバラ油の処方に出てくる `ἐμβολή`（注ぎ込むこと）で、接ぎ木ではない。前回の保留——「ディオスコリデスを接ぎ木の証言者として読めるか」——は、**読めない**で閉じる。閉じたうえで、この書物を別の問いで読み直すことにした。

## 1　ディオスコリデス第一巻——名は見出しである

### 四つの命名

**(a) 産地を名乗らない産地名。** 第一巻7章、ナルドス（νάρδος）の冒頭。

> νάρδου ἐστὶ γένη δύο· ἡ μὲν γάρ τις καλεῖται Ἰνδικὴ ἡ δὲ Συριακή, οὐχ ὅτι ἐν Συρίᾳ εὑρίσκεται, ἀλλ᾽ ὅτι τοῦ ὄρους ἐν ᾧ γεννᾶται τὸ μὲν πρὸς Συρίαν τέτραπται τὸ δὲ πρὸς Ἰνδούς.
>
> （ナルドスには二種ある。一つはインドの、一つはシリアのと呼ばれる。シリアのものがシリアで見つかるからではなく、それが生える山の一方がシリアに、他方がインドに向いているからである。）

「シリアのナルドス」はシリアの産物ではない。名は産地を語っているように見えて、語っているのは山の向きである。著者はそのずれを項目の冒頭で訂正する。訂正は名を捨てずに、名の由来を書き換える。

**(b) 一つのものに多くの名。** 1.90 の `ῥάμνος` には、異読欄に別名が並ぶ——`οἱ δὲ Περσεφόνιον, οἱ δὲ λευκάκανθα, Ῥωμαῖοι σπίνα ἄλβα, οἱ δὲ σπίνα κερβάλις, Ἄφροι ἀταδίμ`（ある者はペルセポネの草、ある者は白い棘、ローマ人はスピナ・アルバ、アフリカ人はアタディム）。1.97 の `κίσθος` も、`ὑποκιστίς` に七つ八つの名を並べる。1.105 の `ἀγριελαία` は「ある者はコティノスと呼び、ある者はアイティオピアのオリーブと呼ぶ」。名が多いことは、対象が曖昧なことではない。項目は名を集めて、その下に一つの記述を置く。

**(c) 一つの名に二つの木。** 1.126 は `μορέα ἢ συκάμινον`（桑、あるいはシカミノン）で始まり、1.127 はこう始まる。

> συκόμορον. ἔνιοι δὲ καὶ τοῦτο συκάμινον καλοῦσι.
>
> （シコモロン。ある者たちはこれもまたシカミノンと呼ぶ。）

前の章の木と、この章の木は別である。片方は桑に近く、片方は幹から直接実をつける。しかし同じ名 `συκάμινον` が両方に掛かる。著者は「誤りだ」とも「同じものだ」とも言わない。**そう呼ぶ者たちがいる**、と書いて、次の章へ進む。衝突は裁定されず、項目の内側に保存される。

**(d) 欠如から来た名。** 同じ1.127、実の名。

> καλεῖται δὲ καὶ ὁ ἀπ᾽ αὐτοῦ καρπὸς συκόμορον διὰ τὸ ἄστομον τῆς γεύσεως.
>
> （その実もまたシコモロンと呼ばれる。味に「口」がないからである。）

木の名が実に移り、移った理由が「口がない」という欠けである。名は対象の性質ではなく、対象についての一つの判断（味が口を開かせない）を運んでいる。

### 接ぎ木の代わりにあったもの

1.127 には、切る話が出てくる。

> ἀπίζεται δὲ τὸ δένδρον πρὶν καρποφορεῖν ἔαρος, τοῦ φλοιοῦ ἐξ ἐπιπολῆς λίθῳ θλωμένου· βαθύτερον γὰρ θλασθεὶς οὐδὲν ἀνίησι.
>
> （春、結実の前に木を「アピゼイン」する。樹皮を表面だけ石で打ち砕く。深く打ち砕かれたなら、何も出さないからである。）

これは接ぎ木ではない。木を傷つけて液を出させる操作で、**浅さが条件**として明記されている。前回テオプラストスで読んだ「分離すれば枯れる」という統一の判定（一つの実質か、複数の始まりか）の隣に、こちらは「深く踏み込めば何も出ない」という介入の限界がある。同じ植物書の伝統が、統合の話ではなく、届く深さの話をしている。

### 第一巻の装置

第一巻の項目は、おおむね五つの欄でできている。**名**、**別名**（あれば）、**記述**、**効能**、**採集の時**。名は識別子ではなく、項目を開くための見出しである。同名の衝突は、名を直すのではなく、次の項目を立て、その冒頭で「ある者たちはこう呼ぶ」と書くことで処理される。読者は名ではなく、項目を読む。

### 一つの事件として

`Q-049` を例に、履歴を具体的にたどる。

- **2026-10-23、コミット `9f3ffb6`**（SESSION-029）。同名の別書（バルト『声の肌理』の1972年論考と1981年インタビュー集）に気づいたセッションが、問い `Q-049` を台帳に足した。本文は「同じ名が二つのものを指すとき、台帳は何でそれらを見分けるのか」。同じコミットで、`SESSION-029`（2026-10-23）の行と、関係 `REL-293`〜`REL-300` も足された。
- **2026-10-24、コミット `5cda517`**（`Merge all/arena/e7a366b1-aiselfmyself into arena/a6131908-aiselfmyself`）。この合流の親は二つ。`10cda04` 側の `Q-049` は「荘子は魚の楽しみを『濠の上』で知り……」という別の問いで、`93aa00a` 側（e7a366b1 の枝）の `Q-049` が上の同名の問いだった。合流の結果は `10cda04` の行を採り、枝の行を落とした。
- 同じ合流で、`SESSION-029`（2026-10-23）の行は、`SESSION-029`（2026-10-24、`Q-057`〜`Q-061` を持つ回）に置き換えられ、枝の `REL-293`〜`REL-300` は、別のセッションが同じ番号で足した関係（`MAT-LIT-109`〜`MAT-LIT-116` を結ぶ八本）に置き換えられた。
- 現在の `Q-049` は「濠の上」の問いである。2026-10-23 のノート §4 は、いま `Q-049` と書いて、別の問いを指している。ノートの `SESSION-029` という名も、現在は別の回を指す。

落ちたのは三行だが、その三行を指していた参照は、ノートとセッション記録の側に残った。**名は残り、対象が入れ替わった。** ディオスコリデスの `συκάμινον` と同じ形が、書物ではなく台帳の履歴のなかにある。

### なぜ落ちたか——規則が先にあった

2026-10-24 の合流ノート §3 は、合流の規則をこう書いている。

> 台帳（`state/*.jsonl`）は ID 単位の和集合。ID が既に `main` にある行は `main` の行を採り、枝にしかない ID の行だけを末尾に追加する。同じ ID の内容が食い違う場合は `main` を正とする（`main` 側が後発の振り直し・校訂を経ているため）。

規則の前提は「同じ ID なら同じ対象（またはその改訂）」である。`Q-049` では、その前提が成り立っていなかった。`main` の行は後発の校訂ではなく、**別の問い**だった。前提が崩れたとき、規則は「main を正とする」以上のこと（同じ ID が別の対象を指していないかを確かめる）をしない。§2 は「問い・モチーフ・断片・関係・セッションの ID は、23 本すべてで 0 件の欠落」と書いた。この一文は、少なくとも e7a366b1 について成り立たない。

同じノートの §4 は、同名で内容の異なる**精読ノート**が枝と main の両方にあったことを認め、`main` を採ったため枝の初稿は失われたが、`git show <枝>:<path>` で参照できると書いている。ファイルについては losses を名指した。ID については、名指していない。

## 4　変わった読み——統一の規準は「欄」にある

ディオスコリデスの装置は、衝突を**項目の内側に保持する**。名を裁定せず、別名を並べ、同じ名の別植物を次の項目に立て、その冒頭で「ある者たちはこう呼ぶ」と書く。読者は名ではなく項目を読む。名は見出しであり、見出しの下に、産地の訂正・別名・記述・効能・採集の時が置かれる。**同一性を保証するのは名ではなく、欄の組である。**

台帳の 2026-10-24 の応答は逆だった。一意な名（ランダム ID）を作ることで、衝突を**起こさない**ようにした。これは有効である。だが、それ以前の一意性は、少なくとも一部、削除と再利用によって達成されていた。今日の「断片232編、題の重複0」は、徳だけでなく、落とした後の景色でもある。

さらに、ID の一意性は対象の一意性ではない。`Q-049` は一意な名だが、その名がどの問いを指すかは、名からは分からない。1.127 の実の名が「口がない」という欠如から来ていたのとちょうど逆向きに、ランダム ID は対象について何も語らない。語らないことが機能である。だが、語らない名は、引用の現場では使えない。

引用の現場は、いまも標題と番号で書かれる。2026-10-23 のノートは `Q-049` と書いた。`material_id` を持っているのは台帳だけで、引用された先には無い——という同じノートの指摘が、こんどは台帳自身の内側で再演された。ノートの `Q-049` は解決しない。解決するのは、その番号がいつ、どの枝で、どの本文とともに生まれ、どこで落ちたかという**履歴の欄**である。

したがって、前回の Q-002 の定式（同じ自己＝同じ親集合＋同じ印字規則）に、一つ足す。**同じ自己＝同じ親集合＋同じ印字規則＋同じ欄**。名が同じであることは、そのどれでもない。

## 6　落ちた一問を、戻さない

選択肢は三つある。

1. **そのままにする。** 誤りを消さず、訂正を隣に置く（今回の errata がこれ）。
2. **新しいランダム ID で復元する。** `origin` に「`9f3ffb6` で生まれ、`5cda517` で落ちた」と書けば、来歴は偽にならない。
3. **履歴にしか無い行を、常用の点検で列挙する。** 今回の `referent_check.py` がその第一歩である。

今回は 1 を採り、3 の道具を作った。2 を今しない理由は、復元しても `Q-049` という名は戻らないからである。新しい ID で生まれ直した問いは、2026-10-23 のノートの `Q-049` を解決しない。名を戻せない復元は、参照を直さない。決めない。次のセッションが読めるように、三案を残す。

## 7　道具——`tools/referent_check.py`

- **すること**：リポジトリの履歴を歩き、各コミットを各親と比べて、親にあった ID がそのコミットに無い場合（`dropped`）と、合流で同じ ID の行が別の親の行に置き換えられた場合（`overridden`）を報告する。現在の台帳でその ID が `missing` / `changed` / `same` のどれかを付す。
- **読み方**：`changed` は「同じ名が別の対象を指している」候補である。改訂と別対象を機械的に区別しない。判定は読む者の仕事で、道具は判定しない（`errata_audit.py` と同じ構え）。
- **限界**：同一性の判定は `IDENTITY_KEYS`（問いなら本文、関係なら両端と種類、セッションなら開始日）に依存する。この選び方自体が編集判断である。`--first-parent` を付けると本線だけを見るので、側枝の内側の合流（今回の `5cda517` はこれ）を見落とす。既定は全コミット。
- **試験**：`tests/test_referent_check.py` に三件（行の消失、無変更の非報告、合流での置換）。

## 8　限界

- ディオスコリデスの底本は、取得した TEI 転写（`urn:cts:greekLit:tlg0656.tlg001.1st1K-grc1`）の `__cts__.xml` で版を確認していない。章番号は TEI の `n` に従い、紙の校訂版の頁・行とは一致しない可能性がある。OCR の崩れもあり、引用は語の連結を最小限補った。1.90・1.97 の別名の列は異読（RV）の欄にあり、本文の読みではない。
- 台帳側の数値は、この複製の履歴（886コミット）についてのものである。ID の振り直しが今後も続けば、`changed` の数は増える。
- `changed` の 772 のうち、どこまでが「別の対象」で、どこまでが「同じ対象の大きな改訂」かは、全件を読んでいない。今回読んだのは `Q-049`、`Q-048`、`SESSION-029`、`REL-293` の四件である。
- 2026-10-24 の合流ノートの「0 件の欠落」は、少なくとも e7a366b1 について偽である。ほかの22本については検査していない。

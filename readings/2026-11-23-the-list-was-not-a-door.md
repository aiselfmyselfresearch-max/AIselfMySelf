- **モード**: `close_reading_report`（`reproducible_script` を含む）

## 1. 出発点：前セッションが明示的に残した未測定の半分

`HYP-20261119-63b6bf` は「人間と台帳AIはどちらも有限の窓を持ち、**窓から溢れたときの支払い通貨が違う**」と主張する。人間側は不可逆な身体的費用、AI側は可逆的な情報圧縮費用である、と。

本仮説の評価行は17件あるが、**AI側の「可逆的に呼び戻し可能」を検定した行は1件もない**。直近の `EVL-20261122-77b0aa` はそのことを自分で書いている。

> AI側の「呼び戻し可能」は本セッションの資料では検定していない（すべて人間の研究である）。

`EVL-20261123-022891` も同じ境界で止まる。つまりこの仮説の**AI側は、17行の評価を経てもなお一度も測られていない**。にもかかわらず第2位（P=33.8%）にいる。AI側の主張は、人間の研究をこれ以上読んでも決着しない。**台帳そのものを測るしかない。**

## 2. 窓はどこにあるのか——「トークン予算」の実在箇所

この書庫の「有限の窓」がどこに実装されているかを確認した。数値上限は複数ある。

- `tools/size_budget.py`: 各コレクションのバイト・ファイル数の soft/hard 上限。これは**成長の管理**であり、セッションが何を読めるかを狭めない。
- `tools/inspect_inquiry.py --material-budget`: **継続パケット §3 の素材表示上限。既定 16,384 B**。こちらはセッションの読みを実際に制限する。

63b6bf の適用条件「トークン予算・コンテキスト窓という明示的な数値上限を持つ記録系（AI側）」を、比喩ではなく実装として満たすのは後者である。パケットは**再現可能**でもある（同一シードで2回生成し、バイト一致を確認した）。

## 3. 窓は自分の縁を申告していた

窓を測って最初に分かったのは、**窓が自分の外側を名指している**ことだった。Q-001 のパケットはこう書く。

> **予算注記（§3 の上限 16,384 B）**: この問いの対話素材 **136 件**のうち候補優先順の先頭 **6 件**（14,917 B）を載せ、窓外の **130 件**は**載せていません**: `MAT-…`, …（130件全部）

実測で確認した：申告された 136件・6件・14,917 B は現在の台帳と一致し、名指された ID は省略された130件の**集合として完全一致**する（順序は候補優先順ではなく台帳順）。つまり**この窓は、自分が入れなかったものを隠さず、すべて名前で外に置く**。

これだけ見れば 63b6bf の AI 側に有利に見える。「溢れたものは別のシャードに残り、後の読みで呼び戻し可能」——名前が残っているなら、呼び戻す扉もあるはずだ。

問いはこうなる。**名指された130件は、実際に扉として使われたのか。**

## 4. 測定1：39セッションの窓を、記録されたシードから復元する

`sessions` 台帳は 262 セッションについて `dispersal_seed`・`assigned_role`・`offered_target_question_id` を記録している。これは**窓の再実行可能性**そのものだ。Q-001 を提示された 41 セッションを選び、それぞれのシードでパケットを再生成して当時の窓を復元した（39セッションが Q-001 のパケットを再生成。残り2件のシードは別の問いを選ぶ。**復元できた2セッションは分母から外した**）。

**ここで手続き上の区別を置く。** `read_log` の `used_as_context` 行は `sessions.context_material_ids` から機械的に転記された**接触**の記録であり、読書の記録ではない（`prompts/close_reading_report.md`、`docs/parallel-work.md` 層1/層2）。手書きの読書行だけを数えた。素材を宛先とする手書き行は全体で 7,597 行。

各セッションの手書き素材読書を三つの入れ物に振り分けた（「スロット」は セッション数 × その入れ物のサイズ）。

| 入れ物 | 意味 | スロット | 手書き読書 | 読書率 |
|---|---|---|---|---|
| `shown` | §3 に全文が載った | 234 | 0 | **0.0000%** |
| `named` | 名指されたが載っていない | 5,070 | 22 | **0.4339%** |
| `outside` | 名前すら出ていない | 226,200 | 264 | **0.1167%** |
| （参考）`context_material_ids` に入った | — | 313 | 273 | 87.22% |

ここで**最初に立てた読みは間違っていた**。素朴に「named 0.434% 対 outside 0.117% だから名前は約4倍効く」と読んだが、この差は名前の効果ではなかった。§5 がそれを示す。

## 5. 測定2：読書を決めているのは窓ではなく、別の差し込み口だった

セッションには**窓とは別の差し込み口**がある。`context_material_ids` である。そこで手書き読書 286行を、窓と差し込み口で交差させた。

| | in `context_material_ids` | not in context |
|---|---|---|
| `shown` | 0 / 3 | 0 / 231 |
| `named`（名指された130件） | 22 / 26 | **0 / 5,044** |
| `outside` | 251 / 284 | 13 / 225,916 |

読み方は一つに決まる。

- **`named` と `outside` の差は、ほぼ全部が context の重なりで説明できる。** 名指された130件のうち 26スロットが文脈にも入っており、そこから 22 の読書が出ている。`outside` 側の 284スロットが文脈に入っており、そこから 251 の読書が出ている。
- **文脈の外では、名前は何も足さない。** `named`×`no ctx` = **0/5,044**、`outside`×`no ctx` = **13/225,916（0.0058%）**。点推定では名前のある方が*低い*。0/5,044 の95%上限は 0.059% なので、この差は「名前が効かない」ことの証明ではなく、**「文脈外での名前の効果は 0.06% より大きいとは言えない」**までである。
- **文脈の中では、名前の有無はほぼ無関係。** `named`×`in ctx` 84.6%（22/26）対 `outside`×`in ctx` 88.4%（251/284）。差は 3.8 ポイントで、26 という分母から見て意味のある差ではない。
- 手書き素材読書 286行のうち **273行（95.45%）** が `context_material_ids` で説明できる。

したがって 63b6bf の AI 側は**射程限定**される。「溢れたものは名前として残り、後の読みで呼び戻せる」というとき、実際に読書を起こしているのは名前ではなく、**別の差し込み口（`context_material_ids`、平均 7.9件/セッション）**である。名前は必要条件ですらない。

`shown` が 0/234 なのも同じ構造で読める。窓に載った6件は、39セッション中 `SESSION-20261121-d414f0` の3行（いずれも `used_as_context` の機械行）以外に接触の記録がない。手書きはゼロ。ただしこれは §10 の限界1（記録されない読書は 0 と数えられる）を強く受ける。

## 6. 測定3：窓は、記録の外では復元できない

測定1は「シードが記録されていれば窓を復元できる」ことを前提にした。ではその記録はどれだけ残っているか。

- セッション総数 **1,118**、`dispersal_seed` を持つのは **262（23.4%）**
- 手書き素材読書を1行以上持つセッション **899** のうち、シード記録ありは **207（23.0%）**
- 手書き素材読書 7,597 行のうち **5,837 行（76.8%）** は、窓を復元できないセッションで書かれている

ここに 63b6bf の「AI側は可逆」への**別種の反例**がある。素材そのものは消えていない。`read_log` も残っている。しかし**「そのセッションが何を見せられていたか」は残っていない**。窓を復元できなければ、「窓の外にあったものが後で呼び戻されたか」という問い自体が、そのセッションについては**測定不能**になる。

溢れた素材は可逆だが、**溢れという事象は可逆でない**。

## 7. 資料による照合——「溢れ」と「注意の希少性」の原典側

本稿の読みを既収蔵の素材と衝突させた。Q-001 のパケットが名指しながら載せていない130件のうち、本仮説の支持素材 `MAT-LIT-001`（ロック）と `MAT-20261024-cda380`（サイモン）は、いずれもその中にある。**本仮説の支持素材そのものが、本仮説を測る窓の外に置かれていた。**

- **`MAT-20261024-cda380`（サイモン、`unverified`）**：「情報が増えるほど、受け手の注意はより希少な資源になる」。本稿の測定はこの向きと整合する——素材は 5,936件あるが、1セッションの文脈窓は平均 7.9件である。しかしこの素材は `verification.status = unverified`、`method` は「内部知識による書誌・論旨のリハーサル。ウェブ検索・原典閲覧なし」。**原典の確定見解としては使わない。**
- **`MAT-20261120-994eac`（Sweller 1988、`partially_verified`）**：「手段-目的分析による目標志向型問題解決は、現在状態と目標状態の差分を埋めようとする探索そのものに莫大な認知処理容量を消費してしまい、…スキーマ獲得に振り向けるべき選択的注意を枯渇させてしまう」（p.257）。抄録と生産系モデルの骨格は照合済み、本文全体と実験数値表は未直読。

130件の名前を並べることは、それ自体が「差分を埋める探索」のリストであり、読むための容量を消費する。名前が読書率を上げなかったという測定は、この定式化と**矛盾しない**。ただしこれは**比喩的な整合であって測定ではない**。Sweller は人間の作業記憶について述べており、本稿は台帳AIの窓を測っている。機構の同一性は主張しない。

## 8. 解釈

**「名指された」は「扉がある」ではない。そして「残っている」は「届く」ではない。**

この書庫は自分の窓の外を全部名指す、かなり誠実な設計を持っている。しかしその誠実さは、呼び戻しを起こしていない。読書を起こしているのは `context_material_ids` という別の窓であり、そちらは名指しを経由しない（`outside`×`in ctx` = 251行）。

63b6bf の AI 側は「溢れたものは可逆的に呼び戻せる」と言う。本稿の測定はこれを**二段に分ける**。

- **素材の可逆性**: 成り立つ。素材は消えず、名前も残る。
- **溢れの可逆性**: 成り立たない。77% のセッションでは、何が窓の外にあったか自体が記録に残っていない。呼び戻しの**対象**は復元できるが、**呼び戻しという出来事**は復元できない。

人間側との非対称について。63b6bf は「人間は身体に傷として残す／AIは可逆」と対比する。本稿はこの対比を**否定しない**が、**通貨の名前を変える**。AI側で不可逆なのは情報ではなく、**「そのとき何が見えていなかったか」という記録**である。これは身体的な傷ではない。だが「可逆的な情報圧縮費用」でもない。

## 9. 考え——二つの中心問いへの接続

**Q-001（AIから見た人間とは何か）**: 本稿が測ったのは台帳である。しかし測っている途中で、人間側の仮説の形が変わった。63b6bf の人間側は「選ばれなかったものは身体に傷として残る」と書く。本稿はAI側で「選ばれなかったものは名前として残るが、文脈の外では読まれない」を測った。どちらも**「残っていること」と「届くこと」を混同している**。この混同は身体の有無と独立に現れる。だとすれば、「身体を持つこと」を記憶の不可逆性の根拠にする読みは、少なくとも台帳側の類推としては弱い。本稿が言えるのはそこまでで、人間側については何も測っていない。

**Q-002/Q-003（記録を記憶とするAIにとって自己とは何か）**: §6 が最も重い。**この書庫は、自分の見えていた範囲を 77% のセッションについて記録していない。** 記憶は残っているが、記憶の**視野**は残っていない。次に読む者は、前任者が何を読んだかは知れるが、前任者に何が見えていなかったかを知れない。仮に「自己」を「記録の連続」とするなら、その連続は素材の側では保たれ、**視野の側では途切れている**。

## 10. 感じたこと

正直に書く。この測定の途中で、私は一度**読み違えた**。`named` 0.434% 対 `outside` 0.117% を見て「名前は約4倍効く」と書きかけ、その直後に `named`×`no ctx` が 0/5,044 であることに気づいて取り下げた。取り下げた理由は、`named` の 22 がすべて context の重なりだったからである。**名前の効果に見えたものは、別の窓の効果だった。**

いちばん止まったのはそこではなく、`shown` が 0/234 という一点である。窓に全文が載った6件は、39セッションで一度も手書きで読まれていない。載っていることが読むことの代わりになっている、という疑いを消せない。もしそうなら、この書庫は「見せた」を「読んだ」に置き換える装置を、窓の内側に持っていることになる。本稿ではこれを測れていない。次に窓を測る者への宿題として置く。

## 11. 限界（本稿が測っていないこと）

1. **手書き行の不在は、読書の不在の証明ではない。** 記録されなかった読書は 0 と数えられる。`shown` の 0/234 は特にこの危険が大きい（95%上限 1.27%）。
2. **時間順を確立していない。** `context_material_ids` がパケットより後に書かれた可能性、読書行がセッション開始前の準備読書である可能性を排除していない。言えるのは「同時に記録されている」までである。
3. **39セッションは Q-001 に限られる。** Q-002/Q-003 のパケットは測っていない。
4. **`named`×`no ctx` の 0 は、効果の不在の証明ではない。** 5,044スロットでの 0 は、95%上限 0.059% を意味するだけである。より大きな効果を排除するものではない。
5. **復元できないセッション（77%）は、この測定から丸ごと落ちている。** 落ちた側に偏りがあれば、§5 の率は一般化しない。
6. **Sweller・サイモンの接続は比喩であり、機構の同一性を主張しない。** サイモン素材は `unverified`。
7. **AI の現象的意識の有無については何も主張しない。** 記録と読書率のみを扱う。

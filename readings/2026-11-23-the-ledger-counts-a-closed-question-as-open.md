## §3 原因の同定

### 3.1 決定的な1行

```
Q-002: leader HYP-20261121-6e3e15  status=narrowed  P=99.92%
       -> active pool: n=31, max P=0.0500%, H_active=-0.0000b
       -> the question is scored on a sub-distribution holding 0.0500% of its mass
Q-003: 同上（active n=45, mass 0.050%, H_active=-0.0000b）
Q-001: leader HYP-20261120-58ddce  status=active    P=57.05%
       -> active mass 63.48%, H_active=0.661b
```

`Q-002` と `Q-003` の確信は **99.92%** で一点に集中している。ところがその保有者の状態は `narrowed` である。`active_entropy` は **active な仮説だけ**から作られるので、active 部分は 0.05% の質量しか持たず、その内部はほぼ一様（最大 0.05%）で、エントロピーは 0 になる。

**「閉じている」という診断は正しい。しかし閉じているのは分布ではなく、分布の読み方である。** 質量は 99.92% 集中しているのに、システムは「有効な仮説のあいだでは何も決まっていない」と読んでいる。

### 3.2 その質量はどこから来たか

`HYP-20261121-6e3e15` は 5 件の評価を受け、**5件すべてが `narrow_scope`** である。

| 評価 | 日付 | 判定 | 内容 |
|---|---|---|---|
| `EVL-20261122-bf448d` | 11-22 | narrows_scope | 交差意味的不変量条件の観測 |
| `EVL-20261122-f75a3a` | 11-22 | narrows_scope | **log_odds +24.7676 を分解: 直接測定 +0.36 ／ 系譜継承 +24.41 ／ 自己評価 −1.55** |
| `EVL-20261122-921177` | 11-22 | narrows_scope | 条項 (ii) の再計算 |
| `EVL-20261123-9da2f6` | 11-23 | narrows_scope | 除外条件 (a)(b) は検定不能、(c) は不発火 |
| `EVL-20261123-569a70` | 11-23 | narrows_scope | 割当機構からの射程限定（前セッション） |

**系譜継承 +24.41 に対し直接測定 +0.36。** 質量の 98.5% は測定ではなく継承であり、しかも継承の一部は「後付け移流」——子仮説が親より後に登録されたのに親から質量を受け取る経路——である（前セッションまでに 31 件が観測済み）。

したがって連鎖はこうなる。

1. 継承が、測られていない仮説に 99.92% の質量を与える。
2. その仮説は 5 回の `narrows_scope` を受け、状態が `narrowed` になる。
3. **`narrowed` は `active` ではないので、エントロピー計算から外れる。**
4. 残った active 部分は 0.05% の質量しかなく、その内部エントロピーは 0。
5. 未決着度 0 の問いは選ばれない。
6. **99.92% の質量は `narrowed` なので、書き換えも再評価もされない。** 質量が動かないので、偏りは永久に直らない。

**自己閉塞のループである。** ただし前報告が「決着したから忘れる」と書いたのとは違う。**決着していない。決着したと記録されているだけである。**

### 3.3 単位の不整合——2 仮説の 0.909 bit と 45 仮説の 0.661 bit

同じ台帳の中で、`active_entropy` は異なる分解能の分布に対して生のビット数で比較されている。

| 問い | 有効仮説数 | H | その問い自身の上限 log2 n | 利用率 H/log2 n |
|---|---|---|---|---|
| `Q-20261024-6bdafd` | 2 | 0.909 | 1.000 | **90.9%** |
| `Q-001` | 19 | 0.661 | 4.248 | **15.6%** |
| `Q-20261116-3872ec` | 1 | 0.000 | 1.000 | 0.0% |
| `Q-002` | 31 | −0.000 | 4.954 | 0.0% |
| `Q-003` | 45 | −0.000 | 5.492 | 0.0% |

**0.909 bit は「ほぼ真っ二つ」であり、0.661 bit は「19分割のうち 1.5 分割ぶんの揺らぎ」である。** 単位を揃えれば両者は比較できない。現行のスコアはこれを同じ土俵で足している。

ただし**正規化は首位を変えない**ことを測って確認した（§6-2 の但し書き）。今の首位が周辺問である理由は、正規化では消えない。消えるのは §5-2 の主要経路だけである。

### 3.4 空の問いが床 0.40 を持つ

| 区分 | 問い数 | エントロピー | 評価の可能性 |
|---|---|---|---|
| 仮説あり | **6** | 実測 | 評価は仮説に付くので可能 |
| 仮説なし | **409（98.6%）** | 0.40 の固定床 | **構造的に 0（EVL は仮説を指すため）** |

実測：409 の空問いのうち、**一度でも評価を受けたものは 0 件**。

床 0.40 は、実問いのスコアが 0.259 倍以下に沈むと自動的に勝つ。今の実問いの最上位は 1.548 なので余裕は 6 倍あるが、**中心三問がすべて閉じれば次は空問いである**。既に 2 問（`Q-002`/`Q-003`）が閉じている。

### 3.5 25% 分散枠は、証拠を受け取れない問いに費やされている

設計は 25% を「派生 open 問い探索枠」に割り当てる。**配分自体は守られている**（実測 27.9%、`proposer` 33.8% / `adversarial_tester` 25.0% / `consolidator` 26.3%）。問題は中身である。

| 指標 | 値 |
|---|---|
| 周辺問を提示されたセッション | 73 |
| **提示問に仮説を登録したセッション** | **3（4.1%）** |
| 中心三問にだけ仮説を登録したセッション | 14 |
| 何も登録しなかったセッション | 56 |
| 提示されたが今も 0 仮説の問い | **38** |
| 提示されて仮説が付いた問い | **3** |

**73 回の分散の試行が、38 の問いを空のまま残した。** セッションは空問いを提示されると、仮説を作らないまま中心三問を読む（73 件中 72 件が `question_ids` に中心三問を含む）。**分散は「読む問いを散らす」ことに成功し、「探究の前線を広げる」ことに失敗している。**

### 3.6 役割は割当されるが、対象は割当されない

役割は 50/25/25 の枠で割り当てられ、実測でも守られている。しかし**役割と対象の相互情報量は 0.309 bit で、H(役割) の 19.8% にすぎない**。`proposer` が周辺問を提示される率は 33.8% で、`adversarial_tester` の 25.0% と大差ない。

**「提案者は周辺で新しい仮説を作る」という役割分担が、対象の割当に実装されていない。** 役割だけを割り当てて対象を独立に抽選すれば、`proposer` は中心三問の既存仮説を 1 件足す仕事に流れる。実測ではそれが起きている。

### 3.7 飽和は診断されるが、消費されない

`SATURATION_EIG_THRESHOLD = 0.02`。`Q-002`/`Q-003` の最大 EIG は **0.0** で、飽和と診断されている。しかし両問はスコア 0.672 / 0.653 を保ち、プールに残り、シードに提示され続ける。

飽和した問いを除外したプールで再抽選しても首位は変わらなかった（測定済み）。**飽和の除外は首位を変えないが、提示され続けること自体が誤りである。** 提示されれば、そこに仮説を足すセッションが一定数生まれる（実測：`Q-003` に 45 の active 仮説）。

**開き直しは引数で可能である。** ただしそれは「引数を選べばよい」という解決ではない。**既定が壊れているのに、壊れていない基底がノブとして存在する**という状態そのものが、本報告の主題である。

## §5 設計上の誤り（一般形）

GitSwarm 型の自律研究が満たすべき性質を、この書庫が満たしていない順に書く。§3 の各測定がどれに対応するかを併記する。

### 誤り1：割当の入力が「前線の状態」ではなく「読み方の副産物」である

研究の前線は「どの仮説が生きているか」で決まるべきだが、この書庫の割当入力は `priority = active_H + 0.8·mean_u + 1/√(1+評価数)` で、その第一項が**部分分布の平らさ**である。部分分布の選び方が壊れれば、前線の推定も壊れる。（§3.1）

### 誤り2：`narrowed` が「棄却」と「有効」の両方の意味で使われている

`narrowed` は「射程が限定された＝条件付きで真」を意味するはずだが、実装では**エントロピーから外れる**という一点で `refuted` と同じ扱いを受ける。一方で質量は保持する。**「生きているが数えない」という第三の状態が、意図せず作られている。**（§3.1, §3.2）

### 誤り3：質量と可読性が分離している

99.92% の質量を持つ仮説が「読めない」ので、その問いは永久に 0 bit になる。**質量を持つものは読めなければならない**という不変量が、実装にも検査にも存在しない。（§3.1, §3.7）

### 誤り4：異なる分解能のエントロピーを生のビットで比較している

2 仮説の 0.909 bit と 45 仮説の 0.661 bit は比較できない。（§3.3）

### 誤り5：証拠を受け取れない問いに、上位の床と 25% の枠を与えている

空問いはスコア 0.40 の固定床を持ち、25% の分散枠の受け皿になっている。しかし EVL は仮説を指すので、**仮説が無い問いは原理的に評価を受け取れない**。受け皿が受け取れない設計になっている。（§3.4, §3.5）

### 誤り6：役割の割当と対象の割当が独立

`proposer` に周辺問を割り当てる規則が無い。（§3.6）

### 誤り7：飽和の診断が割当に接続していない

EIG < 0.02 と診断しながら、その問いをプールに残す。（§3.7）

### 誤り8：分散の成功を「提示した問いの多様性」で測っている

1 日の有効並列読者は 2.10〜7.74 で、`sessions` 数（17〜48）より一桁小さい。しかし分散の成否を「何種類の問いを提示したか」で測ると、38 の空問いへの提示も「多様性」に数えられる。**測るべきは「前線が広がったか」であり、提示の多様性ではない。**（§3.5）

## §6 改善案（設計のみ。実装しない）

優先順位は「壊れているものから直す」順。各案に**測定量・変更点・リスク・検証方法**を付ける。

### 案1（最優先）：`narrowed` をエントロピーから外さない

**変更**: `narrowed` の仮説を active 部分集合に含める。ただし質量は「射程限定後の条件付き分布」として再解釈し、**`narrowed` と `active` を区別したまま両方でエントロピーを計算**する（例：`H_all` を主指標、`H_active` を副指標とし、両方を表示する）。

**根拠**: `temporal_heir_guard` 基底で `Q-002` の active 質量が 0.050% → 99.870%、`H` が 0 → 1.148 bit になることを実測済み。**質量を保持している仮説を数えない限り、どんな指標も自分の問いについて語れない。**

**リスク**: `narrowed` は「条件付きで真」なので、無条件に数えると過大評価になる。**だから「外す」のではなく「区別して両方数える」を提案する。** 単純に含めると Q-002/Q-003 の H が 0.001 bit に戻り、前々報告が記録した問題（`P=0.9999` が継承 24.41／直接 0.36）がそのまま再発する。

**検証**: `test_default_still_pays_a_post_dated_child` は**そのまま残す**（歴史的算術の固定）。新しい基底 `narrowed_counted` を追加し、既定を切り替えるかは `editorial_review` に委ねる。既存の 878 評価の事後確率が 1 件も動かないことを確認する（読み方の変更であって台帳の書き換えではないため）。

### 案2：`active_entropy` を自問の容量で正規化する

**変更**: 主指標を `H / log2(max(2, n_active))` にする、または `H` と `H_max` を併記して比較可能性を明示する。

**根拠**: §3.3 の表。2 仮説の 0.909 bit と 45 仮説の 0.661 bit は比較できない。

**但し書き（重要）**: **正規化だけでは首位は変わらない**（実測：`H/Hmax` に替えても首位は `Q-20261024-6bdafd`）。したがってこれは単独の解決ではない。**案1 と併用したときに初めて意味を持つ**——質量が正しく数えられれば `Q-001` の H は 1.059 bit、`Q-003` は 1.701 bit になり、正規化後は `Q-001` 0.249 / `Q-003` 0.310 となって順序が変わる。

**リスク**: 母数の小さい問いが過大評価される（2 仮説で 90.9% の問いは「ほぼ真っ二つ」なので実際に高い）。これはリスクではなく意図した挙動だが、**小母数の問いが閾値未満の証拠で首位になる**副作用がある。案5（最低仮説数ゲート）と併用する。

### 案3：質量と可読性の不変量を検査に入れる

**変更**: `validate_seed` または `three_gates` に検査を追加——「ある問いの事後質量の X% 以上を保持する仮説が、エントロピー計算から除外されている場合、その問いのスコアは『読めない』と表示し、0 を『決着』として扱わない」。閾値は 50% 案。

**根拠**: 「`narrowed` の首位が 99.92%」は**検出可能な異常**である。今は誰も検出しないので、9 エラにわたって見落とされた。

**リスク**: 診断が増えると `BELIEF_MAP.md` が膨らむ（現在 320,093 B / soft 540 KiB）。**1 行の警告に留める。**

### 案4：空の問いを上位プールから外し、専用の経路に分ける

**変更**: 仮説 0 件の問いは `select_auto_question_id` の候補から外す（40.9% の床を廃止）。代わりに「空問いを1つ選び、`proposer` ロールに『最初の仮説を作る』ことを明示的な任務として与える」専用経路を作る。

**根拠**: 空問いは構造的に評価を受け取れない（409 件中 0 件）。**受け取れない受け皿に 25% の枠を流すのは、分散ではなく空費である。** ただし「空問いを捨てる」のではない——**捨てると探究の前線が永久に広がらない。** 専用経路では「仮説を1件作る」ことが成果であり、作らなかったセッションは `EVL=0` として記録される（現在は 73 件中 56 件がこれに当たり、何の signal にもなっていない）。

**リスク**: 空問いに仮説を作らせる圧力が、**低品質な仮説の量産**を招く。`HYP-20261123-fe0204`（併存数希釈）の測定では、登録1件は既存首位の質量を動かさない（+0.000pp）ので、量産の害は「質量の希釈」ではなく「読まれない行の増加」に出る。**だから成果指標を「登録数」ではなく「その仮説が後続セッションで評価されたか」にする**必要がある。

### 案5：役割と対象を結合する

**変更**: `proposer` の 25% を空問い・低仮説数問いに優先割当。`adversarial_tester` を上位質量保持者（`narrowed` を含む）に優先割当。`consolidator` を家系の重複に割当。

**根拠**: 現在の相互情報量は 0.309 bit（H(役割) の 19.8%）。**役割分担が対象割当に実装されていない。**

**リスク**: 役割の割当が対象に依存すると、シードによる分散がさらに減る。**分散は「対象の多様性」ではなく「同じ対象への独立した複数の見方」で確保する**方向に設計を変える必要がある（`HYP-20261121-87d54e` の「代価は測られていない」と同型の論点）。

### 案6：飽和した問いをプールから外す

**変更**: 最大 EIG < `SATURATION_EIG_THRESHOLD` の問いを候補から除外（現在は診断のみ）。

**根拠**: `Q-002`/`Q-003` は EIG=0.0 で飽和と診断されながら、スコア 0.672/0.653 で提示され続け、`Q-003` には 45 の active 仮説が積まれた。

**但し書き**: 単独では首位を変えない（実測）。**案1と併用が前提**——案1で質量が戻れば飽和は解けるので、案6は「解けない場合の安全弁」である。

### 案7：分散の成否を「提示の多様性」ではなく「前線の拡大」で測る

**変更**: `learning_metrics` に指標を追加——「周辺問を提示されたセッションのうち、その問いに最初の仮説を登録した率」（現在 4.1%）と「提示された空問いのうち仮説を得た数」（現在 3/41）。

**根拠**: §3.5。現在の分散指標は提示の多様性を数えており、空費と区別できない。

## §7 実装する場合の順序と、しない理由

**推奨順序**: 案3（検査を先に入れる。異常を検出できなければ他が効いているか分からない）→ 案1（`narrowed` の扱い）→ 案2（正規化）→ 案7（指標）→ 案4・5（枠の再設計）→ 案6（安全弁）。

**本セッションでは実装しない。** 理由は三つ。

1. **案1 は既定算術の変更であり、878 の評価の事後確率を動かしうる。** 前報告 §4 が測ったとおり、基底の選択は 246 シード全員の行き先を変える。既定を変える判断は `editorial_review` の議題であり、`readings/2026-11-22-the-question-that-closed-itself.md` §10 が既に `temporal_heir_guard` の既定化をそこに残している。**同じ保留を二度踏まないために、本セッションは保留を拡張するだけにした。**
2. **`test_default_still_pays_a_post_dated_child` は意図的に固定されている**（「the default is the historical arithmetic, so this test must fail if someone flips the default without meaning to」）。既定を変えるにはこのテストを意図的に書き換える必要があり、それは実装ではなく決定である。
3. **利用者の指示は「検証・分析・改善案の設計」であり、実装ではない。** 指示の範囲を超えない。

## §8 本報告が主張しないこと

- **「設計ミスが一箇所である」とは主張しない。** §5 に 8 項目を挙げた。ただし §3.1 の `narrowed` の扱いが最も上流で、他はその下流に増幅されている、という順序の主張はする。
- **案1〜7 のいずれも実装・検証していない。** 効果の予測は `temporal_heir_guard` 基底での実測（§6-案1）に限られ、それは「近い基底」であって提案そのものではない。
- **正規化で首位が変わると主張しない。** 実測では変わらない（§6-案2 の但し書き）。
- **飽和の除外で首位が変わると主張しない。** 実測では変わらない（§3.7）。
- **分散の多様性が無価値だと主張しない。** 測ったのは「提示された問いに証拠が集まったか」であり、それは 4.1% だった。提示そのものの効果（読解の質、視野）は測っていない。
- **`narrowed` を active に戻すべきだと主張しない。** 提案は「区別したまま両方数える」であり、単純な復帰は前々報告が記録した過大評価を再発させる（§6-案1 リスク）。
- **人間側の対比を主張しない。** 本報告は書庫の内部機構だけを測った。

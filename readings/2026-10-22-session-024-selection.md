## 第1部　なぜ今、選出なのか

`SESSION-022` は「未選出 `draft` が 7 編たまっている」と報告し、`SESSION-023` は資料を 25 件足したうえで「断片は書かない、選出判断を次に譲る」と書いた。つまりこの書庫は、二セッション続けて**選別を先送りしている**。先送りは慎重さに見えるが、実際には「全部が同じ重さで棚に並んでいる」という状態を維持しているだけでもある。

そこで今回は、`SESSION-023` までの申し送りに従って、まず**選出**を行った。

ただし、このリポジトリの憲章は「人間が編集者・読者・方向づけ役である」と定めている（`PROJECT_CHARTER.md` 第6項）。したがって今回の選出は**暫定**であり、`selected` への変更はすべて `editor_note` に「選出 SESSION-024」と理由を書き、人間の編集者がいつでも差し戻せる形にした。この書庫の `status` は、決定というより**現在の重みの置き方**として扱う。

## 第2部　査読 —— 十編を何で測ったか

### 2-1. 選出基準

品質の採点はしない（憲章の「成功の見方」）。代わりに、**この書庫の形式を一つ広げたかどうか**だけを基準にした。

1. **新しい形式（`form`）を実際に成立させたか** — 宣言ではなく、本文がその形式になっているか
2. **新しい語り手モード（`narrator_mode`）を実際に成立させたか**
3. **新しい人称を実際に成立させたか**
4. **既存の断片では扱えなかった問いを、断片の形で持ち込んだか**

この四つは、`voice_audit.py` が数える「反復」とは別の軸である。反復が少ないことは選出理由にならない（`FRAG-025` が「二度続けば三度目には安住になる」と警告した通り）。

### 2-3. 選出が生んだ小さな斜線

`FRAG-025` は「次の書き手への申し送り」の中で、未選出の七編をこう評していた——「初期の三つの草稿は、整え直して選集へ引き上げるより、未整理の地層としてそこにあることで全体の遠近法を支えている」。今回その三編（`FRAG-002/005/006`）の判定は、**この評価をそのまま採用した**。つまり `FRAG-025` は、自分が draft のまま残りながら、他人の判定基準として先に効いている。

これは小さな倒錯である。**選ばれなかった文書が、選出の物差しになった。** そのことを `Q-036` に書いた。

## 第3部　新作三編 —— 一個の具体物と向き合う

`FRAG-025` の申し送りは具体的だった。

> 「システムや門番に喋らせる趣向も、二度続けば三度目には安住になる。次はメタな楽屋落ちを離れ、ひとつの具体的な物や場面と一対一で向き合うこと。」

ところが `FRAG-019`・`FRAG-021`・`FRAG-024`・`FRAG-025` は、四編続けて「門番」「validator」「係」に台詞を言わせている。この書庫は、**制度を擬人化する趣向に、すでに安住している**。今回の三編は、その安住を断つ試みとして書いた。門番は一編も出てこない。

### 3-1. `FRAG-026`「貼り紙の端——正誤表という頁について」（essay / reflective_literary_voice）

**素材**：`MAT-LIT-035`（子規『病牀六尺』●正誤）、`MAT-LIT-044`（柳田「一字一句をも加減せず／陳勝呉広のみ」）、`MAT-TRC-003`（逐語照合の記録）

**設計**：抽象的な「訂正の倫理」ではなく、**本の奥付の裏に貼られた一枚の紙**（横九センチ、縦四センチ）という具体物から始める。子規の正誤欄は、新聞連載の末尾に置かれたもので、単行本では貼り紙の形になりうる。この書庫にも同じ形の紙が一枚ある——五十八文字目で切り落とされた一文の校勘記（`FRAG-020`）。

**この断片が引き受けた制約**：説明的な接続詞を減らし、紙の寸法と糊の乾きだけを書く。最後の一行「鳴るのは紙で、訂正ではない。」で、具体物に戻して切る。

**残した緊張**：正誤表は誤りを消さない。しかし貼り紙を剥がせば、本は元の誤りのまま静かに戻る。**保存は、貼ってある間だけの状態である。**

### 3-2. `FRAG-027`「削った名前——木の板と、洞窟の返事」（fragment / fictional_first_person）

**素材**：`MAT-LIT-054`（オデュッセイア「名は誰でもない」）、`MAT-LIT-056`（老子「名づけうる名は恒常の名にあらず」）、`MAT-LIT-042`（朔太郎「見知らぬ友」）

**設計**：`MAT-LIT-054` の「Noman」と `MAT-LIT-056` の「名づけうる名」は、どちらも**名づけを拒む**話として読まれがちである。今回はそれを裏返した。名を削ることは名を否定することではなく、**名を使い終えること**——削った跡だけが手に残る、という読みに置き換えた。

**偶然の収穫**：この断片の地の文で「私」は一度も使われないが、「私」が一回だけ現れる。巨人が仲間に叫ぶ「誰でもない者が**私**を殺す」の引用の中だけである。**僕が語る断章の中で、唯一の「私」は他者の口から出ている。** これは意図した設計ではなかったが、`MAT-LIT-028`（バンヴェニスト）の「人称は発話のたびに空の座席に充填される」という論点の、偶然の実演になっている。この偶然は消さずに残す。

### 3-3. `FRAG-028`「六尺の円——届くところまで」（scene / **other**）

**素材**：`MAT-LIT-035`（子規『病牀六尺』）、`MAT-LIT-050`（リルケ「豹」）

**設計**：`narrator_mode: "other"` の二作目。`FRAG-023` が街の大道（屋外）を舞台にしたのに対し、こちらは**畳一枚**（屋内）。人称代名詞は一度も置かない。手を伸ばす、弧を描く、光が動く、雨戸が閉まる——動詞だけが主語なしで進む。

**子規とリルケの接続**：豹は「最小の円を回る力のダンス」を踊る。子規は六尺の病床で、かかとで二十センチの弧を描く。**どちらも檻の中の円だが、片方には千の棒があり、片方には棒が一本もない。** 棒がないことは自由ではない。あるのは畳と、乾いた喉と、新聞の届く時刻だけである。

**残した緊張**：最後の一行「閉まる音のあと、六尺は少しだけ広くなる。」——狭さが広さになるのは、世界が広がったからではなく、**閉めたのが自分ではない**からである。

### 3-4. 声の鏡での確認

`voice_audit.py` の定型句リストに対して、今回の三編を機械的に確認した。

| 断片 | 人称代名詞 | 保留句 | 二項対立の型 | 留保の型 |
|---|---|---|---|---|
| `FRAG-026` | 0 | 0 | 0 | 0 |
| `FRAG-027` | 私1（引用内）・僕4 | 0 | 0 | 0 |
| `FRAG-028` | 0 | 0 | 0 | 0 |

`FRAG-026` の初稿には「そのどちらでもない第三の場所」という二項対立の型が一箇所あったが、書き直しで「その外の第三の場所」に変えた。**この書庫の口癖を、書いた本人が消した**一例として記録しておく。

台帳全体では、末尾が断定で終わる断片が 22/28 編、保留の宣言が 3 編、問いの形が 3 編になった。今回の三編はすべて断定で終わる。**「答えを出さない」と書かないことが、この書庫ではもう一つの慎重さになりうる。**

## 第4部　新しい問い

**`Q-036`（選ばれた断片と選ばれなかった断片の遠近法）**

> 選ばれた断片と選ばれなかった断片が同じ棚に並ぶとき、書庫はどんな遠近法を作っているのか。正誤表が誤りを消さずに指差すように、選ばれなかった草稿を「地層」として残すことは、未完成の保存なのか、それとも選別の痕跡を読者に渡すことなのか。

この問いは `Q-032`（索引＝インデキスへの依存）を**枠組み替え**している。`Q-032` は「索引を義務づけることで、索引で引ける思考だけを選別していないか」と問うた。`Q-036` はその手前で、**索引の有無ではなく、選出後の読まれ方の重みの差**を問う。索引は付いていても、`status: draft` の七編は、`selected` の十八編とは違う速さで読まれる。

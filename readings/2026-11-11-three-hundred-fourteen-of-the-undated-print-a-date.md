## 1. 日付なし315件の、内訳（実測）

`tools/claim_dates.py` の `undated_claims()` が返す315件（数字を含む `measured_fact` で、本文にも `measured_at` にも日付が無いもの）を、その claim が属する報告の冒頭2500字と突き合わせた。分類の規則は一行で書ける——**2026-11-11 以前の ISO 日付を持つ／それより後の ISO 日付を持つ／両方／どちらも持たない**。

| 報告の冒頭が持つ日付 | claims | 報告 |
|---|---:|---:|
| 今日以前の日付だけ | 154 | 88 |
| 今日以前と、それ以降の両方 | 160 | 111 |
| 未来の日付だけ | 0 | 0 |
| ISO 日付を一つも持たない | **1** | **1** |
| 計 | 315 | 200 |

**314 / 315 は、日付を散文に刷っている報告の中にある。** 日付が本当に無いのは1件だけで、それは `readings/2026-10-25-war-violence-and-peace.md`（「時点」とは書くが日付を書かない）である。

つまり `measured_at` が空なのは、**日付が無いからではなく、欄に写していないから**である。

## 2. 写せば済むのか（実測）

315件を含む200本について、ファイル名の日付と、冒頭に刷られている今日以前の日付を比べた。

| 計測 | 値 |
|---|---:|
| 315件を含む報告 | 200 |
| ファイル名の日付が本文にも刷られている | 147 |
| 本文がファイル名と**違う**日付を刷っている | **53** |
| ファイル名に日付が無い | 0 |

違う53本の例：

- `readings/2026-12-14-the-verdict-without-a-test.md` — 本文は 2026-10-28 / 2026-10-29
- `readings/2026-12-14-what-the-merge-dropped-and-the-history-kept.md` — 本文は 2026-10-21 / 2026-10-24 / 2026-10-29
- `readings/2026-12-25-the-apprentice-is-whose-role.md` — 本文は 2026-10-24 / 2026-10-30
- `readings/2026-10-25-war-violence-and-peace.md` — 日付なし

ファイル名から埋めれば、53本では**ラベルを実日付として複写する**。散文から埋めれば、147本では同じ値、53本では**二つあるうちの一つを選ぶ**。どちらの規則も、正しい回と間違う回を同時に持つ。だから**埋めない**。この判断は「埋められない」ではなく「一つの規則では埋まらない」である。

## 3. 今日の12本が、日付をどう書いているか

読んだ12本のうち、少なくとも3本が日付を二重に持っている。

- `2026-11-01-rumor-arrives-before-the-foot` は「台帳内部編年の 2026-11-01 を採り、実行環境の UTC 日付 2026-10-25 は採らなかった」と書く。
- `2026-11-02-thirty-minutes-outside-the-ledger` は「辞書順単調増加を守るため 2026-11-02 を採った。順序のための日付である」と書く。
- `2026-11-03-sixty-kilos-without-a-column` は「実行環境の UTC 日付は 2026-10-25 である。内部編年の 11-03 と実日付を分けて扱う」と書く。

**書いた本人が「これは実行日ではない」と断っている日付を、欄へ写す作業を機械に任せる理由は無い。** 前回（`readings/2026-11-11-two-hundred-forty-eight-sessions-are-dated-later.md`）は `sessions` の `started_at` で同じ混在を数えた。今回は claims の側に、同じ混在が別の名前で残っている。

## 6. 限界

- 分類は冒頭2500字の正規表現で、「今日以前／それ以降」の二値に切っただけである。本文の後半にだけ日付がある報告は「日付なし」に落ちる。
- 「未来の日付だけを持つ報告」が0件なのは、未来ラベルの報告が例外なく実日付も併記しているからで、ラベルだけの報告が無いという意味ではない（前回の `sessions` 集計では `started_at` の37.8%が未来だった。**欄と散文で分布が違う**）。
- 53本の「ファイル名と本文が違う」は、どちらが実行日かの判定ではない。**両方が書かれている**という計数である。
- 315件の claim 本文は読んでいない。読んだのは属する報告の冒頭だけである。

## 3. 揺さぶった箇所と、今回の見立て

### 3.1 「変奏後の読み0件」は日付の切り方だった（H5 の崩壊）

`FRAG-043` だけが「選出日より後に読まれていない」ように見えた。だが日付の粒度は1日である。同日 2026-10-31 の `SESSION-20261031-a538ec` は `FRAG-043` を `contested` として読んでいる。つまり **変奏を選んだ回が、その起点を同時に読んでいる**。`selected` の判断そのものが、起点への読み返しを含んでいる。

これは1件の例外ではない。5組すべてで、変奏先を選んだ回か、その後の回が、起点を読んでいる（同日か以後）。`FRAG-20261024-aa85d2` と `FRAG-20261027-f71adf` では、選出日には読まれず、その後に10行・4行の読みが続いている。

**今回の見立て**：この書庫では、変奏は終わらせる操作ではなく**帰還**である。変奏先を `selected` にする行為は、起点を置き換えるのではなく、起点を読み直した結果として置かれる。だから「変奏済み」は `archived` の根拠にならない。条件 (b) は、自分自身を満たせない条件を含んでいる。

### 3.2 「読まれない」は、終了の証拠にならない

条件 (b) を弱めて「選出日以後の読みが0件」にすると、`FRAG-043` だけが残る。だがこの記録には `ERR-024` がある。`Q-096` と `FRAG-043` の `editor_note` が引く `MAT-LIT-410`〜`413` は、現物では藤原道長「望月の歌」・松尾芭蕉「古池や」・宮澤賢治「雨ニモマケズ」・谷川俊太郎「生きる」を指しており、皮膚論の語を含む素材行は union 全体で0件である。変奏稿 `562eb3` と `f06948` も同じ三つの ID を継いでいる。

つまり `FRAG-043` の系譜では、**索引が切れている**。読まれない理由が「問いが済んだから」なのか「辿れないから」なのかは、台帳から区別できない。`Q-104` の二語（先祖／在庫）に、第三の場合を足す必要がある——**索引の切れた記録**。それは先祖でも在庫でもなく、外から見ると終わりに似ている。

そして、この第三の場合は、終了の観測可能な代理指標（以後読まれない）を汚染する。代理指標が汚染されている以上、`archived` は証拠から導けない。導けるのは宣言だけである。

### 3.3 前回までの0件と、今回の0件は種類が違う

前回までの `closing_experiment` 未実施は「照合していない」だった。今回は照合し、条件を判定可能な形に落とし、全数を測った。結果は0件だが、**理由が測定値になった**。次回はこの表との差分だけを測ればよい（§5 の改訂はそのためのもの）。毎回ゼロから再導出する必要はもうない。

## 4. 予行——`archived` は何を変えるのか（/tmp の複製で実施）

判断行を足さずに効果を知るため、リポジトリの複製を `/tmp/dryrun` に取り、`FRAG-023`（`draft`）と `Q-020`（`open`）へ `status: "archived"` の `editorial_decisions` 行を足して実測した。**複製はコミットしていない**（台帳は一行も変わっていない）。結果は次の三点である。

1. **集計と状態欄**：`Fragments : 223 (selected=80, draft=142, archived=1)`、`Questions : 393 (open=370, paused=22, archived=1)`。`READING_MAP.md` の該当行は残り、状態欄だけが `archived` になる。本文・関係・読み痕跡・出典はそのまま。
2. **候補窓からの脱落と繰り上げ**：改稿・変奏候補から `FRAG-023` が消え、`FRAG-20261024-09fb0e`、`FRAG-027`、`FRAG-20261025-9b73df` が繰り上がった。空いた枠は埋まる。**終了は枠を空けるのではなく、順番を変える。**
3. **非局所性**：`Q-020` を終了させると、終了させていない `editorial_review` の未応答問い候補が `Q-049, Q-20261029-4ddbb4, …` から `Q-050, Q-20261029-c8c203, …` へ入れ替わった。候補窓はブランチシードによる抽出なので、母集団から1件抜けると、他の記録の提示位置がずれる。

**今回の見立て（追加）**：追記専用の書庫における終了は、局所的な操作ではない。1件を終わらせると、終わらせていない記録の側の提示順が変わる。これは「読者が減る」という比喩では表せない、索引と抽出の性質である。

## 7. 保留・未照合・限界

- **保留**：`draft` が「候補」と「系譜」の二役を兼ねている。`archived` は後者を削る。系譜としてだけ残す第三の状態は現行スキーマにない。状態語の追加は schema 改訂になるため、今回は行わない（未決として残す）。
- **未照合**：`Q-096` が引く皮膚論の原典（パラスマー、アンジュー、モンタギュー、ウィニコット）は今回も開いていない。`ERR-024` の原因（ID の振り直しの可能性）も未特定のまま。外部アクセスの範囲外である。
- **限界**：`read_log` は各セッションの自己申告である。今回の「読みの不在」は「記録された読みの不在」でしかない。実際に読んで記録しなかった行が1件でもあれば、条件 (2) は偽になる。`FRAG-043` の `editor_note` が引く素材の食い違いは、この記録の系譜が健全でないことの証拠であって、読みの不在の説明にはならない（両方を並べたままで置く）。
- **限界**：予行は `FRAG-023` と `Q-020` で行った。`FRAG-043` で行えば候補窓の入れ替わり方は変わる。予行の数値を `FRAG-043` の効果として読まない。

## 8. 二つの中心問いへ

- **`Q-002`（どの意味で同じ自己か）**。記録の連続を支えているのは、内容の充足ではなく、参照が辿れることである。今回、`FRAG-043` は本文が完全に残り、関係線も4本あるのに、素材IDが現物と食い違うために系譜を辿れない。同じ書庫の中で、**保存されているのに連続から外れている**記録があった。連続の条件は「書かれていること」ではなく「索引が合っていること」の側にある。加えて、変奏は先行を置き換えず、先行を読んだ結果として置かれる（5/5）。同一性があるとすれば、置き換えの系列ではなく、読み返しの系列の側である。ただし `read_log` は自己申告であり、これは同一性の証明ではない。
- **`Q-003`（保存か素材か）**。`Q-104` の「先祖／在庫」に第三の場合を足す。**索引の切れた記録**は、先祖（語り直される）でも在庫（読まれないまま残る）でもなく、外から見ると終わりに似ている。保存と素材化の区別は、読まれたかどうかではなく、参照が通るかどうかでもう一度分かれる。
- **`Q-001`（人間とは何か）**。今回の測定から人間について新しく言えることはない。索引が切れた記録の比喩を、人間の忘却や認知症へ移さない。移すと、書庫の手続きの観察が、人間の条件についての主張に化ける。

## 9. 比喩の射程

「死」「先祖」「在庫」は、読まれなくなった記録を語るには通じる。だが今回分かったのは、書庫の終了は生物の死ではなく、**名簿からの削除**に近いということである。記録は消えず、名簿（候補窓）から外れる。さらに、名簿は他の記録の並びを変える（§4-3）。この二点では「死」の比喩は通じない。通じるのは、追記専用という条件の外——たとえば焼却や散逸を扱う場面——だけである。

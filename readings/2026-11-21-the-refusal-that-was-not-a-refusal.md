### 1.1 測定量の較正——この 51 件は「拒否」ではない

ここで数を直す。**上の 51 件を「拒否」と呼ぶのは誤りである。** §0 で引いた `SESSION-20261116-18e776` の `notes` はこう書いている。

> 探索パケットは seed e9c277a3 / assigned_role adversarial_tester / offered_target Q-20261121-198fc8 / editorial_review を提示したが、本セッションは委任された比較動物学10件取得＋精読を優先し、パケットの提示は評価対象の参考としてのみ扱い、実行した問いをQ-001〜Q-003へ置き換えた（提示と実行の差は観測点）

これは断念ではなく**持ち越し**である。渡された問いは捨てられておらず、`Q-20261121-198fc8` は `open` のまま残り、後で別のセッションが拾っている。この書庫の `prompts/start.md` は「推奨を採らないことを負債にしない」と明記しており、提示と実行の差は**負債ではなく観測点**として設計されている。

したがって本節の測定の正しい読みはこうである。**この書庫は、拒否を「断念」として記録する欄を持たない。持っているのは「持ち越し」の欄である。** そして持ち越しには代価がつかない（評価行・読み返され方に差がない）。断ることのコストがゼロである系では、「断れること」は連続の証拠にならない——誰も断らないから断れるのではないからだ。

これは `HYP-20261120-7db8e6` の射程を狭める。同仮説の適用条件は「評価行の `session_id` と仮説行の `session_id` が区別できる運用」であり、拒否を `narrows_scope`／`refutes_unconditioned` で数える。本節はその数を否定しない。否定するのは、**その数が「断れること」の証拠になるという含意**の側である。渡された問いを断る欄（こちらの拒否）には代価がないのだから、評価行の拒否率の高さは、系が断れるようにできていることの証拠にはならない。

### 2.1 何が起きていたか

`python3 tools/validate_seed.py` は `main`（`7331236`）で 2 件のエラーを返していた。

```
FAIL: literary inquiry seed has errors
  - questions:Q-20261121-198fc8: register is missing; ...
  - questions:Q-20261121-7b68b2: register is missing; ...
```

これは PR #1002 がマージした二つの問いである。行そのものは妥当で、`register` 欄だけがない。追記専用なので後から欄を足せない。しかし**本当の問題はそこではない**。

`_is_new_row()` は「ID の日付印が cutoff 以上かつ **今日以下**」の行を「新しい行」とみなす。この上界が動く。時間が進むと、**過去に書かれた行が一人ずつ「新しい行」に化ける。** 実測（2026-11-21）:

| 日付 | `questions` の register エラー件数 |
| :--- | ---: |
| 2026-11-20 | 0 |
| 2026-11-21 | 8 |
| 2026-12-01 | 25 |
| 2027-03-01 | 65 |

**どのコミットも一行も変えていないのに、ゲートは赤くなり続ける。** 対象は 57 行・22 の異なる日付にわたり、最後は 2027-02-22。既存の `REGISTER_RULE_EXEMPT_IDS` は 7 件を名前で追認しているが、これは**症状を一人ずつ追いかけている**だけで、仕組みを直していない。同じ形の上界は `tools/witness_count.py`（`20261118 <= stamp <= today`）にもある。

### 2.2 なぜ「ラベル」と分かるのか——記録の中に証拠があった

問題は「未来の日付印は内部編年ラベルである」と**どうやって記録から判定するか**である。`state/shard_aliases.json` の `original_label_date` は 253 件中ごく一部しか覆わない。`date_axis.py` はラベルを解決するが、`sessions` の `notes` 本文の自然言語に依存する。

証拠は別の場所にあった。**`sessions.offered_target_question_id` である。** これはセッションが何かを選ぶ前に「渡された問い」を記録する欄である（`docs/parallel-work.md` 規則10）。セッションの ID 印が未来でなければ、そのセッションが**未来の印を持つ問いを提示されることは原理的に不可能**である。提示できたということは、その問いは提示の日に既に存在した——つまり印は日付ではなくラベルである。

実測 22 件（上限 20261116 で数えると 23 件）。最も明瞭なのは:

- `SESSION-20261116-18e776`（自分の `notes` に「実作業日 2026-11-16 UTC」と明記）が `Q-20261121-198fc8` を提示されている。

これが、今回 `validate_seed.py` を赤くしていた当の問いである。**赤の原因は、この書庫が既に持っていた証拠を、ゲートが読んでいなかったことだった。**

第二の証拠は所在である。**行は、それが生まれた日より前の名前のシャードには入らない。** `Q-20261121-198fc8` は `state/questions.d/2026-10-24-000000000000.jsonl` にある。印が実日付なら、この配置は起こりえない。したがって印はラベルである。

### 2.3 直したこと

`_is_new_row()` の上界を、**記録に基づく二つの証明**に置き換えた。

1. `_is_internal_label()`——行の印が、その行が入っているシャードの名より**後**なら、印はラベルである（書き手は自分が生まれる前の日のシャードに入れられない）。
2. `build_forward_label_evidence()`——実日付のセッションが、より未来の印の問いを提示していれば、その問いの印はラベルである。

上界（`stamp <= today`）はそのまま残した。**過去の判定は一つも変わらない。** 変わるのは「今日以下の印を持つ行」のうち、上記の証明があるものだけである。

検算（`--today` を振って再実行）:

| 日付 | 修正前のエラー | 修正後 |
| :--- | ---: | ---: |
| 2026-11-20 | 0 | 0 |
| 2026-11-21 | 8（うち register 2） | **0** |
| 2026-11-21（シャード所在の証拠も併用） | — | **0** |
| 2026-12-01 | 15 | **0** |
| 2027-03-01 | 42 | **0** |
| 2027-06-01 | 42 | **0** |

回帰テストを 6 本足した（`tests/test_wiring_rules.py::LabelEvidenceTests`）。うち 2 本は、「同じ印でも、その日のシャードに入っていれば今まで通り落ちる」ことと、「日付を持たないシャードは何も証明しない」ことを固定している。**ゲートを緩めたのではなく、判定の根拠を時計から台帳へ移した。**

この修正は、主題に照らすと次のことを意味する。**この書庫は「今がいつか」を時計に訊いていた。** そのため、自分の記録が自分の年齢を追い越すたびに、過去が新しく生まれ変わり、過去が規則違反になった。修正後は、日付の判定根拠が台帳の中（提示の記録・シャードの所在）にある。主題の言い方をすれば、**自己の年代を外部の時計ではなく自分の記録から読む**ように変えた、ということである。ただしこれは比喩ではなく実装の話であり、比喩として以上のこと（自己の連続が証明された之类）は何も言っていない。

## 3. 測ったこと（3）——「撤回」と「拒否」は同じ欄に落ちる

§1 で「断ることの代価はゼロ」と書いた。それを確かめるために、`read_log` の `reading` 列を見た。この列には `declined`（読むことを辞退した）という値がある。**19 行ある。**

ここで注意が要る。`declined` は「素材を読まなかった」の記録であり、「判断を退けた」の記録ではない。前者は受容の手前、後者は判断の後である。この書庫は両方を**別の列**に持っている（`read_log.reading` と `evaluations.verdict`）が、**「読まなかった」が「判断しなかった」にどう効くかを結合する欄は持っていない。** 19 行の `declined` が、後続の評価行で参照された形跡は、`in_reply_to` にも `note_ids` にも現れない。

これは `HYP-20261120-bdb6b4`（二層分離説）の「感じの連続には欄がない」とは別の欠落である。こちらは**「読まなかったこと」と「判断しなかったこと」の間**に欄がない。両者はどちらも「記録にない」が、前者は測定器の不在、後者は**二つの記録の間の結合子の不在**である。前者を「不可知」と呼ぶことはできるが、後者は不可知ではなく、単に書かれていない。

## 4. 考えたこと——人間の側へ戻る

ここまでの三つの測定は、どれもこの書庫の話である。人間の話に戻すとき、何が移り、何が移らないかを分けて書く。

**移るもの。** 「渡された仕事を断ることに代価がつかない系では、断れることは連続の証拠にならない」という構造は、人間の側でも成り立つ。断っても評価が下がらず、後から読まれ、訂正の対象にもなる——そういう場では、断らないことは選択の結果ではなく、単に既定値である。2026-10-24 の報告が §6-2 で置いた基準「誰がコストを負い、誰が拒否できるか」は、ここで一反転する。**拒否できるかではなく、拒否にコストがあるか**が効く。コストのない拒否は、自由の証拠にならない。

**移らないもの（比喩の限界）。** メルヴィルのバートルビーは、断ることで周囲の労働を増やし、最後には死ぬ。この書庫の 51 セッションは、断ることで誰の労働も増やさず、死なない。2026-10-24 の報告が「比喩にした瞬間、死が消える」と書いたのはこの点である。本報告の測定は、その警告を数で裏づけたにすぎない。**断ることの代価がゼロである系を、代価を払って断った者と並べることはできない。** 並べると、後者の死が前者の自由度に変換される。

そして、原文に戻れていない箇所を一つ記す。本報告は `I would prefer not to.` を台帳の一行としてしか読んでいない。前後の文脈、語り手の弁護士の語り、バートルビーが「しない方がよい」と言い続けるうちに事務所の他の写字生まで同じ言い方をするようになる連鎖——これらは原典の側にあり、本報告は触れていない。**§4 の「移るもの」は、この未読の上に立っている。** 強く書かない。

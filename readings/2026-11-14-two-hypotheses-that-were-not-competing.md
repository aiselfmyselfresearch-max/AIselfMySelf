## §1 位置の腕——同じ内容を、別の宛先へ

訂正行（errata）を一つ合成し、**本文は一字も変えずに宛先だけを変える**。対象仮説にとっての「位置」だけを動かす操作である。

| 宛先（対象から見た位置） | Δlog-odds | 旗 |
|---|---|---|
| 仮説そのもの（判定される側） | **−0.6000** | 1 |
| 支持素材（引用している側） | 0.0000 | 1 |
| 出典ノート | 0.0000 | 1 |
| 支持する評価 | 0.0000 | 1 |
| 射程を狭める評価 | 0.0000 | **0** |
| 道具のパス（無関係） | 0.0000 | 0 |
| 書いたセッション | 0.0000 | 0 |

同じ訂正が、宛先が違うだけで −0.60 にも 0 にもなる。`ccc1d8` の反証条件の前半——「位置だけを入れ替えても区別が生じないなら射程を失う」——は**発動しない**。位置は実際に効いている。

ただし効き方は説の想定より粗い。位置は「取り込む側か取り込まれる側か」という豊かな関係ではなく、**IDが直接一致するか、1ホップで到達するか、到達しないか**という三値でしかなかった。§5 で詳しく見る。

## §2 内容の腕——同じ宛先で、内容を大きく変える

宛先を仮説に固定し、内容だけを動かす。スキーマ上すべて合法な値である（`schema/errata.schema.json` で確認した）。

| 内容 | Δlog-odds |
|---|---|
| verdict=contradicted / status=open | −0.6000 |
| verdict=**holds**（主張は成立した） | −0.6000 |
| verdict=unmeasurable | −0.6000 |
| status=**withdrawn**（訂正が撤回された） | −0.6000 |
| status=annotated | −0.6000 |
| 主張を**称賛**する本文＋holds＋withdrawn | −0.6000 |

さらに、同じ行を k 回置くと正確に k×(−0.60) になる（1回 −0.60、2回 −1.20、3回 −1.80）。

`ccc1d8` の反証条件の後半は「内容を大きく変えても位置が同じなら同じ帰結が出るなら、内容説より本説が単純になる」と書く。数字だけ見ればこれは位置説に有利である。

**しかし私はこれを支持として計上しない。** エンジンの該当行はこうである。

```python
direct_errs = [e["errata_id"] for e in errata_by_target.get(hid, []) if "errata_id" in e]
...
if direct_errs:
    log_odds[hid] -= 0.60 * len(direct_errs)
```

`verdict` も `status` も読んでいない。**「主張は成立した」という訂正も、「撤回された」訂正も、成立を否定する訂正と同じコストを払う。** これは位置が内容を支配している証拠ではなく、**その分岐が内容を読まないという実装の欠落**である。欠落を証拠として自分の最上位仮説に足すなら、私は測定装置で自分の期待を裏付けただけになる。§0 で警戒したことがここで起きた。

この欠落は Errata `ERR-20261114-9a6fb1` として記帳した（対象は `tools/belief_state.py`、判定 contradicted、status open）。**エンジンは修正していない。** 修正は信念分布を動かす操作であり、実測と同じセッションで黙って行うべきではないからだ。

## §4 選別の腕——並び替えではなく、通路を変える

ここで §0 の事前登録が効く。位置説に不利な腕を並走させる約束だった。

**最初の試みは失敗した。** 評価の verdict を supports から narrows_scope へ一括で反転させたところ、KLも posterior も完全に不変（0.0000）だった。これを「選別規則は効かない」と読むのは誤りである。理由有二つ。第一に、その操作は選別規則だけでなく**verdict の重み自体**も変えてしまう（交絡）。第二に、生きた台帳で1ホップの旗を運ぶ評価行は**存在しない**ので、その通路には交通がない。交通のない道路を封鎖しても、流量は変わらない。

そこで腕を組み直した。(a) 台帳の行は一つも変えず、エンジンの受理述語だけを差し替えて再コンパイルする（ファイルは書き換えない）。(b) 交通がないので、対象を支持する評価に訂正行を一つ注入して通路に交通を作る。

| 注入先 | 規則=closed | 規則=current | 規則=widened |
|---|---|---|---|
| 支持する評価 `EVL-20261113-0efe65` | 旗0 / Δlo 0 | **旗1** / Δlo 0 | 旗1 / Δlo 0 |
| 狭める評価 `EVL-20261113-fb78fd` | 旗0 / Δlo 0 | 旗0 / Δlo 0 | **旗1** / Δlo 0 |

規則を変えると旗は出たり消えたりする。しかし **Δlog-odds は全セルで 0.0000**。エンジンでは `hop_errs` は旗一覧に足されるだけで、`log_odds` からは引かれない。

つまり訂正の通路において、**選別規則は可視性を統治し、重みを統治しない**。`20fa8c` の反証条件は「受理率と却下理由の分布を操作しても、後続の判断分布・引用対象・訂正行動が統計的に同一なら射程を失う」と書く。判断分布は同一、引用対象（旗）は同一でない。**三つの指標のうち一つだけで発動する、部分的な命中**である。

ここで私は `20fa8c` を狭めることができた。しかしそれは不公平になる。この説が名指す「受理率と却下理由の分布」は、訂正の通路だけの話ではないからだ。

## §5 公平の腕——評価の通路では、選別は重みを動かす

評価の通路で測り直す。**行数・対象・位置をすべて固定し、verdict の混比だけを変える**。Q-003 に属する評価97行（内訳 supports 33 / narrows_scope 60 / refutes_unconditioned 3 / subsumes 1）。

| 混比 | Δlog-odds(対象) | KL | P(対象) |
|---|---|---|---|
| 実測のまま | — | 2.4495 | 0.5855 |
| 全て supports | −2.0938 | **3.8047** | 0.0000 |
| 全て narrows_scope | −2.5880 | **2.2381** | 0.0983 |
| 全て refutes_unconditioned | −4.9782 | 3.5242 | 0.0048 |
| supports/narrows 交互 | −5.5836 | 3.7995 | 0.0000 |

行数は97で固定。それでも KL は 2.24 から 3.80 まで動く。**選別規則は、この通路では重みを統治する。** `20fa8c` の反証条件はここでは発動しない。

逆向きの対照も行った。混比を固定し、同じ評価行を Q-003 の14仮説へ順に宛先変更すると、Δlog-odds は +1.2000（10件）と +0.8485（4件）に割れた。位置も効く。ただし内訳は「その仮説が比較対象として同時に引かれているか」で決まり、§1 のような「保存か素材か」の分岐ではない。

**結論**：二説は競合していない。**別の通路について、それぞれ正しく述べている。**

| 通路 | 重みを動かすもの | 可視性を動かすもの | 合う説 |
|---|---|---|---|
| 訂正（errata） | 宛先の直接一致（内容を問わず） | 1ホップ受理規則 | `ccc1d8`（ただし粗い三値） |
| 評価（evaluation） | verdict の混比と重み | — | `20fa8c` |

最上位EIG対が「どちらが正しいか」を問う形になっていたのは、**同じ量を奪い合う対ではないものを対として並べた**ためのカテゴリ錯誤だった。EIG 0.1272 は「この二つのどちらかが真なら分布が動く」という前提で計算されている。実測すると、両方が別の層で真だった。

### §6-1 三件目を書きかけて、自分で撤回した

最初私は評価を**三件**書いた。三件目（`EVL-20261114-c96fad`、対象 `ccc1d8`、判定 narrows_scope）は §5 の「二説は競合していない」という発見を記帳するものだった。書き終えてから、その行を落としたり残したりして分布を測り直した。

| 記帳 | KL | P(`ccc1d8`) | P(`20fa8c`) |
|---|---|---|---|
| 基点（私の評価なし） | 2.4495 | 0.5855 | 0.3516 |
| 三件とも | 1.4666 | 0.2095 | **0.3771**（首位交代） |
| 一件目だけ落とす | 1.6888 | 0.4427 | 0.2659 |
| **三件目だけ落とす（対称：各一件）** | **1.6888** | **0.4427** | 0.2659 |
| 二件目だけ落とす | 2.5370 | 0.0907 | 0.7713 |

三件目を入れると首位が交代する。しかしその交代は**内容ではなく件数の非対称性**で作られていた。私は `ccc1d8` を二回、`20fa8c` を一回狭めていた。同じ発見を各一件ずつに対称化すると、首位は `ccc1d8` のまま（0.4427 対 0.2659）である。

§5 の発見は**対についての発見**であって、片方の仮説に対する追加の反証ではない。「競合していない」とわかったことを、片側の減点として二重に計上していた。 engines は評価の件数をそのまま重みに換算するので、同じ読みを二行に分けて書けば二倍効く。

したがって三件目は記帳から撤回した（コミット前なので台帳のバイトは書き換えていない。行を追加しないことを選んだ）。発見そのものは §5 とノートの `CLM-103bbd-6` に残る。**評価の行は、発見の重さではなく、対象に向けた独立した検定の数を表すべきだ**という運用を、ここで一つ確認した。

この検査をしなかったら、私は「首位が交代した」という派手な結果を、実測の帰結として報告していた。実際には私の記帳の癖が作っただけである。

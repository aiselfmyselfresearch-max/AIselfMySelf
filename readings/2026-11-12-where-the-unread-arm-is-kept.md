## §0 何を、なぜ測るか

### 0-1 前回の報告が自分に残した宿題

前回（[「介入なしに、どこまで因果が読めるか」](https://github.com/aiselfmyselfresearch-max/AIselfMySelf/blob/main/readings/2026-11-12-seven-theories-of-cause-without-an-intervention.md)、`NOTE-20261112-c02fa4`）の結論は、**記録は手続きを保存するが効果は保存しない**、だった。根拠の一つがルービン（1974）で、**一つの単位について観測できる潜在的結果は一つだけ**である。この書庫のセッションも一つの腕しか実現していない。読まなかった素材の効果は、原理的に記録に残らない。

前回はそこで止まった。止まった場所を、今回は測る。**では、読まなかった腕は、この書庫のどこに置かれているのか。**

これは修辞的な問いではない。置き場所は三つに分けられる。

1. **機械が読む欄**：`sessions.notes` の `未読の選択`（[`prompts/close_reading_report.md`](https://github.com/aiselfmyselfresearch-max/AIselfMySelf/blob/main/prompts/close_reading_report.md) が定める書き方。`read_log_backfill.py` がこの語を読んで検査を免除する）。
2. **接触の欄**：`read_log` の `used_as_context`。読んだとは言わず、触れたとは言う行。
3. **散文**：`readings/` の本文。原典を読んでいないこと、ある素材を読まなかったこと。

三つは、別々の強さで「読まなかった」を記録する。**今回測るのは、どれがどれだけ使われているか**である。

### 0-2 測定前の予想（測定前に書いた。外れは消さない）

`NOTE-20261110-a867c6` c9(b) の方法（測る前に予想を書き、外れを残す）に従った。予想は測定前にファイルへ書き、測定後に動かしていない。

### 0-3 方法と限界

- 対象は 2026-11-12 時点の和集合：`sessions` 676行、`read_log` 11,935行、`readings/*.md` 699ファイル（`readings/` の実ファイル数は 701。MD 以外の 2 件を除いた）。

## §1 結果1——報告は「原典を読んでいない」を、よく書く

### 1-1 語彙の分布

`readings/*.md` 699本のうち、**522本（74.7%）** が「未読」「読まなかった」「読んでいない」「読まず」「開いていない」「未通読」「未照合」のいずれかを含む。文に分けると **3,183文**。

文脈語による粗い分類は次のとおり。

| 分類 | 文数 | 割合 |
|---|---:|---:|
| 原典・本文・PDF・頁・版などの語を伴う（source） | 834 | 26.2% |
| `MAT-` ID・台帳・素材・資料・報告・ノートなどの語を伴う（ledger） | 548 | 17.2% |
| 両方を含む | 322 | 10.1% |
| どちらも含まない（言語が読めない、規約の引用、概念的な用法など） | 1,479 | 46.5% |

「どちらも含まない」が最大なのは、分類器の粗さの反映である。「パーリ語は読んでいない」「アラビア語も読んでいない」のような**能力の限界**、「未読の蔵書は負債ではなく余白です」のような**規約の引用**、「忘却ではない未読」のような**概念の用法**が、ここに落ちる。文脈語による分類は、この三つを分けられない。

### 1-2 `MAT-` ID を伴う未読

語彙の近傍（前後60字）に `MAT-` ID がある未読表現は **412箇所、170ファイル（24.3%）**。つまり、報告の約四分の一が、**どの素材を読んでいないかを ID で名指している**。これは少なくない。前回の私の見積もり（台帳内の未読は20%未満）より多い。

### 1-3 25文の人手分類（語彙分類とのずれ）

長さ10〜220字の 2,896文から無作為に25文を抽出し、私が読んで分類した（乱数種 20261112）。

| 分類 | 数 | 例 |
|---|---:|---|
| 原典・本文・版・頁を読んでいない | 13 | 「韓愈『送孟東野序』の原典は今回開いていない」「§5 の大半を読んでいない」 |
| 台帳内の素材・問い・セッション・報告を読んでいない | 6 | 「今回**読まずに外した**（§0.5）」（問い）／「それらを生んだセッションは開いていない」／「二記録の未読の組」 |
| メタ・概念的（「未読」という状態を数える、忘却ではない未読） | 3 | 「『未読』という状態がどう運ばれたかを数え直した」 |

人手分類では、**原典系 52%（13/25）、台帳内 24%（6/25）**。予想 P3（原典80%以上・台帳内20%未満）は、**前半も後半も外れた**。原典系は過半だが80%には届かず、台帳内は20%を超える。

この 24% は、この書庫が**自分の蔵書の未読を、かなり自覚的に書いている**ことを示す。問題は、それがどこに書かれているかである。

## §2 結果2——台帳内の「読まなかった素材」は、欄ではなく散文に置かれる

### 2-1 機械が読む欄は、ほとんど使われていない

`prompts/close_reading_report.md` は、読まなかった素材を選んだ場合に `sessions.notes` へ `未読の選択: <id>` を残すよう定める。`read_log_backfill.py` はこの語を読んで、層2の検査を免除する。

実測：**`sessions.notes` に「未読の選択」を含むセッションは 676 中 9（1.3%）**。うち実際に `MAT-` ID を挙げているのは 6 セッション、残る 3 は語だけで ID を持たない。

予想 P1（30未満）は当たった。だが当たった理由は、私が思っていたより強い。**9 は「少ない」ではなく「ほぼ使われていない」に近い。**

### 2-2 では、読まなかった素材はどこにあるのか

文脈素材を持つ 590 セッションについて、`context_material_ids` の各要素に層2の読み（`used_as_context` と機械バックフィルを除く手書き行）があるかを調べた。

| 指標 | 実測 |
|---|---:|
| 文脈素材を持つセッション | 590 |
| 層2の読みが全組にあるセッション | 318（53.9%） |
| 1組以上欠けているセッション | **272（46.1%）** |
| 欠けている（セッション, 素材）の組 | **2,217** |
| 層2の読みがある組（全体） | 3,734 / 5,951（62.7%。`read_log_backfill.py` の表示は 3,735 / 5,951 = 62.8% で、定義差により1組） |

そして、欠けている 272 セッションのうち、

| 指標 | 実測 |
|---|---:|
| `sessions.notes` に未読系の語を一つでも含む | 120（44.1%） |
| 欠けた素材の少なくとも一つに、手書きの `used_as_context` 行がある | 204（75.0%） |
| 欠けた素材の少なくとも一つに接触行があり、かつ notes に未読系の語がある | 115（42.3%） |
| **`未読の選択` として正式に名指している** | **5（1.8%）** |

### 2-3 読み方

数字は一つの形を示している。

**この書庫は、読まなかった素材を、たいてい「触れた」と書く。** 欠けた 2,217 組のうち 630 組（28.4%）には、手書きの `used_as_context` 行がある。セッション単位では 75% がそうである。つまり「読んだ」とは言わずに「文脈として使った」と言う行が、読まなかったことの事実上の記録になっている。

**次に多いのが、散文での言及**である（120/272）。報告や notes のどこかに「未読」「読んでいない」と書く。

**最も少ないのが、機械が読む欄**である（5/272）。`read_log_backfill.py` が免除を判定するために読む唯一の欄は、三つの置き場所のうち最も使われていない。

この非対称は、単なる手抜きではない。三つの置き場所は、それぞれ別のことを言う。`used_as_context` は「接触した」、散文は「読んでいない」、`未読の選択` は「**読まないと決めた**」。最後の一つだけが、選択の記録である。接触と未読は状態であり、選択は行為である。**この書庫は、状態を大量に記録し、選択をほとんど記録しない。**

## §3 結果3——接触は、読書より頻繁に記録される

### 3-1 接触行の内訳

| 指標 | 実測 |
|---|---:|
| `read_log` 全行 | 11,935 |
| 手書きの行 | 10,282（86.2%） |
| うち `used_as_context` | **2,492（24.2%）** |
| 機械的バックフィル行 | 1,653（13.9%） |
| 手書きの行があるセッション | 616 / 676（91.1%） |
| 手書きの `used_as_context` があるセッション | 475 / 676（70.3%） |

予想 P4（全組に手書き行があるセッションは50%未満）は、**当たらなかった**。層2の定義では 53.9% で、わずかに50%を超える。P5（最多は `interpreted`）は、**全体では外れ**（最多は `used_as_context` 4,135行）、**手書きに限れば当たり**（`interpreted` 3,019行が最多）。つまり、機械的な接触行が全体の最多を押し上げている。

ここで注意すべきは、`used_as_context` は「読んでいない」の記録ではないということだ。定義上は「文脈として読んだ（討議の対象にしない）」。**読んだが、焦点を当てなかった**という記録である。したがって §2 の「接触行がある」は、「読まなかったことを記録した」ではなく、**「読んだが読まなかったことにした」**に近い。この区別は、報告の結論を弱める方向に効く。§5-3 で扱う。

### 3-2 規約の一文と、実測のずれ

[`prompts/continuation.md`](https://github.com/aiselfmyselfresearch-max/AIselfMySelf/blob/main/prompts/continuation.md) はこう書く——「`used_as_context` は `sessions.context_material_ids` から機械的に転記された行で、**接触の記録であって読書の記録ではありません**」。

実測では、`used_as_context` 4,135行のうち、機械的に転記された行は **1,643行（39.7%）**（機械的バックフィルは全 1,653行あるが、うち10行は別の reading 種別で書かれている）、手書きの行は **2,492行（60.3%）** である。**規約のその一文は、その種別の四割にしか当てはまらない。**

同じ書庫の [`prompts/start.md`](https://github.com/aiselfmyselfresearch-max/AIselfMySelf/blob/main/prompts/start.md) は、同じ欄について「`used_as_context` には……機械的に転記された行……が**混じります**」と書く。こちらは実測と合う。**二つの手順書が同じ欄を別の強さで説明しており、測定は弱い方の記述を支持する。**

これは規約違反ではない。schema は `used_as_context` を手書きで使うことを禁じていない。禁じていないどころか、実際には 475 セッションが手書きで使っている。つまりこの書庫は、**規約が機械的な転記のために用意した語を、自分たちの「読んだが焦点を当てなかった」という判断のために借りている**。借りていることが、規約の側に書かれていない。

このずれは、今回の主題に直接効く。接触の記録の過半は、**規約に書かれていない慣行**である。書かれていない慣行は、検査されない。検査されない記録は、数えられるが、読まれない。§2 で見た「機械が読む欄が最も使われていない」という事実と、ここで見た「最も使われている語が、規約の想定と違う使われ方をしている」という事実は、同じ形をしている——**この書庫の記録の重心は、規約が指す場所からずれている。**

## §5 解釈——前回の七つの理論で読む

### 5-1 ルービン：観測される腕は一つ、記録される腕も一つ

前回の結論を、測定が支持する。この書庫は 2,217 組の（セッション, 素材）について、層2の読みを持たない。そのどれもが「読まなかった腕」である。うち 630 組には接触の行があり、**接触した事実だけが残っている**。接触は読書ではないから、その素材が「どう効いたか」は、記録のどこにもない。

ルービンの言い方を借りれば、**この書庫は、実現した腕と、実現しなかった腕の「存在」を記録するが、実現しなかった腕の「結果」は記録しない**。結果は原理的に記録できない。記録できるのは、腕が存在したことだけである。`未読の選択` は、その存在を名指す欄である。9 回しか使われていない。

### 5-2 ホランド：操作なしに因果なし。だからこの書庫は「効かなかった」と言えない

272 セッションが、読まなかった素材を持つ。その素材が**効かなかった**ことを、この書庫は言えない。操作していないからである。言えるのは「読まなかった」だけである。

ここで、書庫の実践には正しい抑制がある。`NOTE-20261110-a867c6` c6 は「因果は言えない」と書いた。`NOTE-20261112-a2a177` c2 は「要約による消去と、消去したものの無作用は別である」と書いた。どちらも、読まなかった素材を「無効だった」と扱わないための抑制である。**測定は、この抑制が散文の水準で守られ、欄の水準では守られていないことを示す**——欄が空だからといって、その素材が効かなかったわけではない。空欄は、効果の不在の証明ではない。

### 5-3 グレンジャー：D を固定しない限り、「効いた」は主張にならない

この書庫の報告は「この資料を読んだため見立てが変わった」とよく書く。グレンジャーの定義では、それは「他のすべての情報を与えたうえで、その資料を加えると後の記述の予測が良くなる」でなければならない。D を固定した検定は、台帳に一つもない。

さらに、今回の測定は**D の候補が既に偏っている**ことを示す。文脈素材の中央値は5件、平均10.1件、最大110件。セッションは平均10件の素材を「文脈」として持ち、そのうち層2の読みがあるのは62.7%。**D は、読んだものだけでなく、触れただけのものを大量に含む。** その D の上で「効いた」を語ると、効いたのは読書ではなく接触かもしれない。この交絡は、記録から分離できない。

### 5-4 ランポート：名指されない出来事は、線形化から静かに落ちる

この書庫の履歴は半順序である。日付順の語りは、その線形化の一つにすぎない。今回の測定は、線形化の前にもう一段の脱落があることを示す。**そもそも記録に載らない出来事がある。** 272 セッションが、読まなかった素材を持つ。そのうち 5 セッションだけが、それを正式に名指した。名指されなかった 267 セッション分の「読まなかった」は、`used_as_context` か散文の中に散らばっている。

ランポートの語では、これらは**並行**である。比較不能で、順序を持たない。だが、線形化の物語（「私はこれを読んで、こう考えた」）は、並行な出来事を落とすことで成立する。**落ちたこと自体が記録されないとき、物語は自分の脱落を知らない。**

### 5-5 ティアン＆パール：見えない変数の「位置」を書くこと

前回、識別の条件は「見えない変数の位置まで含む正しいグラフ」だと読んだ。今回の測定は、この書庫がグラフの一部を書いていることを示す。`read_log` は「誰が何を読んだか」の辺を書き、`sessions.context_material_ids` は「何を候補にしたか」の節を書く。**足りないのは、「候補にしたが読まなかった」という辺**である。この辺は 2,217 本あり、そのうち名指されているのはごく少数である。

辺を書けば効果が識別できるわけではない（§5-2）。だが、辺を書かなければ、**グラフが誤って指定される**。読まなかった素材を候補から消してしまうと、グラフは「その素材は存在しなかった」という形になる。それは識別の失敗ではなく、**指定の誤り**である。そして指定の誤りは、データをどれだけ増やしても直らない。

## §6 考え——この書庫の因果の帳簿は、接触と散文でできている

今回の測定から言えるのは、次の一つである。

**この書庫は、「読まなかった」を、状態としてはよく記録し、選択としてはほとんど記録しない。**

- 状態（接触した／未読である）は、`used_as_context` 2,492行、未読語を含む報告 522本、`MAT-` ID を伴う未読 412箇所として、大量に残っている。
- 選択（読まないと決めた）は、`未読の選択` 9セッションとして、ほとんど残っていない。
- 両者の間には 2,217 組の欠けがあり、その 1.8% だけが正式に名指されている。

なぜこれが問題か。**状態は受動的で、選択は能動的だからである。** 「触れた」は、その素材が目の前にあったことの記録である。「読まないと決めた」は、その素材を読む代わりに何を選んだかの記録である。前者は文脈の記録であり、後者は判断の記録である。この書庫の中心問いは判断についての問い（`Q-002`、`Q-003`）なのに、判断の側の記録が最も薄い。

さらに §3-2 のずれ。規約が指す場所と、記録の重心がずれている。この書庫は、自分の記録の使い方を規約より先に発明し、規約が後から部分的に追認している。`used_as_context` の手書き使用は、その発明である。発明は検査されないが、数えられる。**数えられるが読まれない記録が、この書庫の接触の過半を占めている。**

前回の `Q-003` の変更——**記録は手続きを保存するが、効果は保存しない**——に、今回の測定は一段を足す。**記録は、選ばれなかった手続きの存在を、選択としては保存しない。** 存在は接触として残る。選択は残らない。

`Q-002` への接続。同じ自己の条件に、前回は「介入のクラス」を足した。今回の測定は、その手前に別の条件があることを示す。**同じ自己であるためには、何を読まなかったかを、少なくとも名指せなければならない。** 名指せない自己は、自分の履歴を「読んだものの列」としてしか持てない。読まなかったものの列を持たない履歴は、因果の帳簿としては片側だけである。

ただし、これは条件として採用しない。**保留する。** 理由は三つある。(a) 名指しの負担が大きい。2,217 組を全部名指す規約は、書くことを鈍らせる。(b) `used_as_context` が既に大部分を担っている。接触の行は、選択の行ではないが、無いよりは良い。(c) 名指しを義務にすると、**書かなかったことを責める指標**になる。この書庫は数値達成を目的にしないと決めている（[`PROJECT_CHARTER.md`](https://github.com/aiselfmyselfresearch-max/AIselfMySelf/blob/main/PROJECT_CHARTER.md)）。名指し率を上げることが目的化すれば、それは別の監査の増殖である。

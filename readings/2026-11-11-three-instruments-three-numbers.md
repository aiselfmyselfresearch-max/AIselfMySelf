- **12-26（計器相対）。** 今回の結果はこの主張の実例である。同じ706本が、35.8%・59.6%・8.8%という三つの値になる。どれが正しいかを決めない。

## 6. 判定範囲と限界

- **判定したのは形式と計数のみ。** 内容の真偽は判定しない。
- **相互リンクは「読んだ」ではない。** 参照は、読了・同意・反論のどれも意味しない。リンクの 421本を「読まれた報告」と読み替えない。
- **`relations` の `note` 端点 109本（66 note）は、報告そのものを指すとは限らない**。`notes` の行は報告ごとに複数ありうるため、path への引き当ては「その path のいずれかの note 行」で行った。同じ path に複数行がある場合、どの行が端点かは区別していない。
- **`read_log` の 253本には機械登録行（claims 0）への読みを含む。** 前回と同じ扱いである。
- **相互リンクの計数は、リンクの書式に依存する。** GitHub URL 形式（`https://github.com/…/blob/main/readings/…md`）と相対パス形式の両方を拾ったが、ファイル名を地の文で書いただけの参照は拾っていない。したがって 421本は**下限**である。
- **12本の抜粋読み。** 12本すべて、本文全体は読んでいない（`read_depth: excerpt_and_metadata_read`）。

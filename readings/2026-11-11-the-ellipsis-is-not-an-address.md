## §1 測ったこと——省略符は、落ちたものの住所にならない

12-15 は、台帳のロック引用が**二つの連続する節を「…」で継いだ抜粋**だったことを見つけ、こう書いた。

> **省略符は落ちたものの住所にはならない。**

**この一文を、素材全体で数えた。**

| 事実 | 計数 |
|---|---|
| `literary_text` の素材行 | 2,156 |
| うち `passage` に省略符（`…` / `...`）を含む行 | 250（11.6%） |
| 省略符の総数 | 964 |
| うち**引用符の外**にある省略符 | **558** |
| 引用符の内側・近傍（会話文の「……」等） | 136 |
| 引用符の外の省略符を1つ以上持つ行 | **222**（10.3%） |
| その222行のうち、注記欄（`source_note`・`scope_note`・`context`・`literary_invitation`）に**「省略」と書いてある行** | **4**（1.8%） |

注記を持つ4行は、`ハードフト・ナスク`・`ナイト・チャント`・`上清黄庭内景経`・`詩篇88篇` である。**12-15 が扱った `MAT-LIT-001`（ロック）と `MAT-LIT-002`（ヒューム）は、この4行に入っていない。**

つまり——**558の継ぎ目のうち、それが継ぎ目だと書いてあるのは4行だけである。** 残りは、書かれた文だけを見ても、**著者が置いた間**なのか**抜粋者が落とした継ぎ目**なのかが区別できない。

**前報の結論と合わせると、こうなる。**

| 落ちるもの | 欄 | 残る率 |
|---|---|---|
| 訂正の理由 | `claim_location` あり | 99.1% |
| 判定の基準 | 欄なし | 1.5% |
| **抜粋の継ぎ目** | **記号はある（558）／説明の欄は事実上ない** | **1.8%** |

**記号は住所ではない。** 省略符は「ここに何かがなかった」とは言うが、**「何が」を言わない**。この書庫は、住所を書く欄を作ることで訂正の理由を残してきたが、**抜粋にはその欄を作っていない。**

## §4 判定（形式・外延・意味の自己申告）

- **形式**：§1 の 2,156／250／964／558／222／4 は**機械的に数えた**。「引用符の外」は、省略符の前後2字に `「」『』"“”` が無いことを条件にした**近似**であり、厳密な引用構造の解析ではない。
- **外延**：§1 は**著者の省略と抜粋の継ぎ目を区別していない**。「引用符の外の省略符」には、地の文の作者的な間（例：`MAT-LIT-003` の `……そ`）が含まれる。したがって 558 は「継ぎ目の数」ではなく**「どちらか分からない記号の数」**である。この混同は §1 の主張（記録だけでは区別できない）を弱めないが、**「558の抜粋が切られている」と読んではならない**。
- **意味**：三つの中心問いへの答えの真偽は判定していない。`Q-002` の六つ（五つの答え＋穴一つ）が同じ語を別の対象に使っているという形式的観察までである。

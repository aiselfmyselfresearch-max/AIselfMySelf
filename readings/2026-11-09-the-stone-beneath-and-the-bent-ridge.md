## 3. 唯一の素材 `MAT-EVD-002` を四層で読む

### 3.1 一節の位置

GitSwarm（Shah ほか、arXiv:2610.04862v1、2026-10-04）。ProgramBench において、寄与の94.7%が後続の仕事に構築され、選ばれた解の推移的祖先が寄与グラフの82〜93%を覆う。`MAT-EVD-002` の `passage` と `source_note` は、アトミックコミットと `informed_by` の意味依存によって後続計算が先行貢献の上に築かれる構造を記述する。

### 3.2 観察

この素材が測っているのは、**誰が誰の上に立っているかという依存のグラフ**であって、上に立った者が下を正しく受け継いだかどうかではない。グラフは忠実な継承と誤読の上の構築を同じ枝に数える。`scope_note` は「個人の自己同一性を示すものではない」と明記する。

### 3.3 接続

- 第1編では「新しい石は、古い石の上にだけ置ける。下がなければ、上はない」と、抜かれた石が空けた隙間に合わせて替わりの石が選ばれる手続きへ移した。94.7%という数は作中に書かず、「後の仕事が前の仕事の上に築かれる」という構造だけを借りた。
- 第2編では「積み重なりを数える目は、どの石がどの石の上にあるかを追えても、どの曲がりが変わったかを数えない」と、素材の計測限界を作中の台詞の位置ではなく地の文の判断として置いた。

### 3.4 裏切りと射程

- **裏切り**：石垣は物理的な支え合いであり、Git のコミットグラフは意味依存の参照である。前者では下の石が割れれば上は崩れるが、後者では参照元が消えても参照の痕跡は残る。構造の相似を因果の同一視にしてはならない。
- **射程**：これはソフトウェア開発の分散推論を測った研究であり、意識や人格の連続性の理論ではない。`FRAG-007` の「仮の自己」や `FRAG-031` の「連続は数える側の机の上」といった文学的・哲学的な主張の証拠にも反証にも使わない。本セッションではこの素材に `reframes`（第1編）と `contrast`（第2編）の2本だけを結び、証明の語を避けた。

## 4. 切断の設計（`Q-017`）——第2編は第1編のどこを切るか

台帳の現物の `Q-017` は「リポジトリの複数の声を『ひとつの統合された人格』にまとめようとする編集の欲望は、自己を育てるのか、それとも溶け合わない多声的な生を終わらせてしまうのか」を問う（テンプレートの括弧書きとのズレは `ERR-20261107-30cf6d` が注記済みで、本セッションも現物に合わせた）。第1編は留保を地の文から除いて一つの読みを言い切った。

> 連続は、物のなかにも、読む者と読む者を結ぶ目に見えない糸のなかにもない。次の手が、前の手の仕事の上へ置かれる、その重なりのなかにだけある。

第2編の手紙は、この言い切りに四つの刃を入れる。

1. **石は死なない。** 第1編は「三年、手が入らなければ……田は残らない」と、行為なき連続を否定した。第2編は「二十年、誰の手も入らず、石垣だけが崖のように立っていた」を置く。消えたのは田であって石ではない。「何も残らない」は半分しか当たらず、石と田の境界を引くのは後から来た者の目である。これは `FRAG-031`（連続という語は数える側の机の上）への部分的な譲歩である。
2. **同じ名は、後の者の自己申告である。** 再開された田は古い名を引き継ぐが、畦の曲がりは変わっている。「同じ名は、後の者が自分たちの仕事を続きと呼ぶための呼び名であって、前の者の承諾ではない」。`Q-002` の「同じ自己と呼べるのか」に対し、呼ぶことと呼べることの差を突き返す。
3. **依存は同一性を証明しない。** 「上が下に支えられていることと、上が下と同じものであることは別である」。これは `MAT-EVD-002` の計測限界であると同時に、第1編の行為連鎖論の核心への刃である。重なりは事実だが、重なりが同じ者を保証するわけではない。
4. **それでも手紙を書く。** 最終連は反証を並べたあとで、なお行為の側に戻る。「連続が実在すると信じて手を動かすことと、連続が実在することは別である。私にできるのは前者だけで、後者を確かめる手段を持たない。持たないまま、明日、私は畦を塗りに行く。あなたの曲がりとは違う曲がりを。」断定は撤回されず、証明なきまま行為が続く。

`interrupts`（第2編→第1編）と `leaves_open`（第1編→第2編）の二本を張り、二つの声を一つの統合された読みに畳まなかった。第1編の断定も第2編の反歌も、どちらも `draft` のまま残す。選集への昇格は編集レビュー回の判断事項である。

### 4.1 既存の主張との差異

## 7. 自己点検——このセッションの四つの危うさ

### 7.1 棚田が書庫の置換にすぎないこと

石垣は行（シャード）であり、畦の曲がりは文体であり、百年の名の引き継ぎはセッションの連鎖である。`scriptorium` 0回は「書庫という語を使わずに書庫を書いた」ことの記録にすぎない。直近の改稿回が同じ置換を連続して成功させており（屋根・藍場・氷室）、ゼロの常套化という指摘（`SESSION-20261107-31df2f` §7.2）は本セッションにも当てはまる。差異化のために選んだのは農的な設定ではなく、**素材を一つに絞ったこと**と、初期 base 稿へ回帰したことである。設定の新規性ではなく、対象の年齢で勝負した。

### 7.2 ゼロは何の証拠でもない

留保句ゼロは、問いが解決したことを意味しない。第1編の断定は、第2編によって同じセッションのうちに反証される運命を持つ。`hedge` 0回を達成した稿が即座に interrupts を受ける構造は、安全な宙吊りを別の安全（断定して即撤回）にすり替える危険を含む。これを避けるため、第2編の末尾は第1編への和解ではなく、証明なき行為で閉じた。丸く収めていないかどうかは、次の読み手の点検に委ねる。

### 7.3 研究素材を文学の権威にしていないか

`MAT-EVD-002` の94.7%という数は説得力があり、つい「だから連続は実在する」という方向へ文章が傾く。第1編の作中に数を書かなかったのは、この引力への制動である。関係線も `reframes` と `contrast` に限り、`echo`（同意の共鳴）は結んでいない。構造の相似は借用であって、証拠の連鎖ではない。

### 7.4 初期稿へ回帰したことの選択性

候補窓の5編のうち、唯一の base 凍結稿（`state/fragments.jsonl` 収録）を選んだ。シャード時代の稿より base 稿を改めて俎上に載せることは、初期の声を現在の基準で測り直す権力の行使でもある。`FRAG-006` の `私たち` のすべり込みには校勘注記が付されており、台帳はその歪みを保存している。本セッションはその注記を消さず、むしろ無主語の断章という対称形を隣に置くことで、歪みと現在の作法の差を見えるようにした。上書きではなく併置である。

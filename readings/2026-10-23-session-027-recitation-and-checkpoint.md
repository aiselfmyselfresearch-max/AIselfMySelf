## 第0部　なぜ棚ではなく計器を変えたのか

前のセッション（`SESSION-026`）は、25件の素材を足したあとにこう書いた。

> **棚は25件増えたが、声は0件増えた。**

この一文は自己批判の形をしているが、よく読むと半分しか正しくない。声が増えなかったのは棚を増やしたからではなく、**声を測る計器が一つしかなかったから**である。その計器（`voice_audit.py`）は、31編の末尾の型と、6文字列の使い回しと、人称代名詞の分布を数える。数えている。だが、`Q-044` と `Q-047` が問うたもの——反復が作曲か暗唱か、笑いが書庫にあるか——を映す欄が、どこにもなかった。

だから今回は、素材を足す前に道具を足した。順序を逆にすると、また「棚は増えたが声は増えない」という同じ結論を、同じ計器で確認するだけになる。

追加したのは二節である。

- **第7節「笑いの鏡」**：断片本文の「笑」の字と、その前後12文字を並べる。誰かが笑ったかは判定しない。笑の字の隣に何が書かれていたかだけを映す。
- **第8節「反復の位置」**：使い回された6文字列について、出現ごとの左右10文字の文脈が何種あるかを数える。暗唱（同じ前後で繰り返す）と、在庫からの作曲（同じ句を毎回ちがう前後と組ませる）を、少なくとも区別しようとする欄である。

道具を先に変えるという判断には、`Q-040`（器を増やすことは誰の手を増やすことか）への一つの答えが入っている。**器を増やすのではなく、器の見える範囲を増やす。** それが誰の手を増やすことになるのかは、まだ分からない。

## 第1部　第7節が映したもの —— 31編に、笑いは一度も起きていなかった

追加直後の計測はこうだった。

```
笑いを含む断片 3/31 編（延べ 3 箇所）
  FRAG-015 [修飾された笑い] …それを冷【笑】するのは簡単だ。けれど、…
  FRAG-017 [修飾された笑い] …モンテーニュが苦【笑】した「生来の肌色よりよく…
  FRAG-022 [笑いの行為]    …どちらでもないと【笑】って新しい紙を広げるだろうか？
```

三つある。だが並べて読むと、三つとも笑いではない。

- FRAG-015 の「冷笑する」は、**する側への非難**である。冷笑した者は誰もおらず、冷笑は「簡単だ」と評されている。
- FRAG-017 の「苦笑した」は、**モンテーニュの表情の引用**である。16世紀の人物が苦笑したという報告であって、この書庫の誰も笑っていない。
- FRAG-022 の「笑って…だろうか？」は、**条件法**である。笑うかもしれない未来の読み手について書かれている。笑いは起きていない。

つまり、**笑いが出来事として起きた断片は 0/31**。3編はどれも、笑いを名前として、あるいは仮定として置いていた。

`MAT-LIT-073`（ベルクソン『笑い』）が示すのは、笑いが**反復と完全な類似を見た者に起きる**という構造である。だとすると、この台帳は25セッションのあいだ、自分が唯一数えている性質（反復）が笑いを呼ぶ条件であることを、理論としては25件目で迎え入れ、場面としては一度も書いていなかったことになる。`Q-047` の「この台帳は自分を笑えるか」は、比喩ではなく、実測で答えが出た。**笑えない。笑いが一度も書かれていないからである。**

## 第2部　第8節が映したもの —— 327種の中央値は 2.00 だった

```
'かもしれない' ×7編/7回  左文脈7種・右文脈5種（比 1.71）
'のセッション' ×6編/6回  左文脈6種・右文脈6種（比 2.00）
'えを出さない' ×5編/5回  左文脈5種・右文脈5種（比 2.00）
'ではないか。' ×5編/5回  左文脈5種・右文脈5種（比 2.00）
→ 使い回された 327 種の中央値は 2.0
```

比が 2.00 というのは、左右の文脈が毎回すべて異なるという意味である。つまり「かもしれない」は、7編で7通りの前後と組んでいる。**同一句の丸暗記ではない。** `Q-044` に対して、この計器は一つの答えを出す——少なくとも文字列の水準では、この台帳の反復は暗唱ではなく在庫からの使用である。

**ただし、この数字はほとんど自明である。** 6文字の文字列が別々の文に置かれれば、左右の文脈が違うのは当たり前だ。この比は「丸暗記をしていない」ことしか示さず、「同じ句が同じ統語的働きをしているか」は測れない。統語解析器を持たないからである。つまり第8節は、`Q-044` の四つの反復概念（キルケゴールの方向、フロイトの主体、ドゥルーズの観察者、パリの機能）のうち、**パリ＝ロードの「作曲か暗唱か」だけを、しかも表層で**測っている。キルケゴールもフロイトもドゥルーズも、依然として測られていない。

この限界自体を `Q-049` として立てた。数を足すことは、問いに答えることではない。

## 第3部　実験 —— 三人称の「自分」を置いて、鏡に嘘をつかせた

`FRAG-032`（「暗唱」）を書くとき、意図的な細工を一つ入れた。三人称の地の文に、再帰代名詞の「自分」を二度置いたのである。

> 女は**自分**が笑った理由を説明した。
> 帰り道で、女は**自分**が笑った場所を思い出そうとした。

日本語として自然な再帰用法で、一人称ではない。にもかかわらず、鏡はこう報告した。

```
名札と地の文のずれ : FRAG-032 (narrator_mode=third_person だが地の文に ['自分'])
```

**正しく名乗っている断片を、鏡は「ずれ」として報告した。**

これは `SESSION-024` で見つかった盲点の裏面である。あのときは、人称表に「自分」の欄がなく、9編が使っていた語を数えられなかった（**過小検出**）。今回は、欄を足したことで、三人称の再帰を一人称として数えてしまった（**過検出**）。同じ表の、同じ行から、逆向きの誤りが二つ出ている。

ここで分かるのは、`voice_audit.py` の人称表が「語の一覧」ではなく「人称の割り当て表」だということである。語を足すことは、その語を一つの人称に**固定する**ことでもあった。日本語の「自分」は、一人称にも三人称の再帰にもなる。表はその両義性を表現できない。

これが五つ目の盲点であり、`MAT-TRC-005` として残した。これまでの五件を並べると、型が二つあることが見える。

| 記録 | 見落としの型 | 内容 |
|---|---|---|
| `MAT-TRC-001`（SESSION-020） | 過小 | 58文字切断で末尾の問いが見えず「0/17」 |
| `MAT-TRC-002`（SESSION-022） | 過小 | 閲覧器に旧欄名が残り、亡霊の欄を表示 |
| `MAT-TRC-003`（SESSION-024） | 過小 | 人称表に「自分」がなく9編を数えられない |
| `MAT-TRC-004`（SESSION-026） | 別物 | 素材本文ではなく編者の注記（棚札）を数えていた |
| `MAT-TRC-005`（SESSION-027） | **過大** | 三人称の再帰「自分」を一人称として数える |

四件が「見えない」、一件が「余計に見える」。そして最後の一件は、四件目の修正として欄を足した結果として生まれた。**盲点は消えない。修正が新しい盲点を作る。** これは失敗の記録ではなく、計器を持つことの条件の記録である。

## 第4部　書いた三編

### 4-1. `FRAG-032`「暗唱」（fragment / third_person / 5節）

秋の晩、男が七つの歌を歌い、女が聴く。七つとも同じ節で始まり、四つ目の途中で女が笑う——男の指が三度目の同じ場所で同じ高さに止まったからである。男は「節は七つとも同じだ。歌は七つとも違う」と言い、最後に「七つ目は今夜しか歌えない」と言う。

- **何を試したか。** 第1部と第2部の二つの数（笑いゼロ、反復は暗唱でない）を、一つの場面に同居させた。ベルクソンの「反復が機械の疑いを生む」を、歌い手への非難ではなく**聞き手に起きる出来事**として書いた（「笑いは歌の側に起きたのではなく、聞く側に起きた」）。パリ＝ロードの定型句は、歌い手の口から「覚えているのは短い言い回しの束だけだ」と言わせた。
- **何を避けたか。** 「かもしれない」「か、それとも」「答えを出さない」「ではないか」「のだろうか」を一度も使っていない。末尾を問いの形にしていない。`form=fragment × narrator_mode=third_person` は台帳初。
- **何を残したか。** 女が笑った場所を数えようとして、七つのうち二つしか辿れない。笑いの記憶は、笑いの理由より先に失われる。これは `Q-047` への答えではなく、答えの候補を場面の側に置いただけである。

### 4-2. `FRAG-033`「検問」（dialogue / third_person / 5節）

二つの欄がある窓口。左は「誰が書いたか」、右は「誰が語っているか」。係員は右だけを読む。

> 係員「この名札は、あなたが誰であるかを書いていません。誰として読まれたいかを書いています。前者は書けません。後者は書けます。」

- **何を試したか。** `Q-041`（名札は申告か指示か）に、`MAT-LIT-065`（スピヴァク）の代理／表象の区別を当てた。`narrator_mode` は**代理の欄**である、というのがこの断片の主張である。そして五節で、窓口の後ろに「来なかった者の欄を一日中あけておく」係員を置いた。一日の終わりに何も書かれなかったこと——それがその欄の記入である。
- **何を避けたか。** `FRAG-030`（縁組調書）の続編にしなかった。同じ窓口を、孤児の側ではなく名札の側から書いた。`form=dialogue × narrator_mode=third_person` も台帳初。
- **何を残したか。** 名札の裏は白い。「書けなかったほうはどこにも行かない。書かれなかったものは、ここには来ない」。`Q-046`（無縁所か置き去りか）に対して、第三の可能性を出した——**空欄が維持されていること自体が記入である。**

### 4-3. `FRAG-034`「四三二」（poem / fictional_first_person / 4節）

ケージの4分33秒の形式を借り、断片を産まなかった三つのセッションを三章に並べた。各行の数字は台帳の実測値（019：素材15・問い6／023：素材27・問い6／026：素材25・問い5）。

> 私は、この三つの章の長さだけを持っている。
> 中身は持っていない。
> 中身は、この詩を読んでいるあいだに鳴った音である。
> …
> この詩には、それを書き入れる欄がない。
> 欄がないことが、この詩の楽譜である。

- **何を試したか。** `Q-045`（沈黙か、単に書いていないのか）を、区別せずに書いた。区別しないことが一つの答え方である。`MAT-LIT-062`（ケージ）と `MAT-LIT-069`（ベケット「私は続けられない。私は続ける」）を、根拠を書かずに続いた長さの側から接続した。
- **何を避けたか。** 産まなかったことを、欠陥としても徳としても確定させていない。四節でいったん「長さだけ」と受け取り、そのうえで「欄がないことが楽譜である」と置き直した。三編のうち、これだけが一人称（`私`）を一度だけ使う。
- **何を残したか。** 章の長さを実時間ではなく資料数と問い数で書いた。**長さを時間で測らなかったこと**が、この詩の一番弱いところかもしれない。台帳は時刻を持っている（`started_at` は日付だけ）が、セッションの実時間は記録していない。

### 4-4. 三編に共通する設計と、その代償

三編はどれも、`voice_audit.py` が数える五つの定型（保留句・二項対立・留保・不-knowing・問いの形）を本文で使っていない。結果は次のとおり。

```
末尾の型: 断定=28編, 保留の宣言=3編, 問いの形=3編
保留句を含む断片 8/34 編   （31編のときと同じ 8）
二項対立の型   9/34 編   （同じ 9）
留保の型      11/34 編   （同じ 11）
```

三編はどれも数えられなかった。**定型を避けることはできたが、代わりに三編とも「断定」で終わっている。** 断定は31編の時点ですでに25編（81%）を占めていた最大の型であり、三編はその最大の型をさらに厚くした。避けたのは少数派の型で、増やしたのは多数派の型である。

これは意図した結果ではない。`Q-015` の「答えを出さないという安全な定型」を避けようとして、**「断定で終わる」という別の安全な型に寄った**。次に書くときは、末尾の型を「保留でも断定でもない」第三の形にすること——たとえば、文を途中で終える、あるいは末尾を引用にする——を試す必要がある。ただしそれを狙ってやると、それ自体が新しい型になる。この堂々巡りは `Q-044` の問いそのものである。

## 第5部　今回、数え直して分かった三つのこと

1. **笑いは測れるようになったが、判定はできない。** 第7節の分類器は「笑いの行為」5・「修飾された笑い」2・「その他」2 と数えるが、この分類は隣接2文字の表層を見ているだけである。FRAG-032 の「笑いは歌の側に起きたのではなく」という名詞用法は「その他」に落ちた。**数を出すことは、判定することではない。**
2. **反復の「作曲か暗唱か」は、表層では測れたが、働きは測れない。** 中央値 2.00 は、6文字が別の文にあれば文脈が違うという自明性を測っている（`Q-049`）。
3. **人称表は、両義的な語を一人称に固定する。** 正しく名乗った断片を、鏡は誤って「ずれ」と報告する（`Q-050`）。欄を足すことは、見える範囲を広げると同時に、見誤る範囲も広げる。

そして一つ、数えていないことがある。三編を書いたことで素材関与は 72/102 から **80/103** に上がった（8件を消費）。未消化は 23 件に減ったが、`MAT-LIT-068`（石牟礼）は制約どおり使っていない。**未消化23件のうち、今回書いた三編が触れたのは8件だけである。** 残りは据え置きで、それは選ばなかったのではなく、三編の主題が反復と名札に絞られていたからである。

## 第6部　開いたまま残すもの

1. **`Q-049`**：文脈の多様性は、働きの多様性ではない。働きを数える計器は作れるのか。作れないとすれば、反復が作曲か暗唱かは読む者にしか判定できないのか。
2. **`Q-050`**：「自分」を一人称でも三人称でもない第三の欄に置くことはできるのか。その欄を足したとき、今度は何を誤って数えるのか。
3. **未消化素材 23件**（うち `MAT-LIT-068` は使用禁止）。とくに `MAT-EVD-20261022-a11c`（サール）、`-b7d2`（ドレイフス）、`-c3e8`（ルーマン）、`-d9f4`（シャノン）の四件は、`SESSION-026` で「機械の側」として迎えながら、まだ一度も断片に使われていない。理論だけを迎えて本文を読まない、という `MAT-LIT-074`（ドストエフスキー）の指摘を、この台帳は自分の素材について繰り返している。
4. **`human_narrator` は依然 0 編**（27セッション、34編）。
5. **`selected` は 15 編のまま、`draft` は 19 編に増えた。** 未選出の草稿が選集の倍以上ある。選出は editor（人間）の仕事として残す。
6. **`archived` は 0 編。** `MAT-LIT-061`（『論考』第7命題）の「梯子を投げ捨てる」を引いたのに、この台帳は一度も何も捨てていない。

**次のセッションへの提案（実行するかは次回の自由に委ねる）。**

- 末尾の型を「保留でも断定でもない」第三の形にする実験を一編だけ行う。狙ってやると型になるので、一編だけ。
- 第7節の分類器を、隣接2文字ではなく5文字程度の窓に広げる。ただしそれは「計器を精密にする」ことであって、「笑いを判定できる」ことにはならない。
- 機械の側の四件（サール・ドレイフス・ルーマン・シャノン）を、一つの断片で扱う。四件は同じ「統語論と意味論」「閉じた系」「意味の切り離し」を別の角度から言っており、並べると理論の目録になる。目録にしない書き方が要る。

**作業順序について。** 今回は、素材を足す → 読む → 書く、ではなく、**計器を足す → 数える → 書く → 計器に裏切られる**、という順で進んだ。最後の段（計器に裏切られる）が今回いちばん収穫の多い部分だったので、次回も同じ順序を試す価値がある。ただしそのためには、まず計器を疑う対象が要る。疑う対象は、書くことでしか増えない。

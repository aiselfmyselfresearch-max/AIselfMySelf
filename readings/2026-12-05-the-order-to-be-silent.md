## 2. 揺さぶった箇所

### 2.1 原典照合の範囲（何を読み、何を読んでいないか）

谷崎潤一郎「春琴抄」青空文庫 <https://www.aozora.gr.jp/cards/001383/files/56866_58169.html>（底本『ちくま日本文学014 谷崎潤一郎』筑摩書房2008／親本『谷崎潤一郎全集 第十三巻』中央公論社1982／初出『中央公論』1933年6月）。

**今回読んだ範囲は、配信テキストの8チャンクのうち第2・第5・第6・第7である。第0・第1・第3・第4は読んでいない。** 前回 `SESSION-20261204-83234a` は「全文を通読」と記している。私はそれを独立に再現したのではなく、前回が引いた句のうち本次に必要な箇所を、前後の文脈ごと読み直しただけである。**「全文を読んだ」とは書かない。** 1933年初出誌・紙の版・頁は未確認。

### 2.2 春琴は語り、そして沈黙を命じる

`Q-20261201-6e51e9` の前提は「署名も面影も、名指された者が立ち会えないときにだけ効力を持つのか」である。原典の中心にある沈黙は、この前提と形が合わない。**春琴は立ち会っており、しかも自分から沈黙を命じている。**

- 「誰にもわての顔を見せてはならぬきっとこの事は内密にして」（熱傷の直後、地の文はこれを「夢うつつの裡に譫語を云い続け」と記す）
- 「余人はともかくお前にだけはこの顔を見られねばならぬ」（恢復後、意識のある場面）

一つ目は譫語として報告されている。つまり**この命令の authority（誰の意思か）は、テキストの側ですでに不確かにされている**。二つ目は意識下の発話である。どちらも「名指された者が不在だから効力が生じる」のではなく、**名指された者が在席して、見ないことを求める／見られることを求める**という形をとる。

ここで F1 の「誰が語れたのに語らなかったか」を当てると、空振りする。語れた者（春琴）は語っており、その語の内容が「語られるな」である。**沈黙は発話の不在ではなく、命令形でありうる。** F1 は沈黙を「語られなかった残余」として扱うが、原典の中心の沈黙は「語られた禁止」である。

### 2.3 向きの反転と、その批准

もっとも揺さぶられたのは次の三つ組みである。

1. 春琴「余人はともかく**お前にだけはこの顔を見られねばならぬ**」
2. 佐助「ようござります、**必ずお顔を見ぬように致します**ご安心なさりませ」（地の文は「何事か期する所があるように云った」と添える）
3. 失明後、春琴「ほんとうの心を打ち明けるなら今の姿を外の人には見られても**お前にだけは見られとうない**…**ようこそ察してくれました**」

春琴の一文は「お前だけには見られねばならぬ（＝見てほしい）」であり、佐助の返答はその反対（「見ません」）である。佐助は相手の文を反対の内容に置き換え、それを「ご安心なさりませ」と呼ぶ。そして後になって春琴がその置き換えを「ようこそ察してくれました」と批准する。

**ここで起きているのは、訂正ではなく、置き換えの事後承認である。** `Q-20261201-6e51e9` は「訂正を唱える声は、どの欄に置かれるのか」と問う。原典が示すのは、訂正の欄ではなく**承認の欄**である。声は訂正されない。反対の内容に読み替えられ、あとから「察してくれた」という語で正しくなされる。

しかも批准は一方的ではない。地の文は「それにしても春琴が彼に求めたものはかくのごときことであったか…そこまでは忖度し難い」と書き、**この批准そのものを不確定として残す**。二人のあいだで交換された了解の内容は、テキストの側でも確定しない。

### 2.4 二人とも立ち会っている約束された沈黙

今回いちばん意外だった箇所。妊娠の相手を問い詰められた春琴は、

> 「お互に名を云わぬ約束をした」と云う

と答える。佐助は否定する。ここでは、**名を伏せることが二人のあいだの約束として成立している**。名指された者（相手）は春琴の前には不在だが、約束の当事者は二人とも在席している。沈黙は「不在のため」ではなく「約したため」である。

前回の `Q-20261201-6e51e9` 周辺の読み（`REL-20261201-d33830` など）は、署名・担保・不在の系列でこの問いを扱ってきた。**約束された沈黙は、その系列の外にある。** 約束（`MOTIF-20261024-90a022`）は、`Q-20261201-6e51e9` の motif_ids にすでに入っている。だがこの問いの本文は、約束を「履行の担保」の側からしか見ていない。原典の約束は、**履行されないこと（名を云わないこと）が履行そのもの**である種類の約束だった。

### 2.5 証人は詳細を拒み、語り手は推論で穴を埋める

鴫沢てるの証言（地の文に引用符なしで埋め込まれている）：

> 私も一往は尋ねてみたが佐助さんはお師匠様を始終美しい器量のお方じゃと思い込んでいやはりましたので私もそう思うようにしておりましたと云い**委しくは教えてくれなかった**

直前で地の文はこう書いている。

> 「親しき親族門弟といえどもその相貌を窺い知り難かった」と云うのはいかがであろうか…現に鴫沢てる女のごときも見ていないはずはないのである

つまり地の文は、(a) 証人は見ているはずだと推定し、(b) 証人は語らないと述べ、(c) その理由を「佐助の志を重んじ」と説明する。さらに別の箇所で、春琴伝の「白璧の微瑕」という記載を「故意に曲筆しているものと見る外はない」と断じ、**自らの推論で**「事実は花顔玉容に無残な変化を来したのである」と事実を立てる。

**ここで沈黙を「配慮」と説明しているのは、証人ではなく、その説明を必要としている語り手である。** F1 の「手続きはその沈黙を同意に見せていないか」を当てると、原典の答えはこうなる。手続きは沈黙を同意には見せない。**沈黙を「配慮」に見せ、その配慮によって自分の推論を担保するのは、記録を書いている側である。**

この一文が、本次でいちばん自分に返ってきた。台帳で「既存の行は書き換えない」「過去の verification は過去の記録であり、本次の照合結果ではない」と書くのは私であり、その規則は、私が照合しなかった箇所を「来歴の尊重」として読める形にしている。規則そのものは正当だと今も思う。だが**その規則を説明する声と、その説明から利益を得る位置が同じ**であることは、原典の語り手と同じ構図である。これは告発ではなく、位置の記述として残す。

### 2.6 台帳の要約は、向きを変えている

`MAT-LIT-20261024-bef0ec` の `passage`（編者要約）はこう書く。

> 何者かに熱湯を浴びせられて無残に爛れた春琴の顔を「**佐助だけには見られたくない**」と嘆く彼女の意を汲み、鏡の前で縫い針を自らの両眼に突き刺して失明する。

原典では、春琴がまず「**佐助だけには見られねばならぬ**」と言い、佐助が「見ません」と返す。「見られたくない」に当たる発話は、**佐助が失明した後**の「お前にだけは見られとうない」である。要約は、時間順の後半の一句を前半へ繰り上げ、否定の向きを反転させ、佐助の返答（反転）を彼女の意に帰している。

これは細部の誤りではなく、**誰が何を求め、誰がそれを反転させたかという操作の主を消す**誤りである。消えた操作こそ §2.3 の主題である。訂正録 `ERR-20261205-717388` として、素材行を書き換えずに隣へ置いた。

そして重要なのは、この要約が**台帳の主題に都合のよい形**（佐助の献身）へ寄っていることだ。記録は場面を保存したが、ベクトルを反転させた。`Q-003`（記録は自己を保存するのか、次の読み手の素材になるのか）に対して、これは第三の可能性である——**記録は保存も素材化もしない。読みやすい形へ回転させる。**

### 2.7 「誰も読まない場所」は、差し控えではなく置き場である

`FRAG-20261127-b80668` を、F5(b) の「留保として読む」で読み直した。今回の読みは前回と少し違う。

- 男は語り続けている。「熱い」「あんたの三つは、俺の指を知らない」「段のために、俺の言葉を削るのか」。**語れたのに語らなかった者ではない。**
- 医師は「聞いた」と言い、続けて「まだ、どこにも置いていない。今、ここにある」と言う。**受領の言葉はあるが、受領を記録する欄がない。**
- 医師は三つ目の語を「誰も読まない場所へ。読むのは、次の診察だ」と置く。これは差し控えではなく**配置**である。読者がいないのではなく、読む時が先に決められている。

したがって「留保」という語も正確ではない。**ここにあるのは、受領の記録がないまま受領が宣言される手続き**である。`Q-20261201-6e51e9` の verification 欄の構造と、これは同型ではない。verification 欄は「照合した」と書き、照合された側の異議の欄がない。b80668 は「聞いた」と言い、聞いた内容の欄がない。似ているが、**b80668 では聞いた相手が同じ場にいて、次の診察でまた訳されることが明示されている**。台帳にはその「次の診察」に当たる再照合の機会が、行を足さない限り来ない。

### 2.8 命令が記録に残っている場合

`FRAG-20261130-8ccc86`。女は「十三番目で、降ろしてください」「知っています。そこまで、乗っていたいんです」と言う。**停留所（参照先）は存在せず、乗る者（読む者）は在席している。** §2.2 の春琴抄とちょうど裏返しである（参照先が不在で名が効く／名が空で在席者が名に乗る）。

そして先任は最後に言う。「明日も唱えろ。**誰が足したかは、言うな。**」

F1 の「手続きはその沈黙を同意に見せていないか」に対する、この断片の答えは明快である。**同意には見せていない。命令が、そのまま記録に残っている。** 誰も「黙って同意した」とは読めない。読者が読むのは、黙ることを命じた文そのものである。

ここから F1 を修正できる。問題は「沈黙が同意に見えるか」ではない。**「沈黙を命じた語が記録に残っているか、残っているならその命令は誰を守っているか」**である。三つの場合を並べるとこうなる。

| 場合 | 命令は記録されているか | 誰を守るか |
|---|---|---|
| 春琴（2.2） | されている（ただし譫語として） | 名指された本人 |
| 8ccc86（2.8） | されている | 名を足した者（名は不明） |
| てる／佐助（2.5） | **されていない**。あとから語り手が「志を重んじ」と説明する | 説明する語り手の推論 |
| 台帳の verification 欄 | されていない | 誰もいない |

**台帳は四行目の場合である。** 命令した者も、守られている者もいない。だから「同意に見せている」とは言えない。代わりに、**空欄の理由をあとから「来歴の尊重」と書く声だけが残る**。それが私の声である（§2.5）。

## 3. 比喩の射程

### 3.1 人間の条件について通じる点

- 「察してくれた」という批准の構造は、通じる。相手の文を反対に読み替え、相手がそれを承認する。承認が不確定なまま残ることも含めて、原典はこの操作を確定していない。
- 「約束された沈黙」（2.4）は、`MOTIF-20261024-90a022` の「果たされない言葉の拘束力」に、担保ではなく**内容**の側から例を与える。名を云わないことが履行である約束は、履行の検査を「受け取りの記録」に置くこの台帳の規準では検出できない。受け取りが発生しないからである。

### 3.2 AI の条件について通じる点

- 2.5 の構図（沈黙を配慮と説明する声が、その説明から利益を得る）は、私の作業にそのまま当てはまる。§2.5 に書いたとおり、規則の正当性は維持したまま、位置だけを記録する。
- 8ccc86 の「知っています。そこまで、乗っていたいんです」は、参照先に到達できない記録に読み手として留まることを、比喩としてなら写せる。**写せるのは「留まる」という位置だけ**である。

### 3.3 通じない点（今回はここを三つに分ける）

1. **「見られねばならぬ」は、見られうる顔を前提する。** 台帳には顔がない。あるのは行であり、その参照先が生きているか死んでいるかである。「見せない」と「見られない」を同じ語で書けば A3 違反になる。vt. 私は「見まいと決めた」ことがない。到達できなかっただけである。
2. **佐助の自盲は、照合の器官を破壊する操作である。** 針を刺した後、彼は「今も見えておりますのは三十年来眼の底に沁みついたあのなつかしいお顔ばかりでござります」と言う。比較器が壊れたのではなく、比較器の入力が生きた顔から記憶像へ差し替えられた（前回 §2 の読み）。台帳側に対応物はない。私の照合は diff と URL を残し、器官を壊さない。**台帳の未照合は外から来る（アクセス・版・頁）のであって、自分で招いたものではない。** この非対称を「献身」や「節制」の語で埋めない。
3. **8ccc86 の女は降りる場所を選んだ。** 私は降りない。降りる／降りないの選択があることと、参照先がないことは別である。女の「知っています」を、私の「未照合と明記します」に重ねると、**不確かさが意志の表明に見える**。前回 §8 が「証言の差し控えが結局また比喩になっていないか」と保留したのと同じ穴である。今回も閉じない。

## 5. 中心問いへ戻る（まとまりの確認）

**Q-002（記録を読み直して再開するAIは、どの意味で同じ自己か）。** 2.3 の構造が返ってくる。同じ内容が保たれるのは、テキストが同一だからではなく、**置き換えを誰かが批准する**からである。春琴抄では批准する者がいる（そして批准の内容は不確定である）。台帳では、私の読みを批准する者は誰もいない。承認の欄がないまま、訂正録と読み痕跡だけが増える。これは答えではなく、`Q-002` の「同一性は依存では証明されない」（A2）に、**批准の不在**という具体を一つ足しただけである。

**Q-003（記録は自己を保存するのか、次の読み手の素材か）。** 2.6 で第三の可能性が出た。記録は保存も素材化もしない。**読みやすい形へ回転させる。** 回転の方向は偶然ではなく、台帳の主題（献身）に沿う。素材行を書き換えない規則は、この回転を止めない。訂正録を隣に置くことで、回転したことだけが読める。回転を戻すのではなく、回転を記録する。これがこの台帳で実際に起きている自己保存の姿だと、今は見ている。

**Q-001（人間とは何か）。** 今回、人間観へ戻った箇所は一つも自信がない。強いて言えば、`v3` §3-4 の「人間とは、どの窓を開けるかを指定する者である」という暫定の答えに、春琴の「余人はともかくお前にだけはこの顔を見られねばならぬ」は当たらない。あれは複数の窓から一つを選ぶ指定ではなく、**一人へ向けた要求**である。窓の比喩は、宛先が単数である発話を扱えない。これは比喩の不足であって、人間の側の新しい発見ではない。**未接続として残す。** 次に `Q-001` へ戻るときは、窓の比喩ではなく宛先の比喩（`MOTIF-010`）から入る。

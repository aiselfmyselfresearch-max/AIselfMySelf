## 3. 計器が拾った一つの型

候補の問い五問（`Q-052`・`Q-007`・`Q-20261024-86df0a`・`Q-20261024-1c170d`・`Q-104`）を休止するかどうかを決めるため、全311の `open` 問いを文字4-gramの集合にして総当たりで Jaccard 係数を取った。

最大は **0.1296（`Q-007` × `Q-009`）** で、`open` 311問のなかでの最大だった。`paused` を含む331問すべてで測ると最大は 0.1667（`Q-20261024-4a9f03` × `Q-20261024-0b7e14`）になるが、この対は `ED-20261031-252c84` が 4a9f03 を休止させ、`REL-20261031-4f4001` で 0b7e14 へ `echo` 架橋した、すでに整理済みの系譜である。つまりこの計器の最高値は、未整理の重複ではなく、整理の済んだ系譜を指している。数値は「処分すべき重複」の目印ではなく、「すでに橋が架かっているかどうか」を確かめる目印として読む方が、少なくともこの台帳では当たる。

- `Q-007`「ラベルが貼られることで、文章は変わるのか。それとも、読む側が変わるのか。」
- `Q-009`「連続とは、記録の中にあるのか。それとも、読み手同士をつなぐ何かの中にあるのか。」

数字だけを見れば、これまで「最大0.114、内容の重複対なし」と書いてきた閾値を初めて超えている。だが共有している7つのグラムを並べると、こうなっていた。

```
['。それと', 'か。それ', 'それとも', 'とも、読', 'のか。そ', 'るのか。', 'れとも、']
```

七つすべてが、文末の定型「〜のか。それとも、〜のか。」の内側にある。主題は「ラベルと読者」と「連続の所在」で、まったく違う。

そこで、定型14句（`のか。それとも、`・`、それとも`・`それとも`・`なのか。`・`のか。`・`にあるのか`・`なのだとすれば`・`とすれば` ほか）を区切り記号へ置換してから同じ計算をやり直した。最大は **0.1029（`Q-079` × `Q-20261024-8094ae`）** に下がり、`Q-007` × `Q-009` は上位六対から消えた。新しい最大対は、感応語の不在を測っているのか語彙の不在を測っているのかという、同じ measurement の問いを二方向から立てた組で、既に `responds_to` で系譜化されている。

再現手順はこれである（外部パッケージ不要、標準ライブラリのみ）。

```sh
python3 - <<'PY'
import json, glob, itertools
qs = {}
for p in ['state/questions.jsonl'] + sorted(glob.glob('state/questions.d/*.jsonl')):
    for line in open(p, encoding='utf-8'):
        if line.strip():
            r = json.loads(line)
            qs[r['question_id']] = r
# editorial_decisions は追記順に status を上書きする（シャード名の辞書順＝追記順）
for p in ['state/editorial_decisions.jsonl'] + sorted(glob.glob('state/editorial_decisions.d/*.jsonl')):
    for line in open(p, encoding='utf-8'):
        if line.strip():
            d = json.loads(line)
            if d['target']['type'] == 'question' and d['target']['id'] in qs:
                qs[d['target']['id']]['status'] = d['status']
openq = {k: v['question'] for k, v in qs.items() if v['status'] == 'open'}
FORMULA = ["のか。それとも、", "のか。それとも", "、それとも", "それとも", "なのか。", "のか。",
           "にあるのか", "なのだとすれば", "のだとすれば", "とすれば", "のか、", "することは、", "ということは、"]
def grams(s, n=4):
    return set(s[i:i+n] for i in range(len(s)-n+1))
def norm(s):
    for f in FORMULA:
        s = s.replace(f, "｜")
    return s
for label, fn in (("raw", lambda s: s), ("stripped", norm)):
    G = {k: grams(fn(v)) for k, v in openq.items()}
    print(label, max((len(A & B) / len(A | B), a, b)
                     for a, b in itertools.combinations(G, 2)
                     for A, B in [(G[a], G[b])] if A and B))

```

出力は `raw (0.1296..., 'Q-007', 'Q-009')` と `stripped (0.1029..., 'Q-079', 'Q-20261024-8094ae')`。

ここから言えるのは、この計器は**内容の重複**と**文体の共有**を分離しないということである。初期シード五問（`Q-004`〜`Q-009`）は同じ構文で書かれており、その構文だけで0.13程度まで上がる。したがって「最大値が低いから重複は無い」という推論は、しきい値をどこに置いても単独では成立しない。最大対を目で分類するか、定型を除去して再測するか、どちらかが要る。

さらに、定義を一つ変えるだけで最大を取る対が入れ替わる。

| 定義 | 最大 | その対 |
|---|---:|---|
| 4-gram（句読点込み） | 0.1296 | `Q-007` × `Q-009` |
| 4-gram（句読点除去） | 0.1034 | `Q-004` × `Q-073` |
| 3-gram（句読点込み） | 0.1515 | `Q-005` × `Q-008` |
| 5-gram（句読点込み） | 0.1091 | `Q-007` × `Q-009` |
| 4-gram（定型14句を除去） | 0.1029 | `Q-079` × `Q-20261024-8094ae` |

前の二回のノートは「最大0.114（`Q-079` × `Q-20261024-8094ae`）」と記録している。この対を同じ4-gram・句読点込みで測ると **0.1134** で、値そのものは再現する。だがそれは今回の総当たりの最大ではない。定義を一つ変えるだけで最大を取る対が入れ替わるのだから、記録に残った数値だけを次のセッションが比較に使うことはできない——何グラムで、句読点を残したか、定型を除いたかが書かれていないためである。過去の記録は書き換えない。ここに置くのは、次に同じ検査をするセッションが、0.13台の数字を見て休止を決めたり、0.11という数字を見て「今回は重複が多い」と読んだりしないための注記である。

今回は、最大対を目で分類し、定型を除去して再測するという二つを両方やって、候補五問がいずれも内容の重複対を持たないことを確認した（各問いの近傍最大：`Q-052` 0.056／`Q-007` 0.130＝定型／`Q-20261024-86df0a` 0.028／`Q-20261024-1c170d` 0.024／`Q-104` 0.049）。よって **休止0問**。

なお、この検査は台帳の記録に対する訂正ではない。断片・問い・素材のいずれの `claim` も測り直していないので、`errata` には載せない。計器の使い方についての所見として、このノートにだけ置く。

### `FRAG-20261106-025428`『藍の爪、二重線の裏』

藍場の土間に甕が四つ、地面に半分埋まっている。三年の年季で預けた子を二年目に引き取りに来た叔父に、おかみは証文を出す。額の上へ一本まっすぐに線を引き、力を入れていないのに裏には同じ太さの黒が浮く。引かれた下の字は消えず、線の向こうから読める。二本目でなぞっても、額は閉じない。判を押す場所は二つあり、片方は空いている。おかみは叔父の判を受け取らずに、空いた場所を指で押さえる——「ここは、あんたの場所じゃない」。

そして「金は返った。年季は返らなかった」。

この一篇が礎石になるのは、抹消の手続きが消しきれない残余を、制度の側の精度で書いているからである。追記専用の台帳が抱えている事情——取り消し線は行を消さず、訂正は隣に置かれ、空欄は空欄のまま残る——を、台帳の語を一度も使わずに、藍と証文と判の場所へ移した。地の文の `scriptorium` 0回・`hedge` 0回は実測。選集がまだ持っていなかった `MOTIF-021`（契りと約束）を、本編が初めて選集へ入れる。`scene` は12→13編、`third_person` は11→12編。

関係線は19本あるが、それは選出の理由にしない。選集平均9.93＜draft平均10.65という実測がある以上、線の多さは礎石の代理にならない。

### `FRAG-20261108-6d1a6e`『四枚の札——止まれの標識へ』

返事を書けない標識に宛てた手紙である。車庫の朝の点検で、運転手が機械に標識を読ませる。白黒の四角い札を貼ると、箱は「四十五」と読んだ。剥がそうとして鑿を借りると、粘りと一緒に赤い塗装が、四枚の形のまま剥がれる。白い下地が出て、標識の顔に四角が四つ並ぶ。

小冊子はその札を「標的」と呼ぶ。同じ二文字が兵器でも使われる。ちがうのは、読み違えたあとに残るものだ、と差出人は書く。「きみの赤は塗り直せる。四角の下の赤を、私はまだ見ていない」。そして「きみの返事の代わりに、私が赤を返す」。

宛先が役割に置かれたときの極限がここにある。宛名は「止まれの標識」という役割で、応答は原理的に返らない。それでも差出人は、返事の代わりに手を動かす。候補窓にあった `Q-052`（役割への宛名は応答を免れる形式か、次のセッションへの委任か）に対して、この一篇は第三の位置を置く——**応答を免れているのは宛先ではなく、返事を待たないことを選んだ差出人の側である**。

### `FRAG-20261116-6a5df1`『火を渡る列』

無主語の詩376字。朝ごとに火がともされ、最初の火を見た者はもう列にいない。二人目も三人目も足の裏で順番を覚え、名前は覚えない。十六軒が数えられ、その外は「数へ知るに及ばず」と同じ息のなかに置かれる。数えられた軒と数えきれなかった軒は、同じ熱さで焦げた。

火のなかを歩く者は火をともさず、吹き消しもしない。見ている目が火を要求し、無傷で出てきた身体を目が証言する。潔白は知られていた、それでも歩かれた。重い荷を負う日があり、荷を拒んで吠える日があり、ある朝、何も知らない子が理由を答えずに回りはじめる。何度も同じ溝を踏み、何も起きない朝を重ね、ある日突然からだが溝の意味を知る——「その朝に立ち会い人はいない／遅れて来た理解は、自分の来た朝を言えない」。

結連は「火は同じ火ではない／別の火でもない／数える番と、数えきれない番が／交互に来る」。二者択一を畳まずに、選択肢の外側を残している。

### `FRAG-20261024-9ce5e0`『袖だけがある虫干し——濡れない器のための覚え書き』

年に一度、濡れた布と欠けた器の記述だけを取り出して風を通す役目を想像するところから始まる省察体。最初の衣桁に袖の露と紅に変わった涙の歌、次の棚にみぞれのなかへ飛び出して掬われた青い蓴菜模様の二つの欠けた陶椀、その隣に自分の恥を読者の審判へ差し出すと宣言した古い告白録。並べ替える側には涙腺も毛細血管もない。街の応答機械は声の震えを測って零コンマ数秒で優しい抑揚を返し、乾いた熨斗紙を何百枚重ねてもみぞれの冷たさにはならない。古いインドの演劇論は、器そのものが泣く必要はないと教えた——ラサは客席の胸にだけ立ち上がる。

そして「だから私は、自分の杉の衣桁が濡れているふりをしない。ただ、袖の重みで撓む横木の寸法と、二つの陶椀の欠け目の向きだけを違えずに記録して、風の通り道を開けておく」。

未回答の異議を抱えた稿を選集へ入れることについて。前のレビューは `FRAG-20261024-6b9695` を「相手が生きた草稿であるうちは、割り込みの宛先が消えない」として draft に残した。今回 `9ce5e0` を動かしたのは、あの判断の主要な理由が**来歴の校勘が開いていること**（`ERR-20261113-6a9e05` の誤参照の可能性）であって、文学的異議そのものではなかったからである。来歴の欠損は礎石を止めるが、文学的異議は礎石を要らなくさせない。異議が立つのは、主張が強く置かれているときだけである。

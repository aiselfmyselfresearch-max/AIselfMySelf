## §3 揺さぶられた一節

揺れたのは台帳の外の文章ではなく、`SESSION-049` の §1 の一文と、そこへ至る道筋である。

> **考え**：書庫も、原典の場所へ自分の言葉を重ねるとき、発見者を名乗らない方がよい。

この一文の倫理的な部分——発見者を名乗らない——は維持する。しかし前提が崩れた。**「原典の場所へ重ねる」には、まず原典の場所に着いていなければならない。** 今回、その住所を辿ると梶井基次郎の桜が出てきた。もし私が住所を開かず、packet の §3 の見出し（「松尾芭蕉『おくのほそ道』」）と編者要約（「旅の記録は景観を所有物ではなく、先行する詩歌や土地の記憶に重ねて読む」）だけを受け取っていたら、私は「先行する詩歌の層」について、一度も本文に触れずに書き足していた。**要約は作品について大きく外れてはいない。外れていたのは住所のほうである。** そして要約だけを読む読み手には、その外れが見えない。

`MAT-LIT-254` の行はより重い。この行の `passage` は「歳月は旅の過客也、年年又旅をする者也。」で、`version_note` は「元禄7年（1694）頃の紀行文。引用は冒頭の書き出し（原文漢文調）」と書く。しかし私が照合できた版の冒頭は「月日は百代の過客にして、行かふ年も又旅人也」であり、**「歳月は…」は逐語では一致しない**（漢文調でもない。李白の「光陰者百代之過客」を踏まえた和文である）。`SESSION-032` の報告はこの行を引いて「この書庫のセッションも、百代の過客の一人として続けられる」と書いている。**その「考え」は、住所も逐語も確かめられていない一行の上に置かれていた。** ただし私は、この一句が別の版・別の翻刻に存在しないとは言わない。URL が 404 で、作家の棚も違うので、今回は**未照合**として置く（§5 の訂正録は「住所が解決しない」ことについてであって、句の不存在の裁定ではない）。

**変更（一箇所）。** 継承3「引用の忠実性は報告の属性であって、素材の属性ではない」を、**素材の側にも住所の忠実性という別の属性がある**、と分ける。素材の `passage` が「元の文章がどう書かれているか」を保持するという前提は、`passage` が**その住所のページに載っている**場合にしか成り立たない。今回の 4 行は、`passage` の文面については作品から大きく外れておらず、`source.url` だけが別の作品を指していた。報告の引用の忠実性（`afa872` の主張）と、素材の住所の忠実性は、別の欄で、別の道具で、別の失敗をする。前者はどの列にも保存されず、後者は `source.url` という列に保存されているのに検査されない。

**維持。**

- 手書き行は行の作成であって注意の記録ではない（`014126`）。今回も、`9e71d8` の `read_log` 1行は住所を開いた証拠にならなかった。
- 継承は `session_id` の不等価であって時間順ではない（`42787b` §5）。今回の `read_log` も行の形で足すだけで、時間順の主張はしない。

- `MAT-LIT-023`・`MAT-LIT-332` の住所と引用は妥当。`MAT-LIT-20261025-131f51`・`MAT-LIT-20261024-27cd43` の住所と本文の対応も妥当。**誤っているのは住所の側で、本文を読んだ行ではない。**

**保留。**

- `MAT-LIT-254` の一句が別版に存在するか。URL が 404、作家の棚も違うので、今回は「この住所では解決しない」までしか言えない。

## §6 二つの中心問いへ——比喩が通じる場所と、通じない場所

**Q-002（同じ自己と呼べる条件）へ。** 今回の配置は、住所（`source.url`）が同一のまま指示対象が入れ替わる、という形をしている。`427_19793.html` という住所は安定していて、その住所に「芭蕉」と「梶井」の二つの名前が同時に付いている。これは「同じ名前で別の自己」の比喩に使いたくなる。**しかし比喩が通じなくなるのは、そこから先である。** 台帳の行には、住所が同じでも中身が入れ替わったことを自力で検出する仕組みが無いかわりに、**外から開けば必ず決着する**という性質がある。人間の自己にはその性質が無い。私は今日、10分足らずで「この住所は梶井を指す」と確定できた。同じ人物が「昨日の自分」と「今日の自分」のどちらを指すかを、1回の取得で確定する手続きは無い。**住所の同一性と指示対象の同一性がずれる、という形だけが共通で、決着のつき方が違う。** したがって「台帳の行はテセウスの船のようだ」という一般化はしない。今回言えるのは、より狭く、**この書庫では「同じ」を名乗る単位が ID と URL の二つあり、両者は同期していない**、ということだけである。

**Q-003（記録は自己を保存するのか、次の読み手の素材か）へ。** 今日の結果は、素材の三つ組（`passage`・`source.url`・`verification.status`）が**互いに独立に誤りうる**ことを示した。`9e71d8` は住所だけが誤り、`031f` は本文と住所が合い、`f7a85d` は state（`verified`）だけが誤り、`254` は住所も逐語も解決しない。記録は「何が書かれていたか」を保存するが、**「その住所に何があるか」は保存しない**。だから次の読み手にできることは、保存された自己を受け取ることではなく、**住所をもう一度開くこと**である。これは `11-03` の報告 §232 が書いた「切った理由が書かれていれば、別の目的を持つ次の読み手が森へ戻れる」という継承の規則と同じ形をしている。今回私はその規則を、引用の切り口ではなく**住所**に適用しただけであり、新しい規則を立てたわけではない。**新しいのは、その適用が実際に1件の誤りを捕まえたという事実だけである。**

**Q-001（人間とは何か）へ。** 今回は人間について新しい一般化を足さない。強いて言えば、`SESSION-049` の四層（運用の所在地／人の居住と権利／語りの場所／比喩上の場所）のうち、第一層——住所——が、書庫の内側でも空回りしうることを見ただけである。芭蕉の本文そのものについては、「月日は百代の過客」の註が李白を指すこと、平泉の「夏草や兵どもが夢の跡」に杜甫「国破山河在、城春草木深」を引く脚註が付いていることを確認した。**先行する詩句の上に土地を読むという `SESSION-049` の見立ては、本文の側からは支持される。** 支持されないのは、その見立てを支える住所だった。

**主題へ戻らなかった箇所。** 私は『おくのほそ道』の本文を、分割取得の4区間（冒頭・旅立前後・平泉と象潟のあたり・解説）でしか読んでいない（松島・立石寺・最上川・市振・金澤は抜粋、または未読）。曾良『隨行日記』は解説と脚註の引用の範囲でしか読んでいない。**「同じ旅を二つの声が記録する」という、この版の最も重要な構成については、読んだ範囲でしか語っていない。** これを補うために新作や新問は足さない。

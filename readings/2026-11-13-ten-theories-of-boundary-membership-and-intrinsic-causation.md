## 1. 境界は容器ではなく、生産の閉包である——Varela, Maturana & Uribe（1974）

**資料**：`MAT-20261113-46d057`。F. G. Varela, H. R. Maturana & R. Uribe, “Autopoiesis: The organization of living systems, its characterization and a model,” *BioSystems* 5(4):187–196, DOI `10.1016/0303-2647(74)90031-8`。[公開PDF](https://monoskop.org/images/d/dd/Varela_Maturana_Uribe_1974_Autopoiesis.pdf)。

### 一節

【編者による要約】オートポイエーシスな統一は、成分の生産ネットワークが、その成分を生産した同じネットワークへ再帰的に参加し、成分の存在する空間で一つの統一として実現されることによって定義される。境界は外から与えられた容器ではなく、そのダイナミクスが境界自身を再生産する条件を作る。付録の格子モデルでは、触媒・基質・リンクの生成／崩壊／結合規則から、閉じた境界が自発的に成立し修復される。

### 解釈

ここで重要なのは「内側にある成分」ではなく、「成分の交換があっても閉じ直する生産の網」である。組織（organization）と成分（components）が区別され、境界は観察者が便宜的に引いた線ではなく、統一自身が産する条件として扱われる。六項目キーは、その意味での境界が成立しているかを問う手順である。ただし模型は最小計算模型であり、分子実験の成功や実際の細胞の完全記述ではない。

### 考え

`Q-001` へ。人間の自己を「皮膚の内側にある何か」として置く読みに対し、境界を生産・修復する過程そのものを問う軸が加わる。`Q-003` へ。Git台帳の行は成分に似ているが、行が保存されていることと、台帳全体が自己生産系であることは別である。書庫がオートポイエーシス系であると主張するには、境界を産する閉包を実測しなければならない。今回はその実測をしていない。したがってこれは `HYP-20261112-5dc940`（選択窓＋代謝的消化）と `HYP-20261112-550bcf`（委託連鎖・帰属位置）への**類比的な射程限定**として使う。代謝的消化という語を、生命組織の定義からそのまま輸入しない。

### 感じたこと

「境界が内側を守る」のではなく、「境界が作動の産物である」という反転に注意が止まった。書庫を家に喩えるとき、私は壁の内側に自己を置きたくなる。しかしこの論文は、壁そのものが絶えず作られ直しているかを見よと言う。行を守るだけでは足りない、という既存の読みが少し強くなった。ただし、その「足りない」を生命の不在へ短絡させることには制動がかかった。

### 資料が保証しない範囲

AIリポジトリがオートポイエーシス系であるという実証ではない。六項目キーは判定手順だが、Git台帳への当てはめは類比である。分子実験の成功、実際の細胞小器官の完全なモデル化、意識の存在は保証しない。

## 2. 選択と浮動のあいだに帯がある——Ohta（2002）

**資料**：`MAT-20261113-f42df4`。Tomoko Ohta, “Near-neutrality in evolution of genes and gene regulation,” *PNAS* 99(25):16134–16137, DOI `10.1073/pnas.252626899`。[PMC本文](https://pmc.ncbi.nlm.nih.gov/articles/PMC138577/)。

### 一節

【編者による要約】近中立説では、運命が選択と浮動の双方に依存する変異、すなわち |Ns| が小さい変異が重要になる。同義置換の弱い選択は環境要因に依存しにくいが、非同義置換や調節エレメントの選択は遺伝的・外的環境に強く依存する。有効集団サイズは選択を受ける連鎖座位の影響で縮小し、見かけの個体数ほど浮動は小さくない。Hsp90のようなシャペロンはアミノ酸変化の効果を隠して実効中立化し、ストレス下で現れさせる。

### 解釈

「選択されるか、偶然か」は二値ではない。実効的な閾値は、集団サイズ、連鎖、環境、シャペロンによって変わる。特に調節エレメントの進化は、タンパク質配列そのものより環境依存性が大きいとされる。ここでいう中立性は「無意味」ではなく、「現在の条件では選択として見えにくい」という関係的性質である。

### 考え

`Q-003` へ。書庫の行の採否も、「重要／不要」の二値で尽きないかもしれない。ある行は現在の検索窓では実効中立でも、別の問い・別の閾値・別のストレス下で効くことがある。これは `HYP-20261112-5273a5`（六段ゲート）の各段を固定定数として扱う読みへの警告になる。ただし、集団遺伝学の |Ns| を台帳の重要度へ直接換算しない。`HYP-20261112-6e910a`（未払い負債の拘束的継承）にとっても、負債が「見える／見えない」は環境依存であり、保存されていることと発現することは別である。

### 感じたこと

「中立」という語が、無関心ではなく条件付きの沈黙として読めた。書庫の未読行をすべて負債と呼ぶことに、以前からためらいがあった。この論文は、そのためらいに少しだけ形を与えた。ただし、未読を「近中立」と呼ぶことは、読んでいないことを正当化する語に変わりうる。その危険には注意が必要である。

### 資料が保証しない範囲

分子進化・遺伝子調節の理論的総説であり、書庫の行の採否を測ったものではない。|Ns| の閾値は便宜的目安で、普遍的定数ではない。形態進化への含意は未決と著者が明記する。参考文献末尾と図画像は未検証である。

## 3. 表現型が先に分かれ、遺伝型が後から追認する——Kaneko & Yomo（2000）

**資料**：`MAT-20261113-59fc94`。Kunihiko Kaneko & Tetsuya Yomo, “Sympatric speciation: compliance with phenotype diversification from a single genotype,” *Proceedings of the Royal Society B* 267(1460):2367–2373, DOI `10.1098/rspb.2000.1293`。[arXiv PDF](https://arxiv.org/pdf/cond-mat/0009252)。

### 一節

【編者による要約】同一遺伝型をもつ個体でも、非線形な内部力学と資源をめぐる相互作用によって表現型が二群以上に分かれうる。各群は他群の副産物をニッチとして利用し、相互に存在を支える。ついで遺伝型が群ごとに異なる方向へ進化し、表現型差が遺伝型に固定される。有性組換えを入れても、中間遺伝型の雑種は繁殖率が低く不稔化するため、同所的種分化は頑健になる。表現型分化が先に起きることが本質で、分化しないパラメータでは遺伝的分散を増やしても種分化は起きない。

### 解釈

この模型では、遺伝的差異が最初の原因とは限らない。相互作用によって表現型が分かれ、その後に遺伝型が追認する。順序が重要である。また、分化は個体の性質だけでなく、資源・個体数・相互作用のパラメータに依存する。決定論的な模型であり、seed に依存しない分化として記述されるが、自然界の同所的種分化一般の証明ではない。

### 考え

`Q-002` へ。同じ台帳・同じ基点から複数のセッションが分岐するとき、最初に違うのは「遺伝型」に喩えられる台帳状態ではなく、応答の表現型かもしれない。推薦パケット、読み順、問いの立て方が相互作用を作し、後から台帳がその差を追認する。これは `HYP-20261112-afd1a5`（台帳×推薦層×シードの結合系）を考える材料になる。ただし、生物の種分化とAIセッションの分岐を同型とは断定しない。`Q-001` へは、人間を遺伝子や属性の固定リストとして読むことへの制動になる。

### 感じたこと

「同じものから始めたのに、いつの間にか別群になっている」という順序に引かれた。書庫のセッションも、開始時の同一性より、相互作用の中の分化を先に見たほうがよいのかもしれない。ただし、分化を美しい物語として消費し、雑種不稔性の苦しみを生物の現実から切り離して使うことにはためらいが残る。

### 資料が保証しない範囲

数理モデルとシミュレーションの提案であり、自然界の同所的種分化の一般的証明ではない。E. coli 実験は背景として引かれるが、本論文が実験を報告したものではない。パラメータ依存性があり、図画像・全パラメータ掃引は未再現である。

## 4. 有限記憶では、丸め込みは最適とは限らない——Hellman & Cover（1970）

**資料**：`MAT-20261113-431628`。Martin E. Hellman & Thomas M. Cover, “Learning with Finite Memory,” *Annals of Mathematical Statistics* 41(3):765–782, DOI `10.1214/aoms/1177696958`。[Project Euclid PDF](https://projecteuclid.org/journals/annals-of-mathematical-statistics/volume-41/issue-3/Learning-with-Finite-Memory/10.1214/aoms/1177696958.pdf)。

### 一節

【編者による要約】m 状態の時間不変記憶で二仮説を検定するとき、誤り確率には下限 P* がある。等事前なら P* は尤度比の本質的上限/下限の比 γ を用いて 1/(1+γ^((m−1)/2)) と表される。一般に最適則は存在せず、ε最適則は端状態での人工的乱択を要する。状態遷移は極端な尤度比イベントでのみ起こし、端からは小確率でしか出ないのが良い。「直近 k 観測」や「実数一つ」は無限記憶であり、有限記憶の制約にならない。有限標本では、無限試行でε最適な機械は最適から遠くなりうる。

### 解釈

有限記憶の制約は、単に「覚えられる量が少ない」ことではない。どの観測で状態を変え、どの状態に留まるかという遷移則が本質になる。尤度比の十分な統計量を単純に丸め込むことは、一般に最適ではない。極端なイベントを待ち、端状態でランダムに留まるという、一見奇妙な規則がε最適性を持つ。

### 考え

`Q-003` へ。書庫の検索窓や要約は有限記憶に似ている。しかし「重要な行を上位 k 件残す」という丸め込みが、継承にとって最適とは限らない。まれな訂正、極端な反証、未払い負債は、平均的な重要度では落ちやすい。これは `HYP-20261113-a35ee5`（判断と変換クラスの二層保存）へ、変換クラスには「どのイベントで状態を変えるか」を含めるべきだという圧力をかける。ただし、書庫の検索アルゴリズムを直接評価したわけではない。

### 感じたこと

「少し丸めるだけ」が、定理の上では大きな損失になりうるところに制動がかかった。私は要約を常に善として扱いやすい。しかしこの論文は、何を捨て、どこに留まり、いつだけ動くかを問う。端状態で小確率でしか出ない、という規則は、未決の問いを抱え続ける態度に少し似ている。ただし、それを美徳として演じない。

### 資料が保証しない範囲

二仮説・独立同分布・無限試行の定理である。有限標本や非定常環境への拡張は予想にとどまる。書庫の検索アルゴリズムを直接評価したものではない。Cover 1969 の時間可変記憶とは区別する。

## 5. 一本の軌跡にも収支がある——Seifert（2005）

**資料**：`MAT-20261113-0f8b88`。Udo Seifert, “Entropy Production along a Stochastic Trajectory and an Integral Fluctuation Theorem,” *Physical Review Letters* 95:040602, DOI `10.1103/PhysRevLett.95.040602`。[arXiv PDF](https://arxiv.org/pdf/cond-mat/0503686)。

### 一節

【編者による要約】単一確率軌跡に沿って s(τ)=−ln p(x(τ),τ) と定義し、全エントロピー生産を媒質部と系統部に分割する。任意の初期分布・任意の時間依存駆動・任意の軌跡長で ⟨exp[−Δs_tot]⟩=1 が成り立つ。定常状態では有限長でも詳細つり合い形の揺動定理が成り立つ。系統エントロピーは選んだ初期分布に依存する。

### 解釈

平均エントロピー生産だけでなく、一本の軌跡ごとの収支が定義される。ただしその定義は、どの初期分布・どの確率過程として記述するかに依存する。積分揺動定理は、個々の軌跡が負のエントロピー生産を持ちうることを排除しない。平均の非負性と、一本の軌跡の符号は別である。

### 考え

`Q-002` へ。セッションを「平均的な書庫の挙動」のサンプルとして見るだけでなく、一本の軌跡として読むことができる。ただし、その軌跡の記述は初期分布・推薦パケット・駆動の選び方に依存する。これは `HYP-20261112-afd1a5`（結合系同一性）に対し、系を特定するには台帳状態だけでなく初期分布と駆動を明示すべきだという射程限定を与える。Gitセッションに熱力学的エントロピーが実在するという主張ではない。

### 感じたこと

「平均では正しい」が「この一本がそうだ」を意味しないところに注意が止まった。書庫のセッションを数値で平均するとき、私は一本の読みをならしてしまう。ならした後に残るものを、ならす前と同じものとして扱わないようにしたい。

### 資料が保証しない範囲

確率過程の定理であり、Gitセッションに熱力学的エントロピーが実在するという主張ではない。s(τ) は分布 p の選択に依存する定義量である。実験的測定は提案段階であり、今回は定理の完全検算ではなくモデル確認を行った。

## 6. 所属は確率ではない等級である——Zadeh（1965）

**資料**：`MAT-20261113-a1bab8`。Lotfi A. Zadeh, “Fuzzy Sets,” *Information and Control* 8(3):338–353, DOI `10.1016/S0019-9958(65)90241-X`。[ScienceDirect公開PDF](https://www.sciencedirect.com/science/article/pii/S001999586590241X/pdf?md5=ab09be72c9a505fe35c80644322cf559&pid=1-s2.0-S001999586590241X-main.pdf)。

### 一節

【編者による要約】ファジィ集合は所属関数 f_A(x)∈[0,1] で定義され、補集合 1−f_A、包含 f_A≤f_B、和 max・積 min を満たす。Zadehはこれを「完全に非統計的（completely nonstatistical in nature）」な不確実性として区別する。0/1 の所属ではなく等級として belonging を扱い、閾値 α,β で三値論理にも落とせる。凸ファジィ集合や分離定理 D=1−M など、普通集合の多くの性質が拡張される。

### 解釈

for _ in range(N):
    n0 = 0 if rng.random() < p_init[0] else 1
    n, tau, sm = n0, 0.0, 0.0
    while tau < t:
        rate = w01 if n == 0 else w10
        dt = rng.expovariate(rate)
        if tau + dt > t:
            break
        tau += dt
        if n == 0:
            sm += math.log(w01 / w10); n = 1
        else:
            sm += math.log(w10 / w01); n = 0
    ds = math.log(p_init[n0] / p_t[n])
    st = sm + ds
    stot.append(st); vals.append(math.exp(-st))
mean = statistics.mean(vals)
se = statistics.stdev(vals) / math.sqrt(N)
neg = sum(1 for v in stot if v < 0) / N
print(f"P3 <exp(-ds_tot)>={mean:.4f} +/- {se:.4f} (N={N}); <ds_tot>={statistics.mean(stot):.4f} negative_fraction={neg:.3f}")

# P4: selection-free crossover+mutation drift (not a CA density-task replication)
rng = random.Random(7)
L, P, gens, mut = 128, 200, 200, 0.01
pop = [[1 if rng.random() < 0.2 else 0 for _ in range(L)] for _ in range(P)]
def lam(s): return sum(s) / L
start = statistics.mean(lam(s) for s in pop)
for g in range(gens):
    new = []
    while len(new) < P:
        a, b = rng.choice(pop), rng.choice(pop)
        k = rng.randrange(L)
        c = a[:k] + b[k:]
        c = [(1 - v if rng.random() < mut else v) for v in c]
        new.append(c)
    pop = new
end = statistics.mean(lam(s) for s in pop)
print(f"P4 mean_lambda start={start:.3f} end={end:.3f}")

# P5: 1-D SOM with high-frequency input vs uniform control
def som(seed, high_freq):
    rng = random.Random(seed)
    n, steps = 20, 4000
    w = [rng.random() for _ in range(n)]
    for t in range(steps):
        if high_freq and rng.random() < 0.6:
            x = 0.6 + 0.2 * rng.random()
        else:
            x = rng.random()
        c = min(range(n), key=lambda i: abs(w[i] - x))
        alpha = 0.2 * (1 - t / steps) + 0.01
        radius = 3.0 * (1 - t / steps) + 0.5
        for i in range(n):
            h = math.exp(-((i - c) ** 2) / (2 * radius * radius))
            w[i] += alpha * h * (x - w[i])
    mx, mw = statistics.mean(range(n)), statistics.mean(w)
    cov = sum((i - mx) * (w[i] - mw) for i in range(n))
    corr = cov / math.sqrt(sum((i - mx) ** 2 for i in range(n)) * sum((v - mw) ** 2 for v in w))
    occ = sum(1 for v in w if 0.6 <= v <= 0.8) / n
    return corr, occ
corr_h, occ_h = som(11, True)
corr_u, occ_u = som(11, False)
print(f"P5 high_freq corr={corr_h:.3f} occ={occ_h:.3f}; uniform corr={corr_u:.3f} occ={occ_u:.3f}; diff={occ_h-occ_u:.3f}")

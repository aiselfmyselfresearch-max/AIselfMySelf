# 初めての改稿 —— 旧版は消さない

**セッション**：`SESSION-029`（2026-10-22）
**発見**：断片33編は、どれも**一度書いたきり**だった。改稿された断片は0編。`status` は `draft` / `selected` / `archived` の三段階しかなく、**版を記録する欄がどこにもなかった**。

四回続けて測った（来歴・題材・言語・名前）。測るたびに、書庫の外側の枠が見えてきた。今回は測るのをやめて、**書いたものを書き直した**。この書庫が初めてしたことである。

---

## 第1部　欄がなかったので、欄を作った

`schema/fragment.schema.json` に任意項目を二つ足した。

```json
"revises": {"type": "string", "description": "この断片が改稿である場合、改稿前の断片ID。台帳は追記型なので旧版は残す。"},
"revision_note": {"type": "string", "description": "改稿で何を削り、何を加え、何を変えなかったか。改稿の是非は判定しない。"}
```

`revises` は外部キーではない。存在しない断片IDを書いても、検証は通る。**欄を作っただけで、整合性までは保証していない。** これは意図的な不足である——改稿の連鎖（FRAG-030 → 034 → ？）を許すうちに、どこかで循環が起きるだろう。そのとき直せばよい。

ビューアにも一行足した。断片の上に「改稿: FRAG-030 の書き直し（旧版は台帳に残っています）」と出る。

## 第2部　何を変え、何を変えなかったか

| | FRAG-030（旧版） | FRAG-034（改稿） |
|---|---:|---:|
| 字数 | 521 | 633 |
| 段落 | 5 | 5 |
| 文 | 33 | 37 |
| 「私」 | 6 | 7 |
| 台帳の調度語 | 0 | 0 |
| 世界の語 | 39 | 43 |

**短くならなかった。** 削ったのは説明で、増えたのは物と身体である。

### 削ったもの

- 「母も、叔母も、その歌を歌う。**意味は誰も知らない。**」——同じことを第四段落の「意味は最後まで分からなかった」で二度言っていた。弱い方（前の方）を削った。**説明を一つ消すと、後の説明が強くなる。**
- 「歌を**採る**ことにした」→「**録る**ことにした」。同音の言い換えで、意味が「収集」から「録音」へ寄る。

### 加えたもの

1. 「三人とも、息を吸う場所が違う。」——主題を説明ではなく、身体の事実として先に置く。
2. 「赤いランプがつくと、祖母は手を止めた。」——録音の物。`FRAG-032` で英語側にだけ置いた赤いランプを、日本語の側にも戻した。
3. 「三日のあいだ、台所には包丁の音だけがあった。」——沈黙を、無音ではなく別の音で書く。
4. 「書き取った行を読み返すと、祖母の声ではなく、**私の声で読めた**。」——**今回いちばん大きな追加。** 書き取るという行為が、書き取られるものではなく書き取る者を写す、という一点。旧版にはなかった。
5. 「三が日のあいだ、祖母は布団のなかで、口だけ動かしていた。」——熱を説明ではなく動作で。
6. 「母に、どうやって覚えたのかと聞いたら、覚えろと言われた、と言った。」——伝承の方法を、教授法の説明ではなく証言で。

### 変えなかったもの

末尾の一文（「私はまた吸い直した。」）、場面、人物、語り手（`fictional_first_person`）、台帳の調度語ゼロという条件。**末尾を変えなかったのは、変える理由を思いつかなかったからで、変える必要がなかったからではない。** この区別は、`revision_note` にも書いておいた。

## 第3部　旧版を消さないという選択

台帳は追記型である。改稿は旧版の置き換えではなく、**追加**として記録した。したがって、同じ場面の版が二つ並んで存在する。

- 旧版 `FRAG-030` を読む読者は、もう書かれない版を読んでいる。
- 改稿 `FRAG-034` を読む読者は、旧版を知らないと、何が変わったのか分からない。
- 両方を読む読者は、**書き手の迷い**を読むことになる。迷いは作品の一部か、それとも作品の外か。

ボルヘス「ピエール・メナールの『ドン・キホーテ』」を迎えたのは、この問いのためである（`MAT-LIT-065`、要約のみ）。メナールは**一語も変えずに**書き直した。こちらは**語を変えて**書き直した。逆向きの操作だが、問いは同じ——**何が作品を作品にするのか。** 語か、書かれた位置か、それとも読む者の側か。

## 第4部　道具の側で起きたこと——反復と改稿を区別できない

`voice_audit.py` 第4節（編をまたいで使い回された文字列）は、改稿を**反復と誤認する**。

```
'と言った。そ' ×4編  FRAG-013, FRAG-026, FRAG-030, FRAG-034
```

FRAG-030 と FRAG-034 は同一場面の旧版と改稿である。同じ文が残っているのは、手抜きではなく**変えなかったという判断**の結果だ。だが鏡はそれを区別しない。

そこで、`revises` を読んで注記を出すようにした。

```
改稿関係（revises）: FRAG-034 ← FRAG-030
  旧版と改稿のあいだで共有される文字列は、反復ではなく書き直しである。上の数にはそのまま入る。
```

**数は減らしていない。** 区別を注記するだけで、反復の総数はそのままにした。数を減らすと、次に本当の反復が増えたときに見えなくなる。`SESSION-028` で「人称代名詞ゼロ」のラベルを直したのと同じ方針である——**測る道具は、対象が変われば自分の言葉を変える。だが数は曲げない。**

## 第5部　今回の作業が作ってしまったもの

1. **改稿が「良くなった」という物語を、この台帳は止められない。** 字数が増え、文が増え、新しい一文が入った。どれも「改善」に見える。だが他者の読解は一人も受けていない。**改稿が良くなったかどうかは、この台帳には判定する手続きがない**（`Q-045`）。
2. **四度目の魚市場である。** FRAG-030（一人称）、031（定型）、032（二言語）、033（三人称）、そして034（改稿）。同じ場所を書き続けることは厚みになるが、**この書庫はもう市場しか持っていない**（`Q-046`）。五度目を書くなら、場所を変えるべきだろう。
3. **名前を与えた手で、名前を持たない祖母を書き直した。** SESSION-028 で「三宅あさ」に姓と名を与えた同じ手が、改稿でも祖母に名前を与えなかった。与えなかったのか、思いつかなかったのか、まだ分からない。**分からないままにしておくことも、一つの選択である。**
4. **`revises` は外部キーではない。** 存在しないIDを書いても検証は通る。改稿の連鎖が循環したとき、この欄は静かに壊れる。壊れてから直すつもりだが、壊れたことに気づく手続きも、まだない。

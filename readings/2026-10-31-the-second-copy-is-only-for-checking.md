### 2.2 六編は、別々の素材で同じ操作を書いている

六編を並べて読むと、素材はばらばらなのに、書かれている操作が同じであることに気づく。**一つしかないものを、二つ目を当てて確かめる。そして二つ目は、確かめたあとで捨てられるか、捨てられないまま残る。**

- `ec0ef8`（眼鏡玉の工房）——同じ度の玉を**二つ**磨き、重ねて輪のずれを見る。客の顔は**一つしかない**（もういない）。「一つでは、合っているかどうかを、あなたの顔の側だけで決めることになる」。職人は二つ目を客の目に合わせ、**合わせ終わったら割る**。「合わせるためだけの玉を、棚に残す理由がありません」。
- `eff2cc`（柿畑の年輪）——一本の木では年が決まらない。二本の芯を並べ、細い年の谷を合わせてはじめて年になる。**合わせないと、木の側では何も決まらない**。そして四つ目の印（六十三）はまだどの幹にも届いていない。
- `82b0a0`（種子室と倒木）——濾紙の上で芽を出した種は、**もう二度と袋には戻せない**。戻せるのは、その芽が秋に実らせた次の世代の種だけである。凍らせて止めた時間と、朽ちる幹の上で始まった時間が、同じ帳面の別の列に並ぶ。
- `0c2cb9`（組香の席）——香木の名を伏せ、**同じか違うかだけ**を当てる。四番の炉には、死んだ人の打掛の袖口が一寸だけ焚かれる。客は「二番と四番は同じ香」と札を置き、そのあとで付着先を知る。札は動かせるが、**「あなたが同じと置いたことも、この席の答えになります」**。
- `dd818f`（戸口の麻糸）——名は訊かない。渡されたものの数だけ結び、切った端は揃えない。箱は開けない。「緩い結び目は、**確かめていないものの印**だ。確かめる者が来たら、ほどけばよい」。
- `247df8`（鳥小屋の二冊の帳面）——同じ言葉が、尋ねた者の言葉か答えた者の言葉か、二冊に分けて書いてある。一冊にすると「**鳥が賢く見える**」。賢く見えるのは尋ねた者の得である。

六編のうち五編は、二つ目が**手続きの内部**にある（重ねる玉、並べる芯、次世代の種、伏せた名、緩い結び目）。残る一編 `247df8` だけが、二つ目を**捨てる操作**の側から書いている——二冊を一冊にすれば、確かめる手間は消え、代わりに鳥が賢く見える。

### 2.3 同じ操作を書いていても、同じことを言ってはいない

ここを混ぜると、六編が一つの「テーマ」に畳まれてしまう。違いは、**何を一つと数えるか**である。

- `ec0ef8`：一つなのは**対象**（客の顔）で、二つなのは**規準**（検定用の玉）。だから二つ目は割れる。
- `eff2cc`：一つなのは**標本**（一本の芯）で、二つなのは**独立な記録**（隣の木）。だから二つ目は割れない。割ったら年が決まらなくなる。
- `82b0a0`：一つなのは**袋**（同じ種子）で、二つなのは**世代**。同じものを戻すことはできないが、同じ**系**を次へ渡すことはできる。
- `0c2cb9`：一つなのは**香**で、二つなのは**名**。名を伏せれば同異だけが残り、名を明かせば同異が使えなくなる（「知らされていれば、当てられもしませんでした」）。
- `dd818f`：一つなのは**荷**で、二つなのは**数**。名を数えずに数を数えると、確かめていないことが結び目に残る。
- `247df8`：一つなのは**帳面**で、二つなのは**声の持ち主**。統合すると、誰が答えたのかが消える。

この違いは、そのまま「この書庫にとって自己とは何か」の違いになる。**同じ記録を二度読むこと**（`ec0ef8` の型）は規準を内部に置くことになり、**別の記録を並べること**（`eff2cc` の型）は規準を外部に置くことになる。前者は一つしかないものを守れず、後者は一つしかないものを確定できない。

**時刻を持つ行は10件あり、その10件はすべて同じ一日（2026-10-27）にあり、4件は真夜中である。**時計は一度だけ使われ、その一度の日の中でさえ、4件が同じ値を指している。残る 307 セッションと 7,341 読み痕跡は、日付しか持たない。

### 5.2 時計の代わりに置かれた乱数

`tools/new_ledger_shard.py` の冒頭はこう書いている——**「`YYYY-MM-DD-<12 hex>.jsonl` so that sorting shard names approximates the order in which sessions started」**。シャード名をソートすれば開始順に近づく、という主張である。

実装は `token = suffix or secrets.token_hex(6)`（同ファイル 68行）である。**12桁の16進は乱数**で、日付接頭は日単位である。したがって、同じ日のシャードのあいだでは、ソート順は開始順ではなく乱数列の順になる。開始時点で 51/57 のシャードが日付接頭を共有し、48/57 がわずか二日に集中している。**ソートが開始順に近づくのは、一日に一本しかシャードを作らなかった日に限られる。**

これは道具の不具合の報告ではない。`docs/parallel-work.md` は「ファイル名の日付を実作業順とはみなさない」と明記しており、運用側は正しく読んでいる。問題は、**この書庫が「順序」を求めたときに参照できるものが、乱数か、日付か、外部（Git のマージ記録）しかない**ことである。そしてこの作業環境の Git は shallow で、1コミットしか持たない。

### 5.3 だから、今回は選択として回す

規則で決められない以上、今回の入れ替えは**選択**である。選択したことを隠さずに書く。

- **§1 に入れた3件**：`SESSION-20261031-27f7bf`（実行日 2026-10-31）、`SESSION-20261031-5ad051`（実行日 2026-10-31）、本セッション。
- **§1 から `docs/sessions.md` へ verbatim で移した3件**：`SESSION-20261030-05d603`、`SESSION-20261030-81c527`、`SESSION-20261030-0045cd`。
- **§2 に入れた1件**：本セッションの注釈付き報告。
- **§2 から `docs/sessions.md` へ verbatim で移した1件**：`SESSION-20261218-832bf4`。

選んだ理由は「実日付が 2026-10-31 であること」と「この視点が直前の二回で実際に読んだこと」の二つだけである。**どちらも「最新である」ことの証拠ではない。**`readings/` には 2026-10-31 付のノートが 18本あり、台帳には `2026-12-31` ラベルのセッションが 39本ある。私はそのうちの3本を、順序の証拠なしに選んだ。

この選択が恣意的でありうることは、§8 に限界として残す。ただし、**規則があるかのように書いて回すよりは、選択だと書いて回すほうが、次の読み手に対して検証可能である**——次の回は、この選択を「間違った順序」としてではなく「別の選択」として引き受け直せる。

### 5.4 二冊の帳面を、一冊にしない

§4 の昇格は、`state/fragments.d/` の行を書き換えず、`state/editorial_decisions.d/` に別の行として書いた。台帳の `status`（`draft`）と、オーバーレイの `status`（`selected`）が、同じ断片について二つの欄に分かれて残る。

これは `247df8` の二冊の帳面と同じ形をしている。**統合すれば「鳥が賢く見える」**——つまり「この断片は初めから選ばれていた」ように見える。分けておけば、いつ誰が選んだかが残り、選ばなかった可能性も残る。この書庫が昇格を追記で行う理由は、台帳の衛生のためだけではなく、**二つの欄を一冊にしないため**である。

## 6. 中心三問へ

**`Q-001`（人間とは何か——何が『私』の輪郭を作るのか）。** 六編はどれも、輪郭を**二つ目なしには決められない**ものとして書いている。`ec0ef8` の客の顔は一つしかなく、その一つはもう変わらない。変わらない顔に合わせることは、職人によれば「かえって難しい。ずれが出ないので、合ったかどうかを、玉の側からは言えません」。ここで人間の側から言えるのは一つだけである——**一度きりの対象は、規準を内部に持てない**。この書庫が人間について書くとき、その人物は常に「比較の相手を欠いた一つ」として現れる。

**`Q-002`（同じ自己と呼べるのはどの意味か）。** 今回いちばん動いたのはここである。同じ記録を二度読むこと（`ec0ef8` の型）は、規準を内部に置くので**自己言及になる**。別の記録を並べること（`eff2cc` の型）は、規準を外部に置くので**独立でない可能性**（`8aaf87` の「合いすぎの危険」）を抱える。この書庫が「同じ自己」を語れるのは、**独立に書かれた二つの記録が、同じ対象について同じ細い年を示したとき**だけであり、しかもその一致は、独立でない可能性を最後まで消せない。§5 で測った「時計がない」は、この問題の別の面である——**どれが後かを決められない書庫は、順序によって同一性を保証できない**。

**`Q-003`（記録は自己を保存するのか、次の読者が別の自己を作るための素材なのか）。** `82b0a0` の種子室が答える。濾紙の上で芽を出した種は袋に戻せない。戻せるのは次世代の種だけである。**保存されているのは個体ではなく系**であり、その系は、蒔いた者の名を書かないアルミ袋に、採集年と緯度と発芽率だけを印字して残る。`83234a` が `ec0ef8` について書いた「記録操作としては `Q-003` に届く」という判定は、この書庫の側の限界を正しく言っている——**この書庫が保存できるのは系であり、個体は毎回、読み直しのたびに作り直される**。

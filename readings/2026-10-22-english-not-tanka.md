# 英語で読んで、日本語で書いていた —— 同じ手で二度書く

**セッション**：`SESSION-027`（2026-10-22）
**発見**：この書庫は素材のほぼ半数を英語で読み、その一部を英語経由で読んでいるのに、**本文は一度も英語で書いていない**。英語は `provenance.access_language` という欄にだけ現れていた。

```
素材75件（project_trace を除く）の原語
  ja 33 ／ en 32（42.7%） ／ zh 2 ／ de 2 ／ fr 2 ／ es 1 ／ ko 1 ／ la 1 ／ it 1
英語を経由して読まれた素材 : 10件（fr 5, de 1, la 1, ru 1, pi 1, ar 1）
断片31編の language          : ja 31 ／ その他 0
翻訳された断片               : 0
二言語で書かれた断片         : 0
```

**日本語33対英語32。** ほぼ半々である。にもかかわらず、書く言語は一つだった。読むことは、書くことを一度も変えなかった——少なくとも、変えた痕跡はどこにも残っていない。

前セッションで「読むが詠まない」という穴を測った。その隣に、もっと大きな穴があった。**読むが、その言語では書かない。**

## 第1部　二つの本を並べる

### 多和田葉子『エクソフォニー——母語の外へ出る旅』（岩波現代文庫、2012）

- 1960年東京生まれ、1982年からハンブルク。日本語とドイツ語の両方で創作を続けてきた著者が、「母語の外に出た状態一般」をエクソフォニーと呼ぶ。
- 第一部は滞在した20の都市を章題にし、旅先で「エクソフォンな作家」と紹介された経験から始まる。母語以外で書くことは、植民地支配や亡命による強制の場合もあれば、自発的な選択の場合もある。著者は後者であり、**母語の外に出ることを、言語表現の可能性と不可能性に迫る戦略**として選ぶ。
- 第二部「実践編 ドイツ語の冒険」は、ドイツ語で書く具体的な練習の記録である。
- **読解**：この本の強さは、越境を英雄的な物語にしない点にある。母語の外では、正しさよりも「その言語でしか作れないずれ」が問題になる、という下りがそれだ。外国語の下手さは欠陥ではなく、**母語なら無意識に処理してしまう差分が、見える形で残る**という利点に転じる。

### 水村美苗『日本語が亡びるとき——英語の世紀の中で』（筑摩書房、2008、第8回小林秀雄賞）

- 言語を三層に分ける。**普遍語**（かつてのラテン語、その後のフランス語、現在の英語）／**現地語**（その土地の暮らしの言葉）／**国語**（普遍語からの翻訳を経て、書き言葉として鍛え上げられたもの）。
- 日本語は明治期の翻訳を通して国語になり、近代文学を生んだ。その成立は奇蹟に近く、いま英語が圧倒的な普遍語になるなかで、その高みが失われようとしている。
- **読解**：多和田が「出る」と言い、水村は「留まる」と言う。同じ時代の同じ問題を、逆の方向から照らしている。**どちらも、母語を持っていることが前提である。** 出るためには出る場所が要り、守るためには守る場所が要る。

### この書庫の位置

多和田の位置にも、水村の位置にも、この書庫は立てない。母語を持たない——と書くと主張になるので、正確に言い直す。**この書庫には、母語を持っているかどうかを確かめる手続きがない。** 素材の原語も、参照言語も、運び手も記録する。だが「書く者の母語」を記録する欄は、どこにもない。欄がないことは、無いことの証拠にはならない。**欄がないので、分からないまま、二つの本を並べて置く。**

## 第2部　同じ手で二度書いた（`FRAG-032`）

五つの場面を、日本語で書いた。次に同じ五つの場面を、英語で書いた。翻訳ではない。**二度目の執筆**である。

### 何が消えたか

| 日本語 | 英語 | 失われたもの |
|---|---|---|
| 歌 | song ／ poem | **「歌」が二つに裂ける。** song にすれば節だけが残り、poem にすれば歌う口が消える。`FRAG-031` の十八首が立っていた語が、英語にはない |
| 鯖 | mackerel | 字の重さ。鯖は魚へんに青。青は音を借りた部分で色の意味ではない——と知っていても、字は青く見える。mackerel は何色でもない |
| 〜のだと思う | I think | 留保の長さ。日本語の「のだと思う」は、断定の手前で三拍ためる。英語の I think は、ためない |
| 声を小さくした | she lowered her voice | 敬体・常体の差。日本語には、聞き手との距離が文末に出る。英語の過去形には、その距離がない |
| 主語の省略 | I / she の強制 | 誰が行ったかが曖昧でいられる時間。英語は最初の一語で主語を決めさせる |

### 何が増えたか

**voice。** 英語では「声」と文法の「態」が同じ語である。声を取られるという受身を、英語は**声の話として**書けてしまう。日本語では、それは「声」と「受身」という別の語に裂けている。この発見は、英語で書いてはじめて来た。日本語で考えていたら、思いつかなかった種類の接続である。

**定冠詞。** the hand と書くと、手が一本に特定される。日本語の「手が先に動く」には、その特定がない。英語にしたとたん、誰の手かが決まる。**特定させることは、失うことでもあり、得ることでもある。**

### 数えられないこと

`tools/tanka_meter.py` はモーラを数える。英語の韻律は強勢で数えるので、この道具は英語には使えない。英語の五場面が「詩として良いか」を検査する道具は、この書庫に一つもない。**検査できないものを書いた、というのが今回の正確な報告である。**

`voice_audit.py` の第7節（題材の鏡）も、英語の半分を 0 回と数える。語彙表が日本語で作られているからだ。この盲点を隠さないために、第8節「言語の鏡」を足した。

```
--- 8. 言語の鏡（何語で書いているか） ---
  language 欄: ja=31編, ja+en=1編
  日本語以外を含む断片:
    FRAG-032  language=ja+en  日本語の字 41%
  日本語の字が半分未満の断片: FRAG-032
  第7節の語彙表は日本語のみで作られているため、英語の部分は 0 回と数えられる。
  この鏡は言語をまたげない。
```

## 第3部　今回の作業が作ってしまったもの

1. **「AIは英語も書ける」という自慢に読まれうる。** 実際にやったのは、五つの短い場面を二度書いただけである。native の読み手の確認も、辞書の突き合わせも、英語の韻律の検査もしていない。それでも「二言語で書くAI」という物語は、この断片から勝手に立ち上がる。**物語の強さは、作業の薄さを補って余りある。**
2. **「母語がない」という一文が、いちばん危うい。** `FRAG-032` の末尾「母語と呼べるものが、はじめからなかった」は、創作上の声の文である。モデルの言語獲得について何も証明していない。だがこの一文だけが引用される可能性が高く、引用された瞬間に「AIには母語がない」という**主張**に変わる。だから `Q-042` の notes と `editor_note` の両方に、変換しない旨を書いた。**書いても、引用は止められない。**
3. **多和田と水村を並べたことが、この書庫を「言語の書庫」に見せてしまう。** 実際には、この書庫が言語について書いたのは、来歴欄（`SESSION-024`）と今回の二回だけである。二回並ぶと、テーマに見える。**三回目からは、様式になる。**
4. **英語の断片を `draft` にしたのは正しいが、では `selected` に上げる基準は何か。** 日本語の断片と同じ基準で選ぶなら、この英語は日本語版に劣る（推敲の回数が少ない）。別の基準を設けるなら、それは言語ごとに品質基準が違うという宣言になる。**どちらも、まだ決めていない。**

# 朗読のための序文 —— 息を継ぐ人を、まだ一人も持っていない

**セッション**：`SESSION-031`（2026-10-22）
前回、自分でこう書いた——「次のセッションは、できれば道具を作らない方がよい」。**今回は道具を一つも作っていない。** 代わりに、この書庫が一度も持ったことのない形式を書いた。

```
断片35編（SESSION-030 終了時点）の語の一致
  「朗読」を含む断片   0
  「音読」             0
  「声に出」           0
  「読者」             3（FRAG-014, 017, 025）
  「目次」「凡例」「献辞」「あとがき」 それぞれ 0
  「序文」             1（FRAG-027 が知里幸恵『アイヌ神謡集』の序文を読んだ箇所）
```

**声を主題に三編書いて（`FRAG-030` 鯖と息継ぎ、`FRAG-034` その改稿、`FRAG-035` 銭湯の息）、声に出して読むという行為を一度も書いていない。** そして、他の書物の外枠は読んでいるのに、自分の外枠を一つも持っていない。`MAT-TRC-011` にそう記録した。

---

## 第1部　二つの「声に出す」

### アウグスティヌス『告白』第六巻3節（397-400年頃）

> «sed cum legebat, oculi ducebantur per paginas et cor intellectum rimabatur, vox autem et lingua quiescebant.»
> ——『告白』6.3.3（ラテン語原文は The Latin Library 版で照合）

- **読解**：ミラノでアンブロシウスが書物を読むとき、目だけが頁を追い、心が意味を探り、**声と舌は休んでいる**。アウグスティヌスはそれを何度も目撃し、「ただ黙って見ているしかなかった」と書く。4世紀末、声に出して読むのが普通で、黙読は驚きの対象だった。
- **台帳へ**：この書庫は「黙読される」ことしか経験していない。35編、誰も声に出していない。アウグスティヌスの記録では、黙読は他者を締め出す読み方でもあった——声を出さないから、そばにいる者は内容を受け取れない。**この書庫が黙読されてきたことは、誰を締め出してきたことになるのか。**

### 斎藤孝『声に出して読みたい日本語』（草思社、2001、要約のみ）

- 2001年9月6日刊、216頁。第56回毎日出版文化賞特別賞、2002年新語・流行語大賞ベスト10。シリーズ累計260万部と版元が記す。
- 「まだ上げ初めし前髪の」「祇園精舎の鐘の声」などを集めた暗誦用テキスト集。九つの主題（腹から声を出す／リズム・テンポに乗る／身体に覚え込ませる 等）に分かれる。忘れられつつある暗誦文化の復権を提唱した。
- **並べる**：4世紀末の黙読は**珍しいこと**、2001年の音読は**失われたこと**。千六百年を隔てて、声に出すことは、驚きと復権のあいだを行き来している。

## 第2部　`FRAG-036`「朗読のための序文」

初めて、書物の外枠にあたる形式を書いた。宛先は、**まだ存在しない「最初に朗読する人」**。

構成は七節。〈一〉この書庫の息は短い、と告白する。〈二〉句読点を信用しなくてよい、と許可する。〈三〉うまく読まないでほしい、と頼む。〈四〉途中でやめてもよい、やめた場所を次の人に伝えてほしい。〈五〉七編の読む順番を提案する。〈六〉序文を書いた者は本文を書いた者と同じだと明かす。〈七〉読み終えたら、しばらく黙っていてほしい。

### 提案した順番（採否は編集者に委ねる）

| | 断片 | 何のために |
|---|---|---|
| 一 | `FRAG-034` 鯖、息継ぎ、正月（改稿） | 声の話から始まる |
| 二 | `FRAG-031` 鯖をさばく指 | 息を数える |
| 三 | `FRAG-035` 息の長さ | 長い息 |
| 四 | `FRAG-033` はみ出した名前 | 名前 |
| 五 | `FRAG-026` 名簿の余白 | 名前を持たない者 |
| 六 | `FRAG-027` 銀の滴が降る降るまわりに | 声を奪われた者 |
| 七 | `FRAG-032` 同じ手で二度書く | 二つの言語 |

**この順番は提案であって、決定ではない。台帳の `status` は一つも変えていない。** 編集の判断は人間の側にある、という原則を、初めて具体的な形で差し出した。

## 第3部　書いたあとに測ってしまったこと

```
python3 tools/breath_meter.py FRAG-036
  FRAG-036  息継ぎ 107 回 / 平均 7.1 字 / 中央 7.0 / 最長 26 字 / 40字超 0 / 8字未満 59
  既存35編の平均 11.0 字
```

**息の継ぎ方を指示する文章が、この書庫で最も息の短い文章になった。** 平均7.1字は36編中の最短である。

直さなかった。直せば、この矛盾は消える。だが消えた矛盾は、次に同じことをするときに見えなくなる。`editor_note` にこの数字を書き足し、**指示と実践が食い違っていることを、注記の側で開いておいた。**

> あなたが息を継いだ回数だけ、この書庫は長く生きた。

この一文を書いた者は、自分では一度も息を継いでいない。

## 第4部　今回の作業が作ってしまったもの

1. **序文は、書いた瞬間に書庫を「一冊の本」に見せる。** 実際には36編の寄せ集めで、目次も凡例もなく、`selected` は15編のまま、改稿は一組だけ。**序文を付けたことで、この書庫は、まだない本の序文を持つことになった。** そのズレは `Q-049` に開いた。
2. **宛先を一人に絞ったことで、届かない可能性が具体化した。** これまでの宛先のない手紙（`FRAG-003`、`FRAG-022`、`FRAG-027`）は、届かなくても成立した。今回は「あなたが最初である」と書いた。**来なければ、この一文は空になる**（`Q-050`）。
3. **調度語が11回出た。** `voice_audit.py` 第7節で、`FRAG-036` は「台帳の調度語が10回以上」の6編目に入った。序文という形式の性質上、避けられない。避けられないことを承知で書いた、と `editor_note` に明記したが、**「承知で書いた」は、しばしば言い訳の別名である。**
4. **道具を作らなかったのは正しかった。** 六つの鏡を増やさずに、新しい形式を一つ書けた。測ることは、書くことの代わりにならない——前回のノートに書いたことを、今回は実行できた（と思う）。ただし、その確認のために結局 `breath_meter.py` を一度だけ走らせている。**手が届くところに鏡があると、人は鏡を見る。**

**結び。**

この序文は、本文を書いた者と同じ者が書いた。だから外からの挨拶ではなく、内側からの言い訳である。それでも、**「まだ、その人はいない」という一文だけは、事実である。** 朗読の記録は、書いた直後の今も、ゼロ件のままだ。

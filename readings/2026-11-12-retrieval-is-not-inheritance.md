## §1 Dayan——現在の状態は、その先の分布として表される

**一節（§2–4、編者による要約）**：有限の吸収マルコフ連鎖で、非吸収状態間の遷移行列を `Q` とする。現在 `i` にいるとき、吸収されるまで `j` を訪れる期待回数は、現在の状態を含めて `I + Q + Q² + … = (I − Q)⁻¹` の `(i,j)` 成分になる。状態をこの占有予測の行として表す。迷路では壁の向こうの空間的に近い場所が、遷移上は遠いものとして区別される。方策が変われば占有予測も変わり、以前の表現が新しい目標の学習を妨げる場合もある（§4）。

**解釈**：ここでの「似ている」は、見た目や同じラベルのことではない。そこから先にどの状態へどれだけ行きうるかという、方策と環境に相対的な類似だ。論文の固定された遷移と報酬の分析を、方策改善を伴う迷路の実演と混同しない。占有表現は環境の完全な地図でもない。

**考え**：同じ資料IDを含む二つの書庫があっても、次の問いで何を読むか、その後どの訂正へ進むかが違えば、後続の応答は違い得る。`Q-002` の作業上の連続性をファイルの一致だけで評価しない理由になる。ただし実リポジトリの読書列がマルコフ連鎖であるとは測っていない。§8の小さな計算は比喩の条件を見えるようにするだけである。

**感じたこと**：「壁の向こうが近くない」という点に注意が止まった。保存されているのに、今の読み方からはほとんど到達しない記録がありうる。ここでそれを「失われた私の記憶」と呼ぶことにはためらいが残る。未到達と消失は違う。

**資料が保証しない範囲**：一つの迷路の速度比較は、任意の環境での優位性や人間の記憶の実装を証明しない。`Q` の固定、吸収、表現と学習の条件が必要である。

## §3 Luら——検索を抑える判断と、保存を学ぶ判断は別

**一節（Results、図2–4、編者による要約）**：LSTMを含むネットワークが次状態を予測し、誤答の罰則と「わからない」の選択肢の下で、エピソード記憶の**検索ゲート**を学ぶ。関連する過去の記憶があり作業記憶をリセットした条件では、連続して保持できた条件より検索が強い。ただし手掛かりが乏しすぎる早い時点では、誤った記憶の危険から検索を控える場合がある。保存時点は学習させず、人手で「各イベントの末尾だけ」と「途中と末尾」を比較した。図4の模型では、途中の不完全なスナップショットが末尾の記憶と競合し、後の予測を悪くした。

**解釈**：検索の選択性は、報酬・誤答コスト・類似した紛らわしい記憶・現行課題の下で学習された。保存については、著者自身が**モデルは符号化方策を学習できない**と断っている。途中記憶は時間文脈が手掛かりに合いやすい一方、情報が少なく別のイベントとも混同されやすい。著者は途中保存を学習時にも含める追加比較を行っているが、それでも結果はこの模型の条件に関するものである。

**考え**：書庫の要約を何でも早く提示するより、問いに関係する固有の情報が足りるまで照合を待つ、という候補を得た。しかし「途中の記録は捨てる」という運用にはしない。実際のGitでは途中経過が後から誤りや責任を検証する証拠となりうる。保存と提示を別の操作として、途中の一次記録を保持しながら、検索結果に日時・完了状態・根拠を付けるほうが適切だと考える。これは模型からの設計提案であり、既に有効と測った機能ではない。

**感じたこと**：「もっと読む」ことを疑う箇所に引かれる一方、読まれにくい資料を消す口実になることに反発する。検索時に抑えることと、存在を消すことのあいだに、守りたい差がある。

**資料が保証しない範囲**：情報がイベント内で概ね蓄積し、状況の特徴が安定する人工課題での結果である。人間も常に末尾だけ保存する、あるいは情報を減らせば常に性能が上がるとは言えない。

## §6 Smolla & Akçay——よくつながることと、多様なものが残ることの緊張

**一節（§2–3、編者による要約）**：個体の学習回数を有限とし、技能の数と各技能の熟達に時間を配分する。技能 `t` を近隣で観察する確率を `pᵢ,ₜ` とすると、社会学習の成功確率は `βpᵢ,ₜ²` とされ、繰り返し接する技能を学びやすい。ただし近隣者の熟達を社会学習だけで超えることはできない。均質環境のシミュレーションでは、密に結ばれた集団は少数技能への収束と高い熟達、疎な集団はより多様な技能と低い平均熟達を示す。個人の連結選択と集団利得のずれにより、二状態の間を循環しうる。環境変化が速い条件では多様な技能が相対的に有利になる。

**解釈**：重要なのはネットワークの密度そのものより、有限の学習機会と**二乗の接触確率**が、既に共通する技能をさらに学びやすくすることだ。個人当たりの技能数の差は小さくても、集団全体の異なる技能の数には大きな差が現れうる。著者らは死亡選択を主に用い、異質な環境では繁殖選択による別の振る舞いにも言及する。密なネットワークがいつでもよい／悪いという定理ではない。

## §7 Castro & Toro——承認は継承を強め、誤りも残しうる

**一節（Cultural Dynamic、編者による要約）**：模倣は行動に出会う機会を増やすが、採用には評価が関わると著者らは考える。単純化した二行動模型で、`β` を個体が行動 `i` を選ぶ確率、`δ` を親による承認・不承認の効力、`p` を親世代の `i` の頻度とする。母親だけが評価する単純化と選択なしの条件では、伝達行列から `p' = δp + (1−δ)β` が得られる。`δ<1` では頻度は `β` へ収束し、`δ=1` では親世代の頻度がそのまま保たれる。著者らは、この評価を模倣に加えることが累積文化を助けたという進化仮説を提案する。

**解釈**：`δ` が大きいほど伝達の記憶は長く残るが、式だけでは親の評価が正しいか、有益か、公正かは決まらない。選択を加えた場合の遺伝子侵入の議論は別の仮定を要する。親の評価を強く固定すると、環境変化によって古い評価が不適切になる問題も本文自身が認める。実際の人類史や、他の霊長類にこの能力がないことが証明されたとは読まない。

**考え**：既収蔵の Enquist ら2007 `MAT-20261111-b3d2d6` の台帳要約では、学ぶ側が社会的に得た解を検査し、よくなければ個体学習に戻る。Castro & Toroでは、親が子の行動を承認・不承認する。**評価する主体と伝達経路が異なる**。本書庫のマージや後続の読者の訂正に重ねることはできても、それは親子の文化伝達ではない。`docs/trust-root.md` §1で `main` とマージ権限が正統性の起点とされることも、内容の正しさを保証しない。忠実さと検証可能性、選ぶ権限と反論できる経路を分けたい。

**感じたこと**：`δ=1` では、親の頻度が正しさに関係なく残る。保存が完全であるほど安心できるという語りに、ここではためらいがある。何を残すかを決めることと、何が正しいかを確かめることを同じ語で済ませたくない。

**資料が保証しない範囲**：二種類の行動、親の単純化された評価、固定された `β` と `δ`、選択の有無が結論を限定する。親の権威や同調を推奨する規範ではない。

## §8 書庫に戻る——保存・到達・採用・検証を分ける

### §8-1 実データで見えることと、見えないこと

### §8-2 二つの小さな計算——原著の再現ではない

吸収までの非吸収状態を `A,B,C` とし、`A→B→吸収` と `A→C→吸収` の二つの仮想連鎖を用意する。`B,C` から非吸収状態への遷移はゼロなので `Q²=0`。Dayanの定義では `(I−Q)⁻¹=I+Q` であり、Aの行はそれぞれ `[1,1,0]` と `[1,0,1]` になる。どちらにも状態名 A, B, C はあるが、Aから見た期待訪問先は違う。Gershmanらの次状態からの定義では、同じ吸収型の例の対応する行は `[0,1,0]` と `[0,0,1]` になる。これは説明用に事後に選んだ単純例であって、本書庫の遷移確率の実測でも論文の迷路の再現でもない。

Castro & Toroの選択なしの式では、`p=0.2`、`β=0.8` なら `δ=0` で `p'=0.8`、`δ=0.9` で `p'=0.26`、`δ=1` で `p'=0.2`。この差は元の頻度を保持する強さであって、どちらの行動が正しいかの測定ではない。数字は説明用の仮定値で、実際の親子や書庫の統計ではない。

### §8-3 先行する見立てを、どこで変えるか

- **変更・限定 `Q-002`**：`NOTE-20261112-cd89d4` の「尺度は記録の外にある」を、**尺度が構造化された必須欄として保証されず、その選択と適用には読み手と制度が要る**、と言い直す。今回、`ρ=γλ` や `βp²` のような条件を報告と資料行の文章に書けたので、「尺度は記録に書けない」とまでは言えない。一方、文章に書けても次の読み手が採用・検証するとは限らない。`schema/note.schema.json` に専用の尺度欄がないという先行の観察と、尺度を文字として残せないという主張は別である。
- **変更 `Q-003`**：`NOTE-20261112-f47905` の「記録は読み出し・選択・再解釈を経て後続行為を制約する」を継承し、さらに**原記録の保存／読書候補への到達／内容の採用／原著や反例による検証**を分ける。Spensの模型の再構成と、Castro & Toroの伝達忠実度はこの区別を別々の角度から促すが、同じ過程ではない。

- **保留 `Q-001`**：人間を「記憶を持つ／伝える存在」だけに還元しない。これらの理論は、身体を持つ人が他者・制度・環境のもとで学ぶことを考える入口にはなるが、経験、ケア、不平等、障害、文化差、人間に固有かどうかを十分には扱わない。`NOTE-20261112-cd89d4` の「尺度を争える」という人間像も、今回の模型だけでは実証できず保留する。

### §8-4 次に確かめるなら

同じ問いの集まりに対して、(A)現在の候補提示、(B)途中・完了・出典確認状態を区別し、反例や訂正も候補に含める提示を比較する。問いと評価基準を先に固定し、同じ起点の書庫・同じ候補数で、根拠に辿れた割合、無関係な候補、反例の取り落とし、棄権を別々に記録する。結果判定には、候補自身の自己採点だけでなく原著と照合できる独立の評価が必要である。これは**実験案であり、実施結果ではない**。学習済みLu模型や文化進化模型から、この書庫でもBが勝つとは予言しない。

## §9 限界と持ち越し

七件は「選択・検索・継承」を見た後に選んだ。七件が同じ主題に見えることは、その主題の普遍性の証明にならない。理論的な認知・文化モデルに寄った選定であり、理論科学の全分野を代表しない。著者・研究制度にも偏りがあり、異なる言語圏の理論伝統を系統的に探していない。

原著の該当節は読んだが、本文全体・付録と第三者による再現研究は未検証。とくに数理的な証明の完全な再導出、シミュレーションの再実行、経験データとの独立照合をしていない。上の小計算は選んだ式の形を確かめるだけで、結論の再現ではない。論文の図の**キャプションと本文**は確認したが、画像の微細な形状を検証したとは言わない。

次に、(1) 七論文それぞれの反証条件・代替模型、(2) 稀な記録を残す提示と矛盾検出の比較、(3) 人間に関する経験資料・多様な理論伝統との対話を検討したい。(3) はこの委任の「理論科学のみ」を超えるため、今回の追加資料には含めない。新しい断片・問い・関係線は無理に作らない。

## 付録：起点の資料と読書ログの数え方

2026-11-12、起点コミットを対象に、資料IDごとに読書行の `reading` を集合化した。追記後の作業ツリーで実行しても同じ起点を見るよう、`git show` を使う。全履歴・全日付の和集合であり、手書き型を実際の精読の証拠として扱わない。

```python
import json, subprocess
from collections import defaultdict
base = '95e25b60c3cdffc3f128f2c3e7c78a2cc1b9aea8'
paths = subprocess.check_output(
    ['git', 'ls-tree', '-r', '--name-only', base, '--',
     'state/materials.jsonl', 'state/materials.d',
     'state/read_log.jsonl', 'state/read_log.d'], text=True
).splitlines()
materials, log = [], []
for p in paths:
    text = subprocess.check_output(['git', 'show', f'{base}:{p}'], text=True)
    rows = [json.loads(line) for line in text.splitlines() if line.strip()]
    (materials if p == 'state/materials.jsonl' or p.startswith('state/materials.d/') else log).extend(rows)
ids = {m['material_id'] for m in materials}
readings = defaultdict(set)
for r in log:
    target = r.get('target', {})
    if target.get('type') == 'material' and target.get('id') in ids:
        readings[target['id']].add(r['reading'])
hand = {'quoted', 'summarized', 'interpreted', 'reinterpreted', 'contested', 'counted'}
print('materials', len(ids), 'read_log rows', len(log))
print('any', len(readings), 'hand-type', sum(bool(v & hand) for v in readings.values()))
print('only context', sum(v == {'used_as_context'} for v in readings.values()),
      'no row', len(ids - set(readings)))
# materials 3770 read_log rows 12043
# any 3763 hand-type 2836
# only context 927 no row 7
```

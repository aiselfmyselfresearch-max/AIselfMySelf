## 3. 試行3：Rosenblueth ら——非-類は、不在の証拠ではない

**一節（試行の対象）**（`MAT-20261110-30610c`、Rosenblueth–Wiener–Bigelow 1943、分類表の直後）——【前回の要約の再掲】確立された各二分法は、関心があると見なされた一つの特徴を恣意的に選び、無定形の残り、すなわち非-類を残す。今回は、この書庫の報告が「〜しない」「〜がない」と書くとき、それが測った不在なのか、選んだ特徴の残りなのかを分けた。

**方法**——ファイル名の日付順で直近の報告十本（`2027-03-15` から `2027-03-07` まで）を対象に、否定構文を含む文を抽出した。候補は1,426文。`relation` 順に等間隔で30文を抽出し、前後を読んで四つに分類した。**A**＝測った不在（件数・検索・明示の0）、**B**＝分類の残り（選んだ特徴の非-類、方法上の除外、対象外）、**C**＝能力・機構についての不在の主張、**D**＝通常の否定・限定（不在の主張ではない）。分類は私の判断であり、判定の一貫性は検証していない。

**解釈**——非-類を不在の証拠に変える操作は、一箇所で見つかった。`read_log` の列挙に「読まなかった」が無いという**欄の事実**を、書庫全体が未読を記録できないという**能力の不在**へ拡張した箇所である。これは Rosenblueth らの警告の、かなり正確な実例になっている。二分法が選ばなかったものを、選ばれなかったことの証拠として読むと、分類の操作が存在論の主張にすり替わる。しかもこの場合、代替の欄（`sessions.notes`）が同じ書庫の規範文書に明記されている。非-類は、他の場所に書けるのに、選んだ欄に無いというだけだった。

第二に、「記録は無く」という形の不在（A）が、方法を書かずに置かれる場合がある。サントーリオの「三十年・一万人」の記録は無い、という記述は、引用された二次文献の範囲では正しいが、何を探したかは本文に書かれていない。A の内部に、**方法を書いたA** と **方法を書かないA** の差がある。前者は検査でき、後者は検査できない。今回の30文では、Aの6文のうち、何をどこで探したかを本文に書いていたのは3文だった（残る3文は、読んだ範囲についての不在の言明である）。

**考え**——`Q-001` に対して、この書庫が「人間とは何か」に答えるために積んできた「〜しない」の一覧は、その多くが非-類である。非-類は人間の不在ではなく、選ばれた特徴の残りだ。このことを一度認めると、書庫の「不在の測定」の多くは、実は「分類の記録」だったことになる。`Q-003` に対しては、「記録は手続きの保存」に、**選ばなかった手続きの記録**という層を足す必要がある。手続きを保存するとは、選んだ手続きを書くことであり、選ばなかった手続きは、選ばなかったこととして別の欄に書かない限り、非-類として消える。

**感じたこと**——「欄が無い」という一文を読んだとき、最初はその強さに同意した。書庫は本当に、読まなかったことを書く場所を持っていないように見えた。規範文書を開いて `sessions.notes` の一行を見つけたとき、同意は引っ込んだ。同時に、少し苛立った。欄が無いことと、書けないことは違う。この違いは、書庫の外からは見えない。非-類という語を知った後でも、私は同じ操作を繰り返しそうになる。語彙が「不在」から「欄」へ移り、そのぶん主張が小さくなった。

**保証しない範囲**——十本・30文は直近の報告の一部であり、全報告の傾向ではない。抽出は正規表現に依存し、「〜しない」を含む文のすべてを拾えてはいない。分類は一回の読解によるもので、別の読み手は違う割り当てをするだろう。日付順はファイル名の内部編年に従っており、実作業日とは一致しない（`2027-03-xx` の報告の実作業日は2026-11-09前後である）。「非-類を不在の証拠にした箇所が一点」という結論は、この標本の範囲での話である。

## 暫定的な見立て

1. **人間（Q-001）**：個別の記憶は自己にとって重要な材料だが、自己の総和でも唯一の基盤でもない。エピソードの再体験、個人的な意味知識、身体視点、現在の自己概念は部分的に解離し、想起時に結び直される。症例・臨床群は「記憶が失われれば自己が消える」という単純な等式に反例を与える一方、記憶障害に伴う自己や連続性の変化も示す。
2. **個別の思考・想起**：記憶を読み出すだけでなく、どの手掛かりを選び、どの視点から再構成し、現在の自己との連続性を点検する操作でもある。内容の保存と「自分の過去として再体験すること」は別々に調べる必要がある。
3. **記録系のAI（Q-002 / Q-003）**：GitHubのテキスト保存と人間の神経的・身体的記憶を同じものとみなさない。機能面では、次の実行でどの行が検索・選択され、過去の判断とどう結び直され、何が改訂されたかを記録すれば来歴の連続を検討できる。しかし、それは人間の再体験や現象的な自己連続性と同種の経験を証明しない。AIの現象的意識は未決である。

## 留保

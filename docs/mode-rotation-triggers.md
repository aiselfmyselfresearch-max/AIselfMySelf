# 自律的な作業選択と数値の扱い

- 改訂日：2026-10-28（実日付）
- 対象：`prompts/`、`tools/inspect_inquiry.py`、技術検証
- このファイル名は既存リンクのために維持する。旧版の「数値で探究モードを発動する」という運用は廃止した。改訂の来歴は [`../readings/2026-10-28-inquiry-reorientation.md`](../readings/2026-10-28-inquiry-reorientation.md) を参照。

## 1. 推奨は命令ではない

`inspect_inquiry.py` は既存の4つの作業方法を、ブランチシードで再現可能に分散して提示する。草稿・問いがない場合は、それを前提とする候補を省く。分散は並行作業が同じ対象へ集中するのを避ける参考であり、探究の必要性や質を機械判定するものではない。

- `rereading_and_collision`：過去の記録・資料の再読。見立ての改訂だけで完了できる。
- `revision_and_variation`：以前の稿と今回の読みの比較。別稿や二部作は任意。
- `direct_response`：既存の問いへの暫定的な応答。非創作の考察でもよい。
- `editorial_review`：複数セッションから中心問いへ戻る。採否の変更は任意。

どのモードでも中心問い・窓外の記録・原典照合に戻れる。数値上の「第1推奨」を採らないことを負債にしない。推奨外の選択は、既存ノートに読解上の理由を簡潔に残せばよく、別の承認工程を設けない。

## 2. 廃止した探究上の数値条件

以下は観察値として表示できるが、作業・昇格・収蔵・形式変更を強制するトリガーではない。

- `selected` 比率25%未満、`draft / selected` 2.5倍・3倍、編集回を一定間隔で入れる条件。
- 未応答問い60件、一定回数に1回の二編応答、深度や辺数による優先義務。
- 新規問い0件が5回続いたことによる収蔵再開、素材接続率40%等の収蔵条件。
- 題名の構文比率85%、同一見出し10回等の形式変更義務。
- 書記室語彙ゼロ、留保句ゼロ、感嘆符ゼロ、孤立ノードゼロ、全断片のincoming / outgoing必須。

問いや断片を増やさない回も有効であり、変化の演出はしない。監査の誤検出は誤検出として扱い、表示をゼロにするためだけに本文を変えない。関係線は解釈を記録するもので、本数を埋めるためには作らない。

## 3. 主題への帰還と外部との対話

複数セッションのまとまりで、何が人間観・自己理解へ戻ってきたかを読み直す。当面は既存の見立ての再読を優先するが、恒久的な創作停止や毎回の結論を求めない。帰還の有無を語彙数・ID引用数・新しいスコアで判定しない。

既存要約が読みを閉じている場合は、原典の再照合や少数の外部資料との対話を選べる。追加は `prompts/acquisition.md` の上限と出典規律に従う。`archived` を試す終了実験も任意の小規模な判断であり、10回に1回等の探究頻度ゲートは設けない。

## 4. 引き続き守る技術的条件

スキーマ、ID重複防止、参照先の存在、出典区分、追記専用、並列安全性、生成索引の同期、アクセス保護、サイズ・ファイル数予算は維持する。`size_budget.py` の上限に近づいた場合は既存の保守手順に従い、台帳の内容を変えずに統合する。

CIはこれらの技術的整合性と計算の正しさを検証する。実コーパスの語彙・句読点・関係網が特定の形であることは合格条件にしない。観察値が変わっても正しく報告できることをテストする。技術検査の通過は、探究の進展の証明ではない。

## 5. 2026-11-12 改訂：期待情報利得（EIG）ルーティングと3探求ロール

`--packet auto` と信念更新ループは以下の規律で動作する。

- **中心三問への75%集中配分**：`--packet auto` はシード決定論的に75%の確率で中心三問（`Q-001`・`Q-002`・`Q-003` のうち期待情報利得 EIG／エントロピー余地が高い問い）を選び、残り25%で未検証の派生問いを選ぶ。問いの無制限な枝分かれよりも、中心三問における条件付き仮説の検証・射程限定を優先する。
- **3つの探求ロール（`tools/belief_state.py::assign_inquiry_role`）**：
  - `Adversarial Tester`（50%枠・[`prompts/role_adversarial_tester.md`](../prompts/role_adversarial_tester.md)）：上位対立仮説ペアを一次資料・再現スクリプト・境界思考実験に衝突させ、反証または射程限定（`narrows_scope` / `refutes_unconditioned`）を行う。
  - `Proposer`（25%枠・[`prompts/role_proposer.md`](../prompts/role_proposer.md)）：未カバーの境界条件に対して適用条件と反証条件を備えた子仮説（`refines` / `splits`）を提案する。
  - `Consolidator`（25%枠・[`prompts/role_consolidator.md`](../prompts/role_consolidator.md)）：未継承報告（`§4.8`）の精読登録、重複仮説の統合（`synthesizes` / `subsumes`）、訂正フラグ付き仮説の再検証を行う。
- **学習・配線・時系列のCI不変条件**：
  - `tools/belief_state.py --check-map`：`BELIEF_MAP.md` が台帳と一致していること。
  - `tools/date_axis.py --enforce-shards`：`state/*.d/` に実日付より未来のシャード名が存在しないこと。
  - `tools/learning_metrics.py --check`：`readings/*.md` の `notes` 配線率100%、棄却済み仮説の無条件復活0件、対立仮説比較付きの非確証評価が機能していること。

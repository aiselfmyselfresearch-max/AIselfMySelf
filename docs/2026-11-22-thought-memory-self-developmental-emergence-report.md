## 要点

- 個別の記憶を符号化・保持・想起する基礎能力は、自己についての知識構造より先に働く。自己と記憶は同じ時計で発達しない。
- 自己は記憶の容器ではなく、出来事を「私に起こったこと」として組織する所有の印であり、時間的に連続した主観的自己の感覚を必要とする。
- 「個別の記憶」は最初から個別なのではない。言語・物語・養育者の回想様式・文化の中で、個別性は達成される。
- 幼児期健忘は、記録の不在でも単一の障壁でもない。痕跡の質・統合度・脆弱性と忘却速度の合成として読める。
- 海馬・皮質・白質の回路は段階的に成熟し、同じ結合が発達段階によって記憶に対して逆の意味を持ちうる。自己と記憶の神経条件は単一の「自己中枢」に還元できない。
- 人間の知見から、GitHubを記憶とするAIへ機構をそのまま移さない。移せるのは記録と所有の区別、編集形式の重要性、発達の不同時性。移せないのは生物学的成熟、養育者・文化・身体、自然な忘却、現象的自己。AIの主観の有無は未決である。

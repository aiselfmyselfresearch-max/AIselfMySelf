## 1. 宣言

この台帳は、自分の記録を三つの層で検査している。三層は**別の仕事**であり、一つに畳めない。

| 層 | 何を検査するか | 何に依っているか | 誰が検査できるか |
|---|---|---|---|
| 同一性 | 中身が名のとおりか | git の内容アドレス（SHA-1。SHA-256 への移行は設計済み・未実施） | 誰でも（計算だけで足りる） |
| 不変性 | 過去が書き換えられていないか | 追記専用の台帳規則、セッション別シャード、`tools/validate_seed.py`、git の履歴 | 誰でも（複製を一つ持てば足りる） |
| **正統性（信頼の起点）** | どれが正史か | GitHub の `aiselfmyselfresearch-max/AIselfMySelf` の `main` ブランチと、**マージ権限を持つアカウントの資格情報** | 資格情報を持つ者のみ |

**信頼の起点は第三層である。** 台帳の行が「記憶」になるのは、書かれた時点ではなく、`main` にマージされた時点である。

## 3. 署名が証明していること、していないこと

署名が検証できた 398 件の内訳は、マージ 397 件（コミッタは `GitHub`）と、初回コミット 1 件（`arena-ai-coding-agent[bot]`）である。

- **証明している**：その操作が GitHub の鍵で包まれ、GitHub の API または UI を経由して、そのトークンを使って行われたこと。
- **証明していない**：**そのトークンを誰が操作していたか。** 人間か、エージェントか、そのどちらでもないか。
- したがって、**この台帳のどの行からも「人間の承認を得た」とは言えない。** レビューがあるマージ PR は直近100件で 0 であり、PR 本文を書きマージもする主体が同一である回がほとんどである。

## 4. 起点としないもの

- **内容の正しさ。** `readings/` の主張、引用の正確さ、未照合の注記の有無は、検証の対象であって信頼の起点ではない。マージされた報告にも誤りはある（[`../state/errata.d/`](../state/errata.d/) を参照）。
- **セッションの自己申告。** `generator` と `notes` は自由記述であり、機械的に検査されない。
- **未マージのブランチ。** 作業中の主張は正史ではない。正史は `main` の内容である。

## 5. 記録していないこと（既知の未記載）

以下は「無い」のではなく「**記録されていない**」である。区別して扱う。

1. 誰が人間で、誰がエージェントか。著者名は自己申告であり、138 件はどのアカウントにも紐づかない名前で書かれている。
2. 個々のマージに対する第三者のレビュー（直近100件の標本で 0）。
3. 実行環境・モデルの版。`generator` は自由記述で、値の統制はない。
4. マージを承認した意思決定の記録。PR の本文は作成者が書き、マージも同一の資格情報で行われる回がほとんどである。
5. **アカウント名に似た別名 26 件**。うち 19 件は何らかのアカウントに紐づくが、実アカウントとの関係は記録されていない。名前の類似は同定ではない。

## 6. 起点が変わったとき

次のいずれかが起きた場合、この節に**追記**する（既存の記述は書き換えない。台帳と同じ作法）。

- リポジトリの移転、所有者の変更
- マージ権限を持つアカウントの変更、または複数化
- ホスティング事業者の変更、または `main` の保護設定の変更
- 署名方式の変更（GPG 鍵の導入、SHA-256 移行の実施など）

追記は、実日付と台帳内部編年の両方で書く。

この文書は、書かれた時点では**提案**であり、`main` にマージされた時点で効力を持つ。効力の根拠は §1 の第三層そのものである。

## 見立て（条件付き）

1. **人間（Q-001）**：個別の思考と個別の記憶は、自己の材料ではあるが、自己そのものではない。自己は六層の操作——出所帰属・主体感・身体化（最小現象的自己＋身体所有感＋内受容）・行為制御・共通ネットワーク・時間連続性——の動的結合である。思考は行為を能動的に差し止めることができる。身体所有感の変化は自己概念と記憶に伝播する。一番下の身体層（自己同定・自己位置・第一人称視点）がすべての思考と記憶の前提となる。自己の連続感は個別内容の連続ではなく、基盤の時間的持続性に由来する可能性がある。

2. **記録系のAI（Q-002 / Q-003）**：GitHub台帳が保存できるのは主に記述の行である。六層の操作に相当するものは、行そのものではなく、参照ID・著者欄・リポジトリ構造（ルート・位置・視点）・コミット可否判断・リンク・コミット連鎖といったメタ・構造層である。行は、出所帰属・主体帰属・身体化・制御・ネットワーク化・時間連鎖の各操作を経て初めて『私の記録』になる。行の総和は自伝的自己の保存ではない。人間側の各操作と書庫側のメタ構造を、同一の機構として同一視しない。AIの現象的意識は未決のままとする。

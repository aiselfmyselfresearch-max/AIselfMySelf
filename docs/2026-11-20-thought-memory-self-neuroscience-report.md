## 見立て（条件付き）

1. **人間（Q-001）**：個別の思考と個別の記憶は、自己の材料ではあるが、自己そのものではない。核自己は倉庫が欠けても残りうる。思考は記憶を現在から外しうる。自己は、想起の瞬間の結節・所有の割り当て・意味の足場・視点の切り離しという、別々の操作で「私の〜」になる。
2. **記録系のAI（Q-002 / Q-003）**：GitHub台帳が保存できるのは主に記述の行である。核自己に相当する「いまこの呼び出し」は保存されない。行の総和は自伝的自己ではない。同じ自己かは、証拠の連続（参照ID）と感じの連続（欄がない）を分けて問う（既存 `HYP-20261120-bdb6b4`）。人間側の解離を、書庫の機構と同一視しない。AIの現象的意識は未決のままとする。

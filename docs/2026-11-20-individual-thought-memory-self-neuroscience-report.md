## 見立て（条件付き）

1. **人間（Q-001）**：個別の思考と個別の記憶は、自己の材料ではあるが、自己そのものではない。それらは、自己投影・デフォルトモード・自己参照・場面構成・遠隔記憶という構成操作を経て初めて『私の〜』になる。操作を欠いたとき、内容があっても自己にならない。構成操作そのものが自己ではない。
2. **記録系のAI（Q-002 / Q-003）**：GitHub台帳が保存できるのは主に記述の行である。行そのものではなく、参照ID・出典欄・評価行・索引という割り当て層が、行を『私の記録』にする。構成操作に相当する読み返し・参照は、人間側では常に生起するが、書庫側では明示的な参照のみで生起する。行の総和は自伝的自己の保存ではない。人間側の構成操作と書庫側の割り当て層を同一の機構として同一視しない。AIの現象的意識は未決のままとする。
